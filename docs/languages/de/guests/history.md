# Gästedaten, Suche und Aufenthaltshistorie

## Vollständige Gästeinformationen

1. Öffnen Sie Gästezeilen im Buchungsformular oder verwenden Sie Bearbeiten Gäste auf einer vorhandenen Reservierung.
2. Geben Sie den richtigen Namen, die Kontaktdaten und die Identitätsdaten jeder Person in die angegebenen Felder ein.
3. Wählen Sie die Staatsangehörigkeit aus der Liste der Länder aus. Sie können nach Landnamen oder Code suchen.
4. Fügen Sie eine Gästezeile für alle hinzu, die später an dem Aufenthalt teilnehmen.
5. Speichern und überprüfen Sie die Gästeliste der Reservierung.

Nehmen Sie nicht an, dass zwei Personen mit dem gleichen Namen der gleiche Gast sind. Die Anwendung vereint keine Personen, die nur auf ähnlichen Namen basieren. Die Anzahl der Gäste in Zimmer- und Wohnungsreservierungen und die Kapazitätsgrenzen für einzeln gemietete Betten werden separat behandelt.

## Finden Sie Vergangenheit

1. Öffnen Sie Gäste-Suche und Geschichte.
2. Setzen Sie Datum- und Statusfilter.
3. Suchen Sie nach Namen, Identitätsinformationen oder Telefonnummern.
4. Öffnen Sie die Aufzeichnungen und überprüfen Sie die Aufenthaltsdaten und die Einheitszuweisungen.
5. Wenn der Gast umgezogen ist, überprüfen Sie die vorherigen Einheiten und die Personen, die während jeder Periode zusammenbleiben.

## Exportieren Sie eine Liste

Überprüfen Sie Ihre Filter, bevor Sie Excel oder PDF-Export verwenden. Gast-Export deckt die gefilterte Abfrage ab, nicht nur die sichtbare Seite, bis zu 10.000 Zeilen. Verkleinern Sie den Datumsbereich für größere Ergebnisse.

Wenn die PDF-Generation fehlschlägt, senden Sie den Fehler an Ihren Administrator, anstatt die gleiche Anfrage mehrfach einzureichen. Die PDF-Generationskomponente des Servers kann Aufmerksamkeit benötigen.
