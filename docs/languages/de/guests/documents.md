# Verträge, Belege und Dokumentvorlagen

## Bereiten Sie ein Buchungsdokument vor

1. Öffnen Sie die richtige Reservierung oder Zimmerkarte.
2. Wählen Sie den gewünschten Vertrag, die Buchungsbestätigung, die Zahlungserklärung oder das Stornierungsdokument aus.
3. Überprüfen Sie die Dokumentsprache und die Vorlage.
4. Überprüfen Sie die Felder Gäste, Hotelbranche, Datum und Betrag in der Vorschau.
5. Wenn nötig, verwenden Sie den Text dieses Dokuments bearbeiten, um nur das Dokument zu ändern, das Sie erstellen möchten.
6. Veröffentlichen Sie das Dokument und verwenden Sie die verfügbare Download- oder Druckaktion.

Überprüfen Sie für eine Zahlungserklärung den Betrag, die Währung, die Methode und das Datum. Die Ausstellung eines Dokuments berechnet kein Bankkonto oder kein Zahlungsterminal, erfasst eine finanzielle Zahlung automatisch oder übermittelt eine KBS-Gästebenachrichtigung.

## Bearbeiten Sie die Geschäftsvorlage

1. Öffnen Sie Dokumentvorlagen mit einem autorisierten Konto.
2. Wählen Sie den Dokumenttyp und die Sprache aus.
3. Bereiten Sie Titel und Körper vor.
4. Fügen Sie automatische Informationsfelder am Cursor ein, anstatt in jedes Dokument Gäste- oder Hotelzweigdaten manuell einzugeben.
5. Format der Inhalte mit Titeln, Listen, Tabellen und Ausrichtungsinstrumenten.
6. Speichern und überprüfen Sie das Ergebnis in einer neuen Dokument-Vorsicht.

Jede Sprache hat ihren eigenen Titel und ihren eigenen Körper. Bereiten Sie fehlende Sprachinhalte vor, anstatt davon auszugehen, dass eine andere Sprache automatisch ersetzt wird.

## Ändern sich vorherige Dokumente?

In einem ausgestellten Dokument werden die Text- und Zahlungsfelder so gespeichert, wie sie zu ihrer Erstellung waren. Die Aktualisierung einer Vorlage ändert keine bestehenden Dokumente. Die Bearbeitung eines einzigen Dokuments in der Vorschau ändert die geteilte Geschäftsvorlage nicht.

Für Berichtsdokumente folgen Sie dem Dokument vorbereiten in [Mit Hilfe von Berichten](../finance/reports.md).
