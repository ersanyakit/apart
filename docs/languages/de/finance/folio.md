# Zimmerkonto und Zusatzleistungen

Öffnen Sie Folio auf der Zimmerkarte oder Zimmerkonto / Leistung hinzufügen in den Reservierungsdetails.

Das Zimmerkonto zeigt Übernachtungsgebühren, Zusatzleistungen und Zahlungsvorgänge der Reservierung zusammen. Lesen Sie die Summen für jede Währung getrennt.

## Eine Zusatzleistung erfassen

1. Öffnen Sie das Zimmerkonto der richtigen Reservierung.
2. Geben Sie Name und Kategorie der Leistung ein oder wählen Sie diese aus.
3. Legen Sie Menge, Einzelpreis und Währung fest.
4. Ergänzen Sie eine Erklärung und prüfen Sie den Gesamtbetrag.
5. Speichern Sie und kontrollieren Sie den Eintrag im Zimmerkonto.

Beispiel: Zwei Frühstücke zu je 150 TRY ergeben eine Forderung von 300 TRY. Damit ist noch nicht bestätigt, dass der Gast 300 TRY bezahlt hat. Erfassen Sie den Zahlungseingang separat.

## Einen fehlerhaften Leistungseintrag korrigieren

Verwenden Sie die Stornierung der Leistung und geben Sie einen Grund an. Prüfen Sie die Stornierung anschließend im Zimmerkonto. Ändern Sie nicht nur die Beschreibung und erfassen Sie keine zusätzliche Leistung mit negativem Betrag als Ersatz für diese Stornierung.

Rezeptionsmitarbeiter dürfen Leistungen nur zu offenen Reservierungen in zugänglichen Unterkünften hinzufügen. Wenden Sie sich bei abgeschlossenen Reservierungen oder fehlender Berechtigung an Ihre Leitung.

## Vor dem Check-out

Erfassen Sie die letzten Leistungen und prüfen Sie Zahlungseingänge und Erstattungen. Aktualisieren Sie das Konto nach Änderungen anderer Mitarbeiter. Die Bestätigung eines offenen Saldos beim Check-out löscht diesen nicht.
