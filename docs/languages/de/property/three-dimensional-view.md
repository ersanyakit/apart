# 3D-Ansicht

Öffnen Sie die 3D-Ansicht unter Hotelbetrieb.

![3D-Ansicht](../images/property-3d.png)

## Entdecken Sie die Hotelbranche

1. Wählen Sie die richtige Hotelbranche aus und öffnen Sie 3D View.
2. Verwenden Sie die Boden-Taste in der Szene, um einen Boden zu wählen.
3. Verwenden Sie die Fußboden- und Wandsteuerungen, um das Innere zu entdecken.
4. Wählen Sie ein Zimmer oder ein Bett aus, um Informationen und Aufenthaltsstatus zu überprüfen.
5. Folgen Sie den verfügbaren Aktionen auf den entsprechenden Reservierungsschranen, sofern Sie Ihre Berechtigungen haben.
6. Verwenden Sie Refresh, um den neuesten Status zu erhalten.

## Interpretieren Sie die Szene

Etagen, Zimmer und Betten stammen aus den Definitionen der Hotelbranche. Die fehlenden oder überlappenden Positionen können schematisch angeordnet werden, und die Betten in den Räumen werden automatisch positioniert. Dies ist kein architektonisches Messgerät oder ein Werkzeug zur Bearbeitung des Bodenplanes. Die Erkundung der Szene ändert die gespeicherten Koordinaten nicht.

Die visuelle Verteilung der Gäste einer Zimmerreservierung über die Betten hinweg erzeugt keine tatsächlichen Bettenzuweisungen. Gäste ohne spezifiziertes Geschlecht verwenden einen neutralen Charakter; Geschlecht wird nicht aus Namen abgeleitet.

## Eine Einheit fehlt oder sieht falsch aus

Überprüfen Sie die Hotelbranche, den Boden, die Zimmerbeziehung, die tatsächlichen Definitionen von Bettmöbeln und den Mietmodus, dann erfrischen. Schematische Betten, die als Zimmermöbel ausgewählt werden, schaffen keine separaten Reservierungseinheiten.

Wenn der Browser die 3D-Szene nicht öffnen kann, versuchen Sie erneut oder wählen Sie die Text-basierte Einheit aus. Sie können die tägliche Arbeit von der [Raumstatus-Board](../operations/room-board.md).
