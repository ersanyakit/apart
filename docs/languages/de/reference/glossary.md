# Glossar

| Begriff | Bedeutung |
| --- | --- |
| Hotel / Geschäft | Das Hauptgeschäft, zu dem die Zweigstellen und Genehmigungen des Hotels gehören. |
| Unterkunft / Niederlassung | Der Ort, an dem die Operationen durchgeführt werden; die Aufzeichnungen werden an den ausgewählten Hotelfiliale gerichtet. |
| Einheit | Eine Wohnung, ein Zimmer, ein Schlafzimmer oder ein Bett im Miethaus. |
| Physisches Bett | Schlaf- oder Schlafzimmermöbel; nicht unbedingt eine separat vermietbare Einheit. |
| Bettplatz | Ein Ort oder eine Ebene in der physischen Struktur; Gästekapazität wird separat definiert. |
| Bestätigte Reservierung | Eine gespeicherte Reservierung, für die noch kein Check-in erfolgt ist. |
| Geplante Ankunft/Abreise | Die erwarteten Termine für die Reservierung. |
| tatsächliche Ankunft/Abreise | Die Zeiten, in denen der Check-in und der Check-out tatsächlich stattfinden. |
| Zuweisung | Die Einheit, die während eines bestimmten Zeitraums von einer Reservierung belegt wird. |
| Zimmerkonto | Kontoübersicht einer Reservierung mit Gebühren, Leistungen und Zahlungsvorgängen. |
| Periodengerechter Erlös | Der Wert der in einem Zeitraum erbrachten Dienstleistungen; die Zahlung kann zu einem anderen Zeitpunkt erfolgen. |
| Zahlungseingang | Geld, das das Geschäft erhalten hat. |
| Aufwand / Auszahlung | Ein Aufwand ist ein entstandener Kostenbetrag; eine Auszahlung ist ein tatsächlicher Geldabfluss. |
| Kaution | Eine unter bestimmten Bedingungen zurückzuzahlende Kaution; kein Übernachtungserlös. |
| Einheit-Nacht | Ein Einsatz oder Verkauf für eine Nacht. |
| Physische Auslastung | Gebrauchte Einheit-Nächte im Vergleich zur physischen Kapazität. |
| Auslastung der verkaufbaren Kapazität | Verwendung im Verhältnis zur zum Verkauf verfügbaren Kapazität. |
| ADR | Erlös geteilt durch verkaufte Nächte desselben Produkttyps. |
| RevPAR | Erlös geteilt durch verkaufbare Nächte desselben Produkttyps. |
| Betriebsergebnis | Erlöse abzüglich betrieblicher Aufwendungen im Bericht; kein buchhalterischer Nettogewinn. |
| Archive | Aus der täglichen Ansicht entfernen, ohne den Datensatz endgültig zu löschen. |

Interpretieren Sie jedes Status-Label zusammen mit dem Datum und dem Typ der Aufzeichnung. Siehst du ? [Mit Hilfe von Berichten](../finance/reports.md) für Berechnungsdetails.
