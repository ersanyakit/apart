# Eine Rezeptionsschicht von Anfang bis Ende

## Beginn der Schicht

1. Melden Sie sich mit Ihrem eigenen Konto an und bestätigen Sie die ausgewählte Hotelbranche.
2. Lesen Sie die dringenden und laufenden Aufgaben auf dem Schreibtisch "Reception Notes".
3. Überprüfen Sie die schmutzigen, nicht ordnungsgemäßen und renovierten Einheiten auf dem Zimmerstatus-Board.
4. Überprüfen Sie die heutigen An- und Abflüge im Aufenthaltskalender und in der Reservierungsliste.
5. Denken Sie an späte Abflüge und Zimmer, die am selben Tag für eine andere Ankunft geplant sind.

## Während des Tages

Registrieren Sie neue Buchungen unter Verwendung der [Reservierungs-Arbeitsfluss](../operations/reservations.md). Überprüfen Sie die ankommenden Gäste in ihre bestehende Reservierung, anstatt eine zweite Reservierung zu erstellen. Verwenden Sie den Zimmerwechsel der Reservierung, wenn Sie Gäste bewegen. Hinzufügen von zusätzlichen Dienstleistungen auf das richtige Buchungs-Gäste-Bilanzierungskonto.

Aktualisieren Sie den Reinigungsstatus, wenn die Reinigung abgeschlossen ist. Markieren Sie niemals einen unvorbereiteten Raum als sauber, nur um eine Validierungsnachricht zu überschreiten.

## Bei Abfahrt

1. Öffnen Sie die [Vor-Check-out-Gastrechnungskonto](../operations/check-in-out.md).
2. Überprüfen Sie die Unterkunfts- und Dienstleistungsgebühren, die erhaltenen Zahlungen, die Rückerstattungen und die Sicherheiten separat.
3. Füllen Sie alle erforderlichen Aufzeichnungen innerhalb Ihrer Berechtigungen aus.
4. Nach der Bestätigung des Check-outs überprüfen Sie den Aufenthalt und den Zimmerstatus.
5. Lassen Sie einen Empfangsschreiben hinterlassen, wenn das Zimmer vorbereitet werden muss.

## Übergabe

Erfassen Sie eindeutig unvollendete Aufgaben, erwartete Ankunft und Balance, die Nachverfolgung erfordern. Wenn Sie Zugang zu Schicht- und Bargeldberichten haben, vergleichen Sie die aufgezeichneten Bargeldbewegungen mit dem tatsächlich gezählten Bargeld. Unterschreiben Sie sich, wenn Ihre Arbeit fertig ist.

Verwandte Leitfaden: [Aufnahmebestätigungen](../operations/reception-notes.md).
