# Gäste umziehen, Einheiten tauschen und stornieren

## Verlegen Sie einen Gast in eine andere Einheit.

1. Öffnen Sie die Reservierung und wählen Sie den Wechselraum aus.
2. Wählen Sie die Bewegung.
3. Wählen Sie ein verfügbares Zielzimmer, eine Wohnung oder ein Bett aus.
4. Überprüfen Sie den Gast, die Termine und das Ziel und bestätigen Sie es.
5. Überprüfen Sie, ob der Gast auf der Karte der neuen Einheit erscheint.

Für eingeschriebene Gäste tritt der Umzug ab der Betriebsstunde in Kraft. Die Zeit, die in der vorherigen Einheit verbracht wurde, bleibt in der Geschichte. Versuchen Sie nicht, die Geschichte neu zu schreiben, indem Sie einen Einheitscode manuell ändern.

## Austausch von zwei Reservierungs-Einheiten

1. Öffnen Sie den Umkleiderraum für eine Reservierung.
2. Wählen Sie die Austauschoperation.
3. Wählen Sie die richtige zweite Reservierung.
4. Überprüfen Sie beide Gäste, beide Einheiten und ihre Termine.
5. Bestätigen und überprüfen Sie beide Reservierungen später.

Beide Seiten sind zusammen validiert. Die Verfügbarkeit oder die Gästekapazität der Betten können den Austausch verhindern. Erstellen Sie nicht zwei neue Buchungen, um den Fehler zu umgehen.

## Eine Reservierung vor dem Check-in stornieren

1. Wählen Sie die richtige Reservierung aus.
2. Öffnen Sie die Reservierung.
3. Füllen Sie die Bestätigung und den erforderlichen Grund aus.
4. Überprüfen Sie den aktualisierten Reservierungsstatus.
5. Wenn das Geld eingegangen ist, übernehmen Sie die Rückerstattung separat durch [Aufzeichnungen über finanzielle Transaktionen](../finance/transactions.md).

Für Gäste, die sich bereits angemeldet haben, sollten Sie den Check-out anstelle der Stornierung der Reservierung verwenden. Eine Stornierung erfolgt nicht automatisch über eine Bank oder ein Zahlungsterminal.
