# Rezeptionsnotizen und Schichtübergabe

Öffnen Sie die Empfangsnotizen unter Hotelbetrieb oder benutzen Sie die Benachrichtigungsschaltfläche oben.

![Aufnahmebestätigungen](../images/notes.png)

## Erstellen Sie eine Aufgabe

1. Bestätigen Sie die ausgewählte Hotelbranche.
2. Öffnen Sie die Aktion mit neuen Notizen auf dem Board.
3. Schreiben Sie einen kurzen, aktionsorientierten Titel, wie z. B.    ¢ Überprüfen Sie die Ankunftsvorbereitungen für Raum 203 ¢.
4. Hinzufügen Sie die erforderlichen Arbeiten, Zimmerinformationen und Details für die nächsten Schichten.
5. Wählen Sie Status und Priorität aus und speichern Sie dann.
6. Bestätigen Sie, dass die Notiz in der richtigen Spalte angezeigt wird.

## Aktualisierung der Fortschritte

Das Vorstand hat zu tun, in der Entwicklung und abgeschlossenen Spalten. Ziehen Sie eine Karte oder verwenden Sie ihr Statusmenü, um sie zu verschieben. Das Statusmenü eignet sich auch für den Gebrauch von Touch und Tastatur.

Bewegen Sie die Karte nur dann in Fertigstellung, wenn die Arbeit tatsächlich abgeschlossen ist. Archive-Noten, die nicht mehr auf dem Tagesbrett benötigt werden, und wenn nötig, wiederherstellen. Die Archivierung ist keine dauerhafte Löschung.

## Wenn zwei Leute die gleiche Note bearbeiten

Werden die Spare abgelehnt, weil ein anderer Mitarbeiter die Note geändert hat, öffnen Sie sie wieder, lesen Sie die aktuelle Version und wenden Sie Ihren Wechsel erneut an. Die Platte erfrischt sich regelmäßig, wenn sie geöffnet ist und wenn man zum Fenster zurückkehrt. Verwenden Sie Suche und laden Sie mehr, wenn eine Karte nicht sichtbar ist.

Die Notizen werden innerhalb des Hotelbereichs geteilt. Eine Anmerkung zu vervollständigen aktualisiert nicht automatisch die Räumlichkeitsreinigung, die Reservierungen oder die Finanzergebnisse. Führen Sie auch die tatsächliche Operation auf dem entsprechenden Bildschirm durch.
