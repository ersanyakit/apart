# Zimmerstatus und Reinigung

Öffnen Sie den Zimmerstatus unter Hotelbetrieb.

![Raumstatus-Board](../images/board.png)

## Lesen Sie eine Zimmerkarte .

Lesen Sie zusammen den Einheitscode, die Gäste- oder Reservierungsinformationen und die Ankunfts-/Abreisetaten. Die Besetzung und die Reinigung unterscheiden sich: Ein sauberes Zimmer kann besetzt werden, und ein leeres Zimmer muss immer noch gereinigt werden. Lesen Sie das Statusetikett, anstatt sich nur auf Farbe zu verlassen.

## Finden Sie eine Einheit

1. Bestätigen Sie die ausgewählte Hotelbranche.
2. Passen Sie nach Bedarf Such-, Boden- und Datumsfilter an.
3. Überprüfen Sie den Einheitscode auf der Karte.
4. Öffnen Sie das Aktionsmenü der Karte. Auf dem Desktop gibt das Rechte-Klick-Menü auch Reservierungs-, Gast-, Status- und Dokumentaktionen an.

Wenn Sie ein anderes Datum anzeigen, verwechseln Sie nicht den Status der Reservierung dieses Datums mit dem aktuellen Reinigungsstatus.

## Änderung des Reinigungsstatus

1. Bestätigen Sie mit dem zuständigen Mitarbeiter den Code des vorbereiteten Raumes.
2. Öffnen Sie die Raumstatuskontrolle auf der Karte.
3. Wählen Sie "Rein" oder "Schmutzig" nach dem tatsächlichen Zustand aus.
4. Warten Sie auf die Bestätigung und überprüfen Sie das aktualisierte Etikett.

Auf autorisierten Konten gibt es auch Optionen für leere, außer Betrieb und unter Renovierung. Vor der Aufzeichnung einer Wartung oder eines Fehlers überprüfen Sie bestehende Aufenthalte und zukünftige Reservierungen. Füllen Sie alle Gründe oder Bestätigungsfelder aus, die der Antrag verlangt.

## Wenn der Check-in blockiert ist

Der Antrag prüft die Reinigung, den aktiven Aufenthalt und die Verfügbarkeit von der tatsächlichen Ankunftszeit bis zur geplanten Abreise. Wenn eine Schmutzraumwarnung erscheint, überprüfen Sie den genauen Zimmer- oder Bettcode, aktualisieren und überprüfen Sie die aktuelle Lage.

Wenn das Problem weitergeht, folgen Sie den [Fehlerbehebungsmaßnahmen](../reference/troubleshooting.md).
