# Sprache, Design und persönliche Ansicht

Öffnen Sie Einstellungen und die entsprechenden Präferenzsteuerungen in der Schnittstelle.

![Persönliche Vorlieben](../images/settings.png)

## Anpassung der Schnittstelle

1. Öffnen Sie Einstellungen mit Ihrem eigenen Konto.
2. Wählen Sie ein Thema, Hintergrund und eine für Ihre Arbeit geeignete Schriftgröße aus.
3. Überprüfen Sie die Sprach- und Landes-/Währungsformatpräferenzen.
4. Passen Sie nach Bedarf Seitenüberschriften, Seitenleiste und Kalender-/aktuellen Gästeansichten an.
5. Bewegen Sie sich auf eine andere Seite und überprüfen Sie, ob die Präferenzen aufbewahrt sind.

Thema, Sprache und Erscheinung gehören dem angemeldeten Benutzer. Wenn ein Speicherfehler angezeigt wird, versuchen Sie es erneut in Einstellungen. Die Änderung der Sprache ändert nicht die registrierte Staatsangehörigkeit eines Gastes oder die ausgewählte Währung.

## Sprache auf der öffentlichen Website

Bei dem ersten Besuch wählt die Website automatisch die erste unterstützte Sprache aus den Sprachpräferenzen des Browsers aus. Eine vorherige manuelle Auswahl hat Priorität. Wenn keine Browsersprache unterstützt wird, wird Türkisch verwendet.

Das Haus, die Preise, die Bildschirmbilder und die Kontaktseiten bieten 60 Sprachen. Öffnen Sie das Sprachenmenü, suchen Sie nach Namen oder Code und wählen Sie eine Sprache aus. Die Pfeiltasten und Enter wählen eine Option aus; Escape schließt das Menü. Der Sprachnamen ist neben der Flagge angezeigt.

Die Übersetzung von öffentlichen Seiten bedeutet nicht, dass jeder Anwendungsbildschirm in gleichem Umfang übersetzt wird. Die fehlenden Katalogetiketten können auf Englisch erscheinen. Dokumentenvorlagen benötigen für jede Sprache separate Inhalte.

## Kleine Bildschirme

Verwenden Sie das mobile Menü, um auf dieselben Seiten zuzugreifen. Wenn nötig, durchlaufen Sie breite Tische. Schließen Sie kein Formular, bis Sie alle Felder und das Speicherresultat überprüft haben.
