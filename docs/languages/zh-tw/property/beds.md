# 實體床位與雙層床

實際床傢俱描述傢俱及其容量. 一個可以單獨預訂的床位是租房單位. 在設施或庫存目錄中選擇一張床並不創造一個可預訂的實際床傢俱空間.

## 定義一個床

1. 開放 實際床傢俱 定義從床管理在地板和房間的定義.
2. 選擇一個單床,雙床或一張床,設定為2,3或4層.
3. 檢查床號碼,房間和樓層.
4. 調整床型,物理結構,層次和尺寸數量.
5. 檢查每個空間的程式碼,位置和客人容量.
6. 複習 活動和單獨預訂,以及房間的租用模式.
7. 選擇儲存床.

選擇預設僅會填入表單欄位。 必須儲存後才會建立記錄。

## 床床的例子

雙層床包含上、下兩個實體床位。 請分別為下鋪和上鋪設定編號。 一張雙人床可以是一個床位，但可容納兩個人。 床位數量與可住人數不是同一指標。

## 從房間表格中新增床

房間建立/編輯表格允許您選擇床型和數量. 這些被新增到現有的實際床傢俱中. 要更換現有床,請編輯記錄,而不是新增另一個.

儲存後,檢查定義列表中的床位程式碼和 [3D 檢視](three-dimensional-view.md). 如果銷售板上沒有床,請檢查房間的租用方式,以及是否可以單獨預訂床.
