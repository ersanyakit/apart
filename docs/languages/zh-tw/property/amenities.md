# 設施與客房物品

在房間或酒店分支編輯表格中開啟 Amenity定義和功能欄位.

![設施和庫存](../images/amenities.png)

## 瞭解區別

- 一個設施表示是否有功能,例如浴室或房間裝置.
- 庫存記錄物理物品和數量.
- 實際的床傢俱描述住宿佈局和床位;在床管理中,單獨定義它們.

## 增加一個房間的功能

1. 在設施目錄中找到適當的類別和子組.
2. 編輯目標室.
3. 選擇適用的設施,並在庫存欄位中輸入實際數量.
4. 儲存表格.
5. 重新開放房間,檢查選項和數量是否保留.

在酒店分支層面分配共享設施,而不是讓它們在每個房間中顯示為可用. 一個共享熱水浴和一個私人室內熱水浴是不同的特點.

## 產品目錄,任務和庫存

標準目錄包含共享的定義. 授權使用者也可以使用特定商業定義. 一個物品在目錄中存在並不意味著它被分配給一個房間.

改變房間庫存數量不是倉庫庫庫存收據. 追蹤庫存收益和消費 [交易記錄](../finance/transactions.md) 和相關的庫存報告. 再利用現有的產品程式碼,而不是建立具有不同的拼寫的重複產品.
