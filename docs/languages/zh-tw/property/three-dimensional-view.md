# 3D 檢視

在酒店運營區開放3D檢視.

![3D 檢視](../images/property-3d.png)

## 探索酒店分公司

1. 選擇正確的酒店分支,然後開啟3D檢視.
2. 用現場內的地板按鍵來選擇地板.
3. 用地板分離和牆壁控制器揭示內部.
4. 選擇一個房間或床,檢查其資訊和住宿狀態.
5. 按照您的許可,在相關預訂螢幕上執行可用的操作.
6. 使用 Refresh 檢索最新狀態.

## 解釋現場

樓層,房間和床來自酒店分支的定義. 缺失或重疊的位置可以按計劃安排,室內的床可以自動定位. 這不是建築測量或地板圖的編輯工具. 探索現場不會改變儲存的座標.

預訂房間的客人在床上視覺分佈並不能創造實際的床分類. 沒有特定性別的客人使用中立字元;性別不會從名字中推斷.

## 一個單位失蹤或看起來錯誤

檢視酒店分支,地板,房間關係,實際的床傢俱定義和租用模式,然後重新整理. 作為房間佈局傢俱所選的圖形床不產生單獨的預訂單元.

如果瀏覽器無法開啟3D場景,請使用重試或基於文字的單元選擇. 您可以從 [房間狀態板](../operations/room-board.md).
