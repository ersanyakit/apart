# 旅客資料、搜尋與住宿紀錄

## 客人的詳細資訊

1. 在預訂表中開啟客人行,或使用已有的預訂中編輯客人.
2. 在指定欄位中輸入每個人的正確姓名,聯絡方式和身份資訊.
3. 從國家列表中選擇國籍. 你可以按國家名稱或程式碼搜尋.
4. 加入一個客人排列,以便後者加入.
5. 儲存和驗證預訂的客人名單.

不要假設兩個同名的人是同一個客人. 該應用程式不僅僅基於類似的名字的人員合併. 在房間/公寓預訂中,客人數和單獨租用床的容量限制是單獨的處理.

## 找到過去的逗留

1. 開放客人搜尋和歷史.
2. 設定日期和狀態過選器.
3. 用名字,身份資訊或電話號碼搜尋.
4. 開啟記錄,檢查逗留日期和單位分配.
5. 如果客人搬家,請檢查以前的單位和每個期間共住的人.

## 輸出列表

在使用Excel或PDF出口之前檢查您的過 ?? 器. 客戶出口不僅覆蓋可見頁面,覆蓋過度查詢, 覆蓋到10,000行. 為更大的結果,縮小日期範圍.

如果PDF生成失敗,請將錯誤傳送給管理員,而不是重複提交相同的請求. 伺服器的PDF生成元件可能需要注意.
