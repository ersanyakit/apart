# 語言、佈景主題與個人顯示偏好

開設設定和介面中的相關偏好控制.

![個人偏好](../images/settings.png)

## 調整介面

1. 用自己的帳戶開啟設定.
2. 選擇適合您的工作的主題,背景和字型尺寸.
3. 檢查語言和國家/貨幣格式偏好.
4. 根據需要調整頁面標題,側行和日曆/當前客人的檢視.
5. 轉到另一個頁面,並檢查是否保留了偏好.

主題,語言和外觀屬於登入使用者. 如果出現儲存錯誤,請從設定中重新嘗試. 改變語言不會改變客人的註冊國籍或轉換所選擇的貨幣.

## 公開網站上的語言

在首次訪問時,網站自動從瀏覽器的語言偏好中選擇首個支援的語言. 之前的手動選擇優先考慮. 如果沒有瀏覽器語言支援,則使用土耳其語.

家庭,價格,截圖和聯絡頁面提供60種語言. 開啟語言選單,按名字或程式碼搜尋,然後選擇語言. 在箭頭鍵上,選擇輸入選項;逃跑關閉選單. 語言名稱在旗子旁邊顯示.

公共頁面翻譯覆蓋並不意味著每個應用程式螢幕都被翻譯到相同的程度. 缺失的目錄標籤可能會出現在英語中. 檔案模板需要每個語言的單獨內容.

## 小螢幕

使用移動選單訪問相同的頁面. 需要時,在寬桌中滾動. 在檢查所有欄位和儲存結果之前,不要關閉表格.
