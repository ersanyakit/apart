# 員工、權限與操作紀錄

開放員工定義和系統日誌.

## 設定員工賬戶

1. 使用授權帳戶開啟員工定義.
2. 建立員工或編輯現有人員.
3. 完整的身份,登入和顯示的員工資訊.
4. 分配適合工作的角色和酒店分支機構.
5. 儲存並驗證員工可以用自己的卡登入正確的業務.

不要在多個員工之間分享一個賬戶. 個人賬戶確定誰執行了每個操作,並將偏好分開.

## 沒有選單或操作

檢查員工的角色和酒店分支機構的訪問. 單獨改變角色可能不會允許進入另一個酒店分公司. 更新或刪除員工賬戶可能會終止開放的會議,要求該人再次登入.

## 在系統日誌中找到更改

1. 開啟系統日誌.
2. 根據相關的時間,執行或記錄,使用可用的控制器進行過 ??.
3. 檢查運營總結,房間/酒店分公司和員工.
4. 比較前後的值,閱讀取消或翻新的理由.

失敗的操作不會建立成功變更記錄. 在舊記錄中缺失的細節沒有被重建. 記錄不是撤銷工具;透過相關的編輯或取消工作流進行糾正.
