# 第一天：準備您的住宿設施

本頁面是針對已經由技術團隊建立賬戶和業務的經理. 如果酒店分支已經在使用,請檢查現有記錄,而不是建立複製的房間或床.

## 建議設定順序

1. 開啟酒店分支的個人資料,並驗證商業和酒店分公司的資訊.
2. 在地板和房間定義中,建立地板並分配房間和公寓.
3. 每個房間,請選擇是否將整個房間或其單獨的床單租.
4. 定義實際的床傢俱. 對於旅館,請檢查床位水平和提供的床位.
5. 在相關編輯表格中填寫房間和酒店分支設施和庫存數量.
6. 在員工定義中審查員工角色和酒店分支機構訪問.
7. 準備業務資訊和所需的文件模板語言版本.
8. 在房間狀態委員會上檢視目前的清潔和維護狀態.

## 在第一次預訂之前

| 檢查 | 預期結果 |
| --- | --- |
| 酒店分店和樓層 | 房間出現在正確的酒店分支和樓下. |
| 租金方式 | 您可以選擇您打算租來的房間或床. |
| 清潔 | 機器已準備好,並標記為清潔. |
| 日期 | 抵達和出發是正確的,沒有矛盾的保留. |
| 工作人員 | 每個員工可以使用自己的帳戶訪問所需的頁面. |

在培訓過程中,請使用經理指定的測試環境,以免取樣交易與現場業務記錄混合.

繼續使用 [酒店分支結構](../property/structure.md) 和 [預訂的建立](../operations/reservations.md).
