# 報表目錄

該申請提供了57份報告. 首先確定您想回答的問題,然後選擇相關的報告和日期,酒店分支和貨幣過選器.

## 我應該從哪個報告開始?

| 問題 | 報告 |
| --- | --- |
| 在商業中發生了什麼? | 管理概述 |
| 為什麼收入和收到的錢是不同的? | 每日收入和支付 |
| 使用哪些支付方式? | 付款方式 |
| 房間或床是如何使用的? | 每日佔用,床佔用或公寓佔用 |
| 接下來的幾天有多忙? | 使用的房間的未來比例 |
| 在哪裡造成的成本? | 單元支出和利 ?? |
| 哪些平衡仍然是顯著的? | 收取和付款 |
| 哪些任務仍然存在? | 缺陷和維護,清潔或完成任務 |

## 瞭解資料來源

預訂,逗留和單位移動報告使用這些申請記錄. 投訴,維護,任務,轉班,庫存,合同,競爭對手價格和證券存款需要相關的交易記錄. 競爭對手的價格和評價不會自動從外部平臺中獲得. 報告顯示了手動輸入的資料,並記錄了其來源.

看看 [交易記錄](transactions.md) 輸入源資料和 [使用報告](reports.md) 對計算和出口規則.
