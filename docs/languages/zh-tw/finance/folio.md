# 客房帳單與附加服務

在客房卡片開啟「帳單」，或在訂房明細選擇「客房帳單／新增服務」。

帳單整合該筆訂房的住宿費、服務費與付款紀錄。不同幣別的合計請分別檢視。

## 新增附加服務

1. 開啟正確訂房的客房帳單。
2. 輸入或選擇服務名稱與類別。
3. 指定數量、單價及幣別。
4. 補充必要說明並核對總額。
5. 儲存後，確認服務已列入帳單明細。

例如：兩份早餐，每份 150 TRY，會產生 300 TRY 的應收服務費。這不代表已向旅客收取 300 TRY。實際收款須另外登記。

## 更正錯誤的服務費用

使用取消服務的操作並填寫原因，之後確認帳單中有取消紀錄。不要只修改說明，或另增負數服務來代替正式取消。

櫃檯員工只能為有權存取的住宿設施中尚未結束的訂房新增服務。訂房已結束或不在權限範圍內時，請聯絡主管。

## 退房前

補登最後的服務，核對已收款項及退款。其他員工修改紀錄後，請重新整理帳單。退房時確認未結餘額不會將其清除。
