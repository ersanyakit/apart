## 如何使用本指南

根據您的職位和您可以訪問的酒店分支機構,有些選擇可能無法獲得. 在做任何改變之前,請檢視所選的酒店和酒店分支.

這些截圖顯示了Mavi Avlu Otel的真實應用介面與虛構資料. 數量,日期和客人的名字是例子. 在做出決定時,在自己的應用程式中使用當前的資訊.

截圖保留了原始的土耳其介面. 該指南解釋了選定的文件語言中的選單名稱和操作;應用程式仍然可能會顯示土耳其標籤. 每個主題都描述了步驟,預期結果和相關指南. 在所有語言版本中,檔名稱和連結都保持在英語中.
