# 櫃檯記事與交接班

在酒店運營部分開啟接待說明或使用上方的通知按鍵.

![接待通知](../images/notes.png)

## 建立任務

1. 確認所選擇的酒店分支.
2. 在板上開啟新筆記動作.
3. 寫一個簡短的行動導向標題,如"檢視203房間的抵達準備".
4. 新增所需的工作,房間資訊和下一輪需要的細節.
5. 選擇狀態和優先順序,然後儲存.
6. 確認該說明在正確的列中出現.

## 更新進展

董事會必須做,正在進行和完成的列. 拖動一個卡片或使用其狀態選單移動它. 狀態選單也適合觸控和鍵盤使用.

移動卡到完成後才完成工作. 在日記板上不再需要的檔案記錄,並在必要時恢復它們. 存檔不是永久刪除.

## 如果兩個人編輯相同的筆記

如果由於另一個員工更改了筆記,因此被拒絕存款,請重新開啟筆記,閱讀當前版本,然後再次申請更改. 在開放時和你回到視窗時,板塊定期更新. 如果卡不可見,請使用搜尋和載入更多.

在酒店分店內共享筆記. 填寫一個筆記不會自動更新房間清潔,預訂或財務記錄. 在相應的螢幕上執行實際操作.
