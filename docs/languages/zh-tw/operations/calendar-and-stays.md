# 住宿行事曆與在住旅客

## 保持日曆

![保持日曆](../images/calendar.png)

1. 從選單中開啟逗留日曆.
2. 導航到所需的時間,然後選擇每天,每週或每月的檢視.
3. 透過搜尋和狀態過選器縮小結果.
4. 選擇一個住宿,檢查客人,日期,筆記和每晚的價格.
5. 在改變時間段或過 ?? 後,確認結果與新選擇匹配.

歐盟對歐盟的歐盟和歐盟的合作伙伴關係 在瀏覽器的列印對話方塊中開啟可見的日曆. 選擇一個PDF目的地,以儲存為檔案.

## 目前的客人

![目前的客人](../images/stays.png)

使用當前客戶來追蹤正在進行的逗留和計劃出發. 在頁面標題中,搜尋,地板選擇和開始日期. 如果這些控制器隱藏,請擴大標題. 根據需要調整時間導航,狀態,日數和空單元控制.

區分計劃日期與實際抵達和出發時間. 早期登記和房間搬遷可能會使實際搬遷與計劃期間不同.

在假設記錄消失之前, 清除酒店分支, 日期,樓層,狀態和搜尋過濾器, 再檢查.
