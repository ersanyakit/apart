# 換房、互換房源與取消訂房

## 移送客人到另一個單位

1. 開啟預訂,然後選擇更換室.
2. 選擇移動操作.
3. 選擇可用的目的地房間,公寓或床.
4. 檢查客人,日期和目的地,然後確認.
5. 檢查客人是否出現在新單位的卡上.

對於已登記的客人來說,此舉從運營時間開始生效. 在前一個單位度過的時間仍然是歷史的. 不要試圖透過手動更改單元程式碼來重寫歷史.

## 交換兩個預訂單位

1. 換衣室開放,一個預訂.
2. 選擇交換操作.
3. 選擇正確的第二次預訂.
4. 檢查兩個客人,兩個單位和他們的日期.
5. 後面確認和檢查兩個預訂.

兩方都被共同驗證. 可用性或客人容量限制可能會阻礙交換. 不要建立兩個新的預訂,以繞過錯誤.

## 在登記前取消預訂

1. 選擇正確的預訂.
2. 開放 取消預訂.
3. 填寫確認和任何必要的理由.
4. 檢查更新的預訂狀態.
5. 如果收到錢, [金融交易記錄](../finance/transactions.md).

對於已經登記的客人,請使用登記,而不是取消預訂. 取消不會透過銀行或支付終端自動退款.
