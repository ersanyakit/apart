# 入住、提前入住與退房

## 為現有訂房辦理入住

1. 在訂房清單或客房卡片中找到正確紀錄。
2. 核對旅客姓名、房源編號及預定入住、離店日期。
3. 確認旅客已抵達，且客房已準備就緒。
4. 在訂房清單選擇「入住」或「提前入住」。客房卡片選單也提供現有訂房的對應操作。核對資訊後確認。
5. 確認訂房已變為入住狀態，並出現在「在住旅客」清單。

儲存訂房不等於完成入住。建立新的住宿紀錄前，請先確認旅客是否已有訂房。

## 旅客提前抵達

使用原有訂房辦理提前入住。房源必須從實際抵達時間起至預定離店時間為止皆可使用；系統也會檢查清潔狀態及其他住宿紀錄。

例如：原定晚上抵達的旅客中午就到了。若客房已備妥且沒有衝突的住宿，使用同一筆訂房辦理入住。預定抵達時間會保留，實際入住時間另外記錄。不要只為通過入住檢查而將預定日期往前改。

若出現「未清潔」提示，請核對房源編號與最新狀態。已備妥的客房成功儲存為「乾淨」後仍無法入住時，請參閱[疑難排解](../reference/troubleshooting.md)。

## 辦理退房

1. 從在住旅客的客房卡片或訂房紀錄開啟退房操作。
2. 在退房前帳單中，分別檢視各幣別的帳戶摘要。
3. 核對住宿費、附加服務、已收款項、退款與押金。
4. 離店前補登遺漏的服務。若其他員工修改過紀錄，請重新整理帳單。
5. 若仍有未結費用、退款或押金餘額，先檢查這些項目，再確認退房後保留餘額。
6. 選擇「完成退房」。
7. 核對已完成的住宿紀錄、實際離店時間及更新後的房況。

退房不會清除未結餘額。產生文件也不會自動登記收款。請另外確認款項確實收到且已正確記錄。
