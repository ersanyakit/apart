# 房況看板與清潔管理

在酒店運營下開啟房間狀態表.

![房間狀態板](../images/board.png)

## 閱讀一個房間卡

閱讀單位程式碼,客人或預訂資訊以及抵達/出發日期. 佔用和清潔是不同的:一個清潔的房間可能被佔用,一個空的房間仍然需要清潔. 閱讀狀態標籤,而不是隻依賴顏色.

## 找一個單位

1. 確認所選擇的酒店分支.
2. 根據需要調整搜尋,地板和日期過選器.
3. 檢視卡上的單位程式碼.
4. 開啟卡的動作選單. 在桌面上,右鍵選單還提供預訂,客人,狀態和文件操作.

在檢視另一個日期時,不要把該日期的預訂狀態和當前的清潔狀態混為一談.

## 改變清潔狀態

1. 確認準備的房間程式碼與負責人員.
2. 開啟卡上的房間狀態控制.
3. 根據實際情況,選擇清潔或髒.
4. 等待確認,然後檢查更新的標籤.

授權的賬戶還有空置,不正常和改造的選項. 在記錄維護或故障之前,請檢查現有的住宿和即將到來的預訂. 填寫申請所要求的理由或確認欄位.

## 如果登入被阻止

申請檢查清潔,活躍逗留和可用性,從實際到達時間到計劃出發. 如果出現汙房警告,請檢視房間或床的確切程式碼,更新並驗證當前狀態.

如果問題繼續,請按照 [解決問題步驟](../reference/troubleshooting.md).
