# INTERACTIVEOTEL User Guide

Manage daily operations at your hotel, aparthotel, guesthouse, short-term rental apartment or hostel, step by step. This guide is for reception staff, property managers and business owners. No technical setup knowledge is required.

![INTERACTIVEOTEL](images/hero.png)

## How to use this guide

Some options may be unavailable depending on your role and the properties you can access. Before making changes, check the selected hotel and property.

The screenshots show the real application interface with fictional data for Mavi Avlu Otel. Amounts, dates and guest names are examples. Use the current information in your own application when making decisions.

The screenshots retain their original Turkish interface. This guide explains menu names and actions in the selected documentation language; the application may still display Turkish labels. Each topic describes the steps, the expected result and related guides. File names and links remain in English across all language editions.
