# Check-in, early check-in and check-out

## Check in an existing reservation

1. Find the correct record in the reservation list or room card.
2. Verify the guest name, unit code and planned dates.
3. Confirm that the guests have arrived and the unit is ready.
4. Use Check-in or Early check-in in the reservation list. The room card menu offers corresponding actions for checking in the existing reservation. Review the information and confirm.
5. Confirm that the reservation is checked in and appears in the Current Guests list.

Saving a reservation does not check the guest in. Before creating a new stay, make sure the guest does not already have a reservation.

## A guest arrives early

Use the existing reservation for early check-in. The unit must be available from the actual arrival time to the planned departure; cleaning and other stay checks also apply.

Example: a guest expected in the evening arrives at noon. If the room is ready and has no conflicting stay, check in the same reservation. The planned arrival is preserved and the actual arrival is recorded separately. Do not move the planned date backwards just to enable check-in.

If a dirty-room warning appears, check the unit code and latest status. If a genuinely prepared room is correctly saved as Clean but check-in still fails, follow [troubleshooting](../reference/troubleshooting.md).

## Check out

1. Open Check-out operations from the current guest's room card or reservation.
2. In the pre-check-out folio, read the account summary for every currency.
3. Review accommodation charges, extra services, payments received, refunds and security deposits.
4. Add missing services before departure. If another staff member has made changes, refresh the folio.
5. If outstanding charges, refunds or deposits remain, review them before accepting the acknowledgement that these balances will be retained.
6. Select Complete check-out.
7. Verify the completed reservation, actual departure time and updated room status.

Check-out does not erase outstanding balances. Creating a document does not record a payment automatically. Confirm separately that payment was actually received and recorded correctly.
