# Stay Calendar and Current Guests

## Stay Calendar

![Stay Calendar](../images/calendar.png)

1. Open Stay Calendar from the menu.
2. Navigate to the required period and choose the daily, weekly or monthly view.
3. Narrow the results with search and status filters.
4. Select a stay to inspect guests, dates, notes and the nightly price.
5. After changing the period or filters, confirm that the results match the new selection.

CSV export contains filtered unit allocations for the selected period. Print / PDF opens the visible calendar in the browser's print dialog. Select a PDF destination to save it as a file.

## Current Guests

![Current Guests](../images/stays.png)

Use Current Guests to track ongoing stays and planned departures. Search, floor selection and the start date are in the page header. Expand the header if those controls are hidden. Adjust period navigation, status, number of days and empty-unit controls as needed.

Distinguish planned dates from actual arrival and departure times. Early check-in and room moves can make actual movements differ from the planned period.

Before assuming a record has disappeared, clear property, date, floor, status and search filters and check again.
