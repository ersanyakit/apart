# Reception notes and shift handover

Open Reception Notes under Hotel Operations or use the notification button at the top.

![Reception Notes](../images/notes.png)

## Create a task

1. Confirm the selected property.
2. Open the new-note action on the board.
3. Write a short action-oriented title, such as “Check arrival preparations for room 203”.
4. Add the work required, room information and details the next shift needs.
5. Select status and priority, then save.
6. Confirm that the note appears in the correct column.

## Update progress

The board has To do, In progress and Completed columns. Drag a card or use its status menu to move it. The status menu is also suitable for touch and keyboard use.

Move the card to Completed only when the work is actually finished. Archive notes no longer needed on the daily board and restore them when necessary. Archiving is not permanent deletion.

## If two people edit the same note

If saving is rejected because another employee changed the note, reopen it, read the current version and apply your change again. The board refreshes periodically while open and when you return to the window. Use search and load more if a card is not visible.

Notes are shared within the property. Completing a note does not automatically update room cleaning, reservations or financial records. Also perform the actual operation in its corresponding screen.
