# Troubleshooting

## The room is clean but check-in says it is dirty

1. Compare the unit code in the error with the card. It may refer to another property or a linked bed.
2. Confirm the property and reservation.
3. Refresh and check the current cleaning label.
4. If the room is actually prepared, verify that saving Clean succeeded.
5. For early check-in, check for another stay between actual arrival and planned departure.
6. If the error persists, give your manager the unit code, planned dates, operation time and exact error text.

Do not duplicate the reservation or accidentally close another stay to bypass the error.

## An empty room cannot be selected

Check the full date range, rental mode, sales availability and parent/child unit reservations. Check for an active guest whose departure is overdue. A room being empty today does not mean it is available throughout the selected period.

## A reservation or note is missing

First check property, date, status, floor and search filters. For notes, also check archived items and load more. If the record is still missing, review notifications and, if authorized, System Logs.

## A report total differs from what I expected

Check the date range, currency, property and report type. Distinguish revenue from payments received and expenses from outgoing payments. Make sure an old advance payment was not recorded twice. Unallocated expenses affect unit-level comparisons; current physical definitions affect occupancy calculations.

## The check-out button is disabled

Wait for the folio to load and for service saving to finish. Confirm that the reservation is still checked in. If outstanding-balance acknowledgement is required, review the balances before accepting it.

## 3D View does not open

Use the retry option. If the browser cannot display the scene, use text-based unit selection or the Room Status Board. If only one property is affected, inspect its room and physical bed definitions.

## A document language is empty or PDF generation fails

Check that the selected language has a template title and body. For PDF errors, the administrator may need to check the server-side PDF component. Calendar/report browser printing is different from guest/document PDFs generated on the server.

## What should I include in a support request?

Provide the page name, property and unit code, operation time, expected result, actual result and error text. Hide unnecessary guest identity, contact and payment information in screenshots. Do not include your password.
