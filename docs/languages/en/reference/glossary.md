# Glossary

| Term | Meaning |
| --- | --- |
| Hotel / business | The main business to which properties and permissions belong. |
| Property / branch | The location where operations are performed; records are scoped to the selected property. |
| Unit | An apartment, room, dormitory or bed in the rental structure. |
| Physical bed | Bed or bunk furniture; not necessarily a separately rentable unit. |
| Bed space | A place or level in the physical structure; guest capacity is defined separately. |
| Confirmed reservation | A saved reservation that has not checked in. |
| Planned arrival/departure | The dates expected for the reservation. |
| Actual arrival/departure | The times when check-in and check-out actually occur. |
| Allocation | The unit occupied by a reservation during a particular time interval. |
| Folio | A reservation's account summary of charges, services and payment movements. |
| Accrued revenue | The value of service provided in a period; payment may arrive on another date. |
| Payment received | Money received by the business. |
| Expense / outgoing payment | An expense is an incurred cost; a payment is money leaving the business. |
| Security deposit | A deposit subject to return conditions; not accommodation revenue. |
| Unit-night | One unit's use or sale for one night. |
| Physical occupancy | Used unit-nights compared with physical capacity. |
| Sellable occupancy | Usage relative to capacity available for sale. |
| ADR | Revenue divided by nights sold, for the same product type. |
| RevPAR | Revenue divided by nights available for sale, for the same product type. |
| Operating result | Revenue less operating expenses in the report; not accounting net profit. |
| Archive | Removal from daily view, not permanent deletion. |

Interpret each status label together with the record's date and type. See [Using reports](../finance/reports.md) for calculation details.
