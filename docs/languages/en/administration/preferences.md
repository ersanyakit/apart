# Language, theme and personal appearance

Open Settings and the relevant preference controls in the interface.

![Personal preferences](../images/settings.png)

## Adjust the interface

1. Open Settings with your own account.
2. Select a theme, background and font size suitable for your work.
3. Check language and country/currency-format preferences.
4. Adjust page headers, sidebar and calendar/current-guest views as needed.
5. Move to another page and verify that the preferences are retained.

Theme, language and appearance belong to the signed-in user. If a save error appears, retry from Settings. Changing the language does not change a guest's recorded nationality or convert the selected currency.

## Language on the public website

On the first visit, the website automatically selects the first supported language from the browser's language preferences. A previous manual selection takes priority. If no browser language is supported, Turkish is used.

The home, pricing, screenshots and contact pages offer 60 languages. Open the language menu, search by name or code and select a language. Arrow keys and Enter select an option; Escape closes the menu. The language name is shown next to the flag.

Public-page translation coverage does not imply that every application screen is translated to the same extent. Missing catalog labels may appear in English. Document templates require separate content for each language.

## Small screens

Use the mobile menu to access the same pages. Scroll within wide tables when needed. Do not close a form until you have checked all fields and the save result.
