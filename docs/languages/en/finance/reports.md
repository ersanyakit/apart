# Use and interpret reports

Open Reports in the left menu. Reports are available to administrator and business-management roles, within their property access scope.

![Management overview](../images/report-dashboard.png)

## Prepare a report

1. Choose the report you need. Start with Management overview for a general picture.
2. Set the start and end dates. The end date is included.
3. Check property and currency selections and narrow any other filters.
4. Read summary cards, charts and the table together.
5. If there are no results, first check the period and filters.

A query supports up to 366 days. If the data-volume limit is reached, shorten the period and create separate reports. Report dates use the Istanbul time zone.

## Revenue and money received are different

Accommodation revenue relates to nights when the service is provided. Payments received relate to when money arrives. Money received today for next month's stay does not have to appear on the same date in both measures.

![Daily revenue and payments received](../images/report-revenue.png)

Currencies are neither automatically converted nor combined into one total. Operating result is not accounting net profit after tax and financing. Unit-level results include only expenses assigned to the unit; inspect unallocated expenses separately.

## Read occupancy rates

Physical capacity and sellable capacity use different denominators. Units closed to sales can affect the result. Historical capacity changes were not stored, so historical occupancy calculations rely on current physical definitions. Bed-space count and guest capacity are different measures.

![Daily occupancy](../images/report-occupancy.png)

## Review payment methods

Compare credit card, bank transfer, cash and other payment channels. Read receipts and refunds separately. Check dates and currency before interpreting the chart.

![Payment methods](../images/report-payments.png)

## Export and prepare report documents

CSV includes all rows in the selected report. Prepare document creates an editable report using the current filters. Add explanations and download HTML or print to PDF in the browser. Editable documents contain up to 1,000 table rows. If rows are omitted, use CSV for the complete dataset.

Choose a report from the [57-report catalog](report-catalog.md). Complete missing source data using [transaction records](transactions.md).
