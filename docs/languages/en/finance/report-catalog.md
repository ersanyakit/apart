# Report catalog

The application provides 57 reports. First identify the question you want to answer, then choose the relevant report and set date, property and currency filters.

## Which report should I start with?

| Question | Report |
| --- | --- |
| What is happening in the business? | Management overview |
| Why do revenue and money received differ? | Daily revenue and payments |
| Which payment methods are used? | Payment methods |
| How are rooms or beds being used? | Daily occupancy, Bed occupancy or Apartment occupancy |
| How busy will the coming days be? | Future occupancy |
| Where were costs incurred? | Expense breakdown and Profitability by unit |
| Which balances remain outstanding? | Receivables and payables |
| Which tasks remain open? | Faults and maintenance, Cleaning or Task completion |

## Understand the data source

Reservation, stay and unit-movement reports use those application records. Complaints, maintenance, tasks, shifts, stock, contracts, competitor prices and security deposits require the relevant transaction records. Competitor prices and reviews are not fetched automatically from external platforms. The reports show manually entered data with its recorded source.

See [transaction records](transactions.md) to enter source data and [Using reports](reports.md) for calculations and export rules.
