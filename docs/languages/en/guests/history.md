# Guest details, search and history

## Complete guest details

1. Open guest rows in the reservation form or use Edit guests on an existing reservation.
2. Enter each person's correct name, contact and identity details in the designated fields.
3. Select nationality from the country list. You can search by country name or code.
4. Add a guest row for anyone joining the stay later.
5. Save and verify the reservation's guest list.

Do not assume that two people with the same name are the same guest. The application does not merge people based only on similar names. Guest counts in room/apartment reservations and capacity limits for individually rented beds are handled separately.

## Find past stays

1. Open Guest Search and History.
2. Set date and status filters.
3. Search by name, identity information or telephone number.
4. Open the record and inspect stay dates and unit allocations.
5. If the guest moved, check previous units and the people staying together during each period.

## Export a list

Check your filters before using Excel or PDF export. Guest export covers the filtered query, not just the visible page, up to 10,000 rows. Narrow the date range for larger results.

If PDF generation fails, send the error to your administrator instead of repeatedly submitting the same request. The server's PDF generation component may need attention.
