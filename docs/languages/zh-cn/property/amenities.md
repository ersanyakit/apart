# 设施与客房物品

在房间或酒店分支编辑表格中打开 Amenity定义和功能字段.

![设施和库存](../images/amenities.png)

## 了解区别

- 一个设施表示是否有功能,例如浴室或房间设备.
- 库存记录物理物品和数量.
- 实际的床家具描述住宿布局和床位;在床管理中,单独定义它们.

## 增加一个房间的功能

1. 在设施目录中找到适当的类别和子组.
2. 编辑目标室.
3. 选择适用的设施,并在库存字段中输入实际数量.
4. 保存表格.
5. 重新开放房间,检查选项和数量是否保留.

在酒店分支层面分配共享设施,而不是让它们在每个房间中显示为可用. 一个共享热水浴和一个私人室内热水浴是不同的特点.

## 产品目录,任务和库存

标准目录包含共享的定义. 授权用户也可以使用特定商业定义. 一个物品在目录中存在并不意味着它被分配给一个房间.

改变房间库存数量不是仓库库库存收据. 追踪库存收益和消费 [交易记录](../finance/transactions.md) 和相关的库存报告. 再利用现有的产品代码,而不是创建具有不同的拼写的重复产品.
