# 3D 视图

在酒店运营区开放3D视图.

![3D 视图](../images/property-3d.png)

## 探索酒店分公司

1. 选择正确的酒店分支,然后打开3D视图.
2. 用现场内的地板按键来选择地板.
3. 用地板分离和墙壁控制器揭示内部.
4. 选择一个房间或床,检查其信息和住宿状态.
5. 按照您的许可,在相关预订屏幕上执行可用的操作.
6. 使用 Refresh 检索最新状态.

## 解释现场

楼层,房间和床来自酒店分支的定义. 缺失或重叠的位置可以按计划安排,室内的床可以自动定位. 这不是建筑测量或地板图的编辑工具. 探索现场不会改变保存的坐标.

预订房间的客人在床上视觉分布并不能创造实际的床分类. 没有特定性别的客人使用中立字符;性别不会从名字中推断.

## 一个单位失踪或看起来错误

查看酒店分支,地板,房间关系,实际的床家具定义和租用模式,然后刷新. 作为房间布局家具所选的图形床不产生单独的预订单元.

如果浏览器无法打开3D场景,请使用重试或基于文本的单元选择. 您可以从 [房间状态板](../operations/room-board.md).
