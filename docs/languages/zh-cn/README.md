# INTERACTIVEOTEL 用户指南

管理您的酒店,公寓,客房,短期租屋或宿舍的日常运营,一步一步. 这本指南适用于接待员工,酒店分店经理和企业主. 没有技术设置知识.

## 如何使用本指南

根据您的职位和您可以访问的酒店分支机构,有些选择可能无法获得. 在做任何改变之前,请查看所选的酒店和酒店分支.

这些截图显示了Mavi Avlu Otel的真实应用界面与虚构数据. 数量,日期和客人的名字是例子. 在做出决定时,在自己的应用程序中使用当前的信息.

截图保留了原始的土耳其接口. 该指南解释了选定的文档语言中的菜单名称和操作;应用程序仍然可能会显示土耳其标签. 每个主题都描述了步骤,预期结果和相关指南. 在所有语言版本中,文件名称和链接都保持在英语中.
