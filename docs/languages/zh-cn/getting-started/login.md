# 登录并了解界面

## 在你开始之前

询问您的管理员申请地址,您应该访问的业务以及个人账户的身份证. 在本指南中没有共享的演示密码. 用你的业务分配给你的账户.

## 登录

1. 打开申请地址. 如果您在公共网站上,请使用登录链接.
2. 选择你要工作的酒店.
3. 选择自己的员工卡.
4. 输入密码,然后按登录按键.
5. 在下面的屏幕上查看酒店和酒店分支的名称. 如果您在多个酒店分公司工作,请在创建记录之前选择正确的分公司.

如果您的员工卡缺失,请先查看所选的业务. 如果它仍然缺失,请请你的经理查看你的账户和酒店分支机构. 不要使用其他员工的卡来绕过密码错误.

## 接口的部分

- 左侧菜单打开房间状态表,逗留日历,预订和其他工作页面.
- 酒店和酒店分支选择器确定您的工作业务背景.
- 页面标题包含搜索,过 ?? 和操作. 扩大一个崩塌的头条,以揭示隐藏的控制.
- 右上方的通知报告成功保存或错误. 在表格内表示缺失表格的字段.
- 在小屏幕上,打开移动导航菜单,访问相同的工作页面.

保存后,请检查成功通知和更新列表. 如果出现网络错误,请在再次提交相同操作之前检查是否创建了记录.
