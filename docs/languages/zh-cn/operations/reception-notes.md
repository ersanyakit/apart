# 前台便笺与交接班

在酒店运营部分打开接待说明或使用上方的通知按键.

![接待通知](../images/notes.png)

## 创建任务

1. 确认所选择的酒店分支.
2. 在板上打开新笔记动作.
3. 写一个简短的行动导向标题,如"查看203房间的抵达准备".
4. 添加所需的工作,房间信息和下一轮需要的细节.
5. 选择状态和优先级,然后保存.
6. 确认该说明在正确的列中出现.

## 更新进展

董事会必须做,正在进行和完成的列. 拖动一个卡片或使用其状态菜单移动它. 状态菜单也适合触摸和键盘使用.

移动卡到完成后才完成工作. 在日记板上不再需要的档案记录,并在必要时恢复它们. 存档不是永久删除.

## 如果两个人编辑相同的笔记

如果由于另一个员工更改了笔记,因此被拒绝存款,请重新打开笔记,阅读当前版本,然后再次申请更改. 在开放时和你回到窗口时,板块定期更新. 如果卡不可见,请使用搜索和加载更多.

在酒店分店内共享笔记. 填写一个笔记不会自动更新房间清洁,预订或财务记录. 在相应的屏幕上执行实际操作.
