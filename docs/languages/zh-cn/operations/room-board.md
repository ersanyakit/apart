# 房态看板与清洁管理

在酒店运营下打开房间状态表.

![房间状态板](../images/board.png)

## 阅读一个房间卡

阅读单位代码,客人或预订信息以及抵达/出发日期. 占用和清洁是不同的:一个清洁的房间可能被占用,一个空的房间仍然需要清洁. 阅读状态标签,而不是只依赖颜色.

## 找一个单位

1. 确认所选择的酒店分支.
2. 根据需要调整搜索,地板和日期过选器.
3. 查看卡上的单位代码.
4. 打开卡的动作菜单. 在桌面上,右键菜单还提供预订,客人,状态和文档操作.

在查看另一个日期时,不要把该日期的预订状态和当前的清洁状态混为一谈.

## 改变清洁状态

1. 确认准备的房间代码与负责人员.
2. 打开卡上的房间状态控制.
3. 根据实际情况,选择清洁或脏.
4. 等待确认,然后检查更新的标签.

授权的账户还有空置,不正常和改造的选项. 在记录维护或故障之前,请检查现有的住宿和即将到来的预订. 填写申请所要求的理由或确认字段.

## 如果登录被阻止

申请检查清洁,活跃逗留和可用性,从实际到达时间到计划出发. 如果出现污房警告,请查看房间或床的确切代码,更新并验证当前状态.

如果问题继续,请按照 [解决问题步骤](../reference/troubleshooting.md).
