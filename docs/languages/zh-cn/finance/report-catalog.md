# 报表目录

该申请提供了57份报告. 首先确定您想回答的问题,然后选择相关的报告和日期,酒店分支和货币过选器.

## 我应该从哪个报告开始?

| 问题 | 报告 |
| --- | --- |
| 在商业中发生了什么? | 管理概况 |
| 为什么收入和收到的钱是不同的? | 每日收入和支付 |
| 使用哪些支付方式? | 支付方式 |
| 房间或床是如何使用的? | 每日占用,床占用或公寓占用 |
| 接下来的几天有多忙? | 未来使用的房间比例 |
| 在哪里造成的成本? | 单元支出和利 ?? |
| 哪些平衡仍然是显著的? | 收取和支付 |
| 哪些任务仍然存在? | 缺陷和维护,清洁或完成任务 |

## 了解数据源

预订,逗留和单位移动报告使用这些申请记录. 投诉,维护,任务,转班,库存,合同,竞争对手价格和证券存款需要相关的交易记录. 竞争对手的价格和评价不会自动从外部平台中获得. 报告显示了手动输入的数据,并记录了其来源.

看看 [交易记录](transactions.md) 输入源数据和 [使用报告](reports.md) 对计算和出口规则.
