# 财务与运营记录

在相关报告屏幕中使用记录交易. 可用的选项取决于报告和您的帐户权限.

## 选择正确的记录类型

| 事件 | 使用记录 |
| --- | --- |
| 客人收到钱 | 收到的付款,包括日期,金额,货币和付款方式. |
| 业务成本发生 | 费用,包括类别,相关人/单位和解释. |
| 现有债务已偿还 | 实际付款，与登记费用分开记录。 |
| 钱将或已经归还给客人 | 退款，状态为待处理或已完成。 |
| 已收到保证金 | 押金记录，不应计为住宿收入。 |
| 发生故障,任务,投诉或库存移动 | 相关的运营记录,包含源,状态和所需的字段. |

## 创建记录

1. 打开正确的报告和酒店分支,然后选择记录交易.
2. 选择操作类型和日期.
3. 选择记录类型所要求的预订,单位,员工或其他当事人.
4. 对于货币记录,如有所需的全部金额,货币和支付方式.
5. 如有必要,添加账户或班级参考,期限,状态和笔记.
6. 检查确认步骤,然后保存.
7. 使用相同的日期,酒店分支和货币查看报告.

## 工资,租金和公用事业费用

对于员工工资,请选择员工. 在租金费用方面,请指定房东. 对于公用事业费用,请选择正确的类型,如电力,水,互联网或天然气. 记录日期决定了报告期;您可以提到记录中所涵盖的月份.

登记费用并不代表已经付款。 工资页面不会自动计算薪资。 使用费用分类来查看总额;不要再次输入相同的费用.

## 账户和班级匹配

为了结算开放的账户,酒店分支,货币和参考必须匹配. 开放,关闭和相关现金流动时使用相同的轮换参考. 选择相同的产品代码,以查看库存收据和消费.

不要再把旧的预付作为新收据. 单独创建文件不是一个金融交易. 如果维护费用或损害费用也必须作为业务费用,请单独记录费用,并检查是否重复.
