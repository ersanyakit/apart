# 客房账单与附加服务

在客房卡片中打开“账单”，或在预订详情中选择“客房账单／添加服务”。

账单集中显示该预订的住宿费用、服务费用和付款记录。不同货币的合计应分别查看。

## 添加附加服务

1. 打开正确预订的客房账单。
2. 输入或选择服务名称和类别。
3. 指定数量、单价和货币。
4. 添加必要说明并核对总额。
5. 保存后，确认服务已出现在账单明细中。

例如：两份早餐，每份 150 TRY，会产生 300 TRY 的应收服务费。这不表示已经向客人收取了 300 TRY。实际收款需要另行登记。

## 更正错误的服务费用

使用服务取消操作并填写原因，然后检查取消记录是否出现在账单中。不要仅修改说明或另加一笔负数服务来代替正式取消。

前台员工只能为有权访问的住宿设施中尚未结束的预订添加服务。如果预订已关闭或不在访问范围内，请联系经理。

## 退房前

补记最后的服务，核对已收款项和退款。如其他员工修改过记录，请刷新账单。退房时确认未结余额并不会将其清除。
