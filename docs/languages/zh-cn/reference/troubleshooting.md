# 故障排查

## 房间是干净的,但检查显示它很脏.

1. 错误中的单元代码与卡进行比较. 它可能是指另一个酒店分公司或连接床.
2. 确认酒店分店和预订.
3. 刷新和检查目前的清洁标签.
4. 如果房间实际上已经准备好, 检查清洁是否成功.
5. 在实际到达和计划出发期间,请查看是否有其次停留.
6. 如果错误仍然存在,请给管理员提供单位代码,计划日期,操作时间和准确的错误文本.

不要重复预订或意外关闭另一个逗留,以绕过错误.

## 没有空房可以选择

查看完整的日期范围,租金模式,销售可用性和父母/孩子单位预订. 检查一个有时间离开的活动客人. 今天的空房并不意味着它可以在选择的时间内使用.

## 没有预订或留言

首先检查酒店分支,日期,状态,地板和搜索过选器. 查看存档的内容,并加载更多. 如果记录仍然缺失,请查看通知,如果允许,则查看系统日志.

## 报告总数不同于我预期的

查看日期范围,货币,酒店分支和报告类型. 从收到的支付收入和出发的支付支出进行区分. 确保以前的预付没有被记录两次. 未分配的费用影响单位级比较;目前的物理定义影响占用量计算.

## 退出按 ?? 已被禁用

等待客户账户加载, 确认预订仍已注册. 如果需要存款余额确认,在接受之前,请审查余额.

## 3D视图无法打开

使用重新尝试的选项. 如果浏览器无法显示场景,请使用基于文本的单元选择或房间状态板. 如果只有一个酒店分支受到影响,请检查其房间和床家具的实际定义.

## 文件语言是空的或PDF生成失败

检查选择的语言是否有模板标题和体格. 对于PDF错误,管理员可能需要检查服务器侧的PDF组件. 报表/报表浏览器打印与服务器生成的客户/文档PDF不同.

## 在支持请求中,我应该包括什么?

提供页面名称,酒店分支和单位代码,操作时间,预期结果,实际结果和错误文本. 隐藏不必要的客人的身份,联系和支付信息. 不要包含你的密码.
