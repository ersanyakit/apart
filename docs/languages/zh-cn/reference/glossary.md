# 术语表

| 术语 | 含义 |
| --- | --- |
| 酒店/商业 | 酒店分支和许可属于的主要业务. |
| 住宿设施／分店 | 运营地点;记录范围为所选择的酒店分公司. |
| 单位 | 在租用建筑物中的公寓,房间,宿舍或床. |
| 实体床位 | 床或床单家具;不一定是单独租用的单元. |
| 床位 | 物理结构中的位置或层次;客人容量是单独定义的. |
| 确认预订 | 已保存但尚未办理入住的预订。 |
| 预计到达/出发 | 预期预订日期. |
| 实际抵达/出发 | 实际上登记和退出的时间. |
| 分配 | 在特定的时间间隔内被保留的单位. |
| 客房账单 | 预订的费用、服务及付款流水汇总。 |
| 应计收入 | 在某个期内提供的服务价值;支付可能到达其他日期. |
| 已收款项 | 公司收到的钱. |
| 费用／支出付款 | 费用是已经发生的成本；付款是实际流出企业的资金。 |
| 押金 | 按约定条件退还的押金，不是住宿收入。 |
| 房源夜数 | 一个单位的使用或销售一夜. |
| 实体容量入住率 | 与实体容量相比,使用的单位夜晚. |
| 可售容量入住率 | 与可销售的容量相比的使用量. |
| 转型 | 同一产品类型的收入除以已售夜数。 |
| 雷普AR | 同一产品类型的收入除以可售夜数。 |
| 经营结果 | 报表中的收入减去经营费用，并非会计净利润。 |
| 档案 | 从日常视图移出，不是永久删除。 |

解释每个状态标签,以及记录的日期和类型. 看看 [使用报告](../finance/reports.md) 为计算细节.
