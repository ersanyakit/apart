# 客人资料、搜索与住宿历史

## 客人的详细信息

1. 在预订表中打开客人行,或使用已有的预订中编辑客人.
2. 在指定字段中输入每个人的正确姓名,联系方式和身份信息.
3. 从国家列表中选择国籍. 你可以按国家名称或代码搜索.
4. 加入一个客人排列,以便后者加入.
5. 保存和验证预订的客人名单.

不要假设两个同名的人是同一个客人. 该应用程序不仅仅基于类似的名字的人员合并. 在房间/公寓预订中,客人数和单独租用床的容量限制是单独的处理.

## 找到过去的逗留

1. 开放客人搜索和历史.
2. 设置日期和状态过选器.
3. 用名字,身份信息或电话号码搜索.
4. 打开记录,检查逗留日期和单位分配.
5. 如果客人搬家,请检查以前的单位和每个期间共住的人.

## 输出列表

在使用Excel或PDF出口之前检查您的过 ?? 器. 客户出口不仅覆盖可见页面,覆盖过度查询, 覆盖到10,000行. 为更大的结果,缩小日期范围.

如果PDF生成失败,请将错误发送给管理员,而不是重复提交相同的请求. 服务器的PDF生成组件可能需要注意.
