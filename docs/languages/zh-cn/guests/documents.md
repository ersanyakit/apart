# 合同、收据与文档模板

## 准备预订文件

1. 打开正确的预订或房间卡.
2. 选择所需的合同,预订确认,支付收据或取消文件.
3. 检查文档语言和模板.
4. 在预览中查看客人,酒店分公司,日期和金额的字段.
5. 如果需要的话,请使用编辑本文本的文本,只能更改即将创建的文档.
6. 发行文件并使用可用的下载或打印操作.

对于支付收据,请验证金额,货币,方法和日期. 发行文件不收取银行账户或支付终端费用,自动记录财务支付,或提交KBS客户通知.

## 编辑业务模板

1. 开启一个授权帐户的文档模板.
2. 选择文件类型和语言.
3. 准备标题和身体.
4. 插入自动信息字段在线索器,而不是手动输入客户或酒店分支的详细信息.
5. 用标题,列表,表格和调整工具格式化内容.
6. 在新文件预览中保存并检查结果.

每种语言都有自己的标题和体格. 准备缺失语言内容,而不是假设另一个语言将自动取代.

## 之前的文件是否发生了变化?

发行文件存储文本和支付字段,如其创建时. 更新一个模板不会改变现有文件. 在预览中编辑单个文档不会改变共享业务模板.

对于报告文件,请关注 准备文件 [使用报告](../finance/reports.md).
