# 用語集

| 期間 | 意味 |
| --- | --- |
| ホテル / ビジネス | ホテルの支店と許可が属する主な事業. |
| 施設／支店 | 業務が行われる場所;記録は選択されたホテルの支店に限定される. |
| ユニット | 賃貸の建物内のアパート,部屋,寮,ベッド. |
| 実際のベッド | ベッドまたはベック・インテリア;必ずしも別々に賃貸するユニットではない. |
| ベッド区画 | 物理構造の場所またはレベル;ゲスト容量は別々に定義されます. |
| 予約確認 | 保存済みで、まだチェックインしていない予約です。 |
| 到着/出発計画 | 予約の予定日 |
| 実際の到着/出発 | チェックインとチェックアウトが実際に起こる時間 |
| 配分 | 特定の時間間隔で予約が占める単位. |
| 客室会計 | 予約の料金、サービス、入出金の概要です。 |
| 発生収益 | 期間中のサービス価値;支払いは別の日付で届く可能性があります. |
| 入金 | ビジネスから受け取ったお金 |
| 費用／出金 | 費用は発生したコストで、出金は事業から実際に支払われるお金です。 |
| 保証金 | 条件に従って返還される預り金で、宿泊収益ではありません。 |
| ユニット泊 | 一晩で1ユニットの使用または販売 |
| 物理的収容数に対する稼働率 | 物理的な容量と比較して使用された単位ナイト |
| 販売可能数に対する稼働率 | 販売可能な容量に対する使用量 |
| ADR | 同じ商品種別の収益を販売済み泊数で割った値です。 |
| RevPAR | 同じ商品種別の収益を販売可能な泊数で割った値です。 |
| 営業収支 | レポート上の収益から営業費用を差し引いた値で、会計上の純利益ではありません。 |
| アーカイブ | 日常の表示から外すことで、完全な削除ではありません。 |
