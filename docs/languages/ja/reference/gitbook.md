# 文書管理者向け GitBook 接続ガイド

このページは,ガイドを出版する人向けです. 受付スタッフはこれらの手順を実行する必要はありません.

## 貯蔵庫構造

- 貯蔵庫根 `gitbook-docs.yaml` サイトを記述し,各言語をドキュメントディレクトリに映し出します. ファイル名は点から始まらない.
- トルコ語コンテンツは `docs/`. 翻訳版は `docs/languages/` 言語コードで
- 各言語ディレクトリには独自の言語ディレクトリーがあります `.gitbook.yaml`, `README.md`, `SUMMARY.md` そして `images/` フォルダー
- テーマファイル名はすべてのエディションで英語であります. スクリーンショットはトルコのインターフェースを保持しています

構成は [公式のGit Syncドキュメント](https://gitbook.com/docs/docs-as-code/git-sync/content-configuration). ファイル作成は自体に GitBook サイトを接続したり公開したりしません.

## リポジトリを接続する

1. すべてのガイドファイルがコミットされ, GitHub 支店に転送されていることを確認します.
2. GitBookでドキュメントサイトの Git Sync 接続を開きます.
3. リポジトリとブランチを選択します. プロジェクトディレクトリを空にして使用する `./`. サイト設定はリポジトリのルーツで それぞれの言語を独自のフォルダーにマップします
4. 最初の同期化のために,既存の GitHub コンテンツを GitBook にインポートしてください. GitBook で既にコンテンツがある場合は,選択した同期化方向を確認してください.
5. 言語版,ページの順序,画像,内部リンクを先見参照してください.
6. アカウントに公開アドレスとアクセス設定を設定し,準備ができるときに公開します.

## 設定エラーが欠けている

GitBookが報告している場合 `gitbook-docs.yaml` 枝に存在していない場合は,選択したリモートブランチの根に正しく命名されたファイルが存在していることを確認します. 地元のファイルだけでは十分ではありません どちらも `.gitbook-docs.yaml` また `.gitbook.yaml` サイト構成を置き換える. ファイルを押した後 同じ枝で再試します

プロジェクトディレクトリを `docs` この設定では 各マッピングされた言語ディレクトリが使用する `root: ./` その `.gitbook.yaml` ファイル シンクロレーション後,既存のスペースキーを安定に保つ. タイトルフィールドを改名するために使用する.

## 翻訳 を 維持 する

アクションや画面が変わると,各言語版のマッチングページを更新します. その 編集 の 一回 の ひとつ の 新しい ページ を リスト する `SUMMARY.md`. 画像リンクを相対的にマッピングされた言語フォルダ内に保存して GitHubと GitBookがそれらを解決できるようにします.

画面を指示とともに更新する. Git Sync が有効になったとき, README の編集をリポジトリに保存します. 非利用可能な機能や非機能的なライブデモアドレスを文書化しないでください.
