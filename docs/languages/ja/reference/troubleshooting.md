# トラブルシューティング

## 部屋はきれいだけどチェックインは汚い

1. 誤ったユニットコードとカードを比較する. 他のホテルの支店や連帯ベッドを指すかもしれない.
2. ホテルの支店と予約を確認する
3. 現在の清掃ラベルを刷新し確認する
4. 部屋が実際に準備されているなら クリーンを救ったかどうか確認してください
5. 早期チェックインは,実際の到着と予定された出発の間での別の滞在を確認してください.
6. エラーが続ければ,管理者にユニットコード,予定日期,動作時間,正確なエラーテキストを入力してください.

予約を複製したり,誤りを回避するために,別の滞在を無意に終了したりしないでください.

## 空き部屋は選択できません

全日期,賃貸モード,販売可用性,親/子単位予約を確認する. 出発が遅れた活動家を探してください. 部屋が今空いているということは 選択された期間中空いているとは限りません

## 予約またはメモが欠けている

まずホテルの支店,日付,状態,床と検索フィルターをチェック 注記については,アーカイブされた項目をチェックし,さらに読み込みください. 記録がまだ欠けている場合は,通知および許可された場合,システムログを確認してください.

## 総報告は予想とは違います

日付範囲,通貨,ホテルの支店,レポートタイプを確認する. 受け取った支払いからの収入と出かけの支払いからの支出を区別する. 古い預金を2回記録していないことを確認してください. 割り当てられていない支出は単位レベルでの比較に影響を与える.現在の物理定義は,占用量計算に影響を与える.

## チェックアウトボタンは無効です

ゲストの請求書が読み上げられ サービス貯蓄が終わるまで待つ. 予約がまだチェックインされていることを確認してください. 負債の確定申告が必要であれば,それを承認する前に,負債を再検討する.

## 3Dビューが開かない

再び試すオプションを使用してください. ブラウザがシーンを表示できない場合は,テキストベースのユニット選択またはルームステータスボードを使用します. ホテルの一支のみが影響を受けた場合,その部屋とベッドの家具の定義を確認してください.

## ドキュメント言語は空いているか,PDF生成が失敗している

選択された言語にはテンプレートタイトルとボディがあるかどうかを確認します. PDF エラーについては,管理者はサーバー側 PDF 構成要素を確認する必要があります. カレンダー/レポートブラウザの印刷は,サーバーで生成されるゲスト/ドキュメント PDF ファイルとは異なります.

## 支援要請に何が含まれているか?

ページ名,ホテルの支店およびユニットコード,運用時間,予想結果,実際の結果,エラーテキストを入力します. 必要なゲストの身分,連絡先,支払い情報をスクリーンショットで隠す. パスワードを入力しないでください.
