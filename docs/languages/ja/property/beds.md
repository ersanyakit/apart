# ベッドと二段ベッドの管理

実際のベッドは家具とその定員を表します。個別に予約可能なベッド区画は販売単位です。設備や備品のカタログでベッドを選ぶだけでは、予約可能なベッド区画は作成されません。

## ベッドを登録する

1. フロア・客室設定のベッド管理からベッド定義画面を開きます。
2. 必要に応じてシングルベッド、ダブルベッド、または 2・3・4 段のベッドのプリセットを選びます。
3. ベッドコード、客室、フロアを確認します。
4. ベッドの種類、構造、段数、寸法を調整します。
5. 各区画のコード、位置、定員を確認します。
6. 有効・個別予約可能の設定を客室の貸出方式と合わせて確認します。
7. ベッドを保存します。

プリセットを選んでも入力欄が埋まるだけです。記録を作成するには保存が必要です。

## 二段ベッドの例

二段ベッドは上下二つのベッド区画をまとめたものです。下段と上段には別々のコードを割り当てます。ダブルベッドは一つの区画で定員を二人に設定できます。ベッド区画数と宿泊可能人数は異なる指標です。

## 客室フォームからベッドを追加する

客室の作成・編集フォームではベッドの種類と数量を選べます。ここで選んだベッドは既存のベッドに追加されます。既存のベッドを変更したい場合は、別のベッドを追加せず、その記録を編集してください。

保存後は一覧のベッドコードと[3D 表示](three-dimensional-view.md)の配置を確認します。販売ボードにベッドが表示されない場合は、客室の貸出方式と個別予約可能の設定を確認してください。
