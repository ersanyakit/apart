# 施設・フロア・客室・アパートメント

オープンホテルブランチ プロフィールとフロアとルームの定義

![ホテル部門とユニットの定義](../images/property.png)

## 構造を計画する

階層はホテル →ホテル支部/支部 →階層とユニットです. ユニットはアパート,部屋,宿舍,ベッドかもしれません. 部屋はアパートに属し ベッドは部屋に属し得る. 物理的な床と母ユニットは別々の関係であり,多階建てのアパート内の部屋は異なる階層にある可能性があります.

## 床とユニットを作る

1. ホテルのブランチを選択し,フロアとルームの定義を開きます.
2. 階のコードを設定し,名前と順序を表示します. 同じホテルの支店内のフロアコードを再利用しないでください.
3. ユニットフォームでは,アパート,部屋,寮の種類を選択し,そのコードを入力します.
4. 適切な階と,必要に応じて,母ユニットを割り当てます.
5. 部屋のフォームでレンタモードを選択してください.
6. 実際のベッドの家具,便利な設備,インベントリ情報を追加する.
7. 定義リストおよび関連する運用ビューに単位を保存しチェックする.

## 部屋を借りるか,個別ベッドか?

| 選択 | 結果 |
| --- | --- |
| 部屋全体 | 部屋は予約ユニットであり,その実際のベッドの家具は部屋の布局を記述します. |
| 個々のベッド | リンクされたベッドスペースは別々に提供されます. |

部屋のレンタルモードは,後に追加されたベッドにも適用されます. 既存の予約に影響を与える変更は,ブロックされる可能性があります.

## 定義を編集または削除

記録を編集して 床と親単位の割り当てをチェックします 構造上の変更が確認された予約または有効な予約に影響を与える場合,最初にそれらを適切に移動するか,チェックインしていない予約のキャンセルを検討してください. 申請の検証を無視する代わりに実行してください.

大量操作の場合,選択した各ユニットコードをチェックしてください. 複数のユニットに変更を加える前にフィルターと選択された行を確認する.
