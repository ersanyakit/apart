# レポート一覧

申請書には57件の報告があります. まず,答えたい質問を特定し,関連するレポートと設定日期,ホテルの支店,通貨フィルタを選択します.

## どちらの報告から始めればいいのか?

| 質問 | 報告 |
| --- | --- |
| ビジネスはどうなってる? | 管理概要 |
| 収入 と 受ける お金 は なぜ 違う の です か. | 日々の収入と支払いは |
| 支払方法は? | 支払い方法 |
| 部屋やベッドはどのように使われていますか? | 日常用,ベッド用,アパート用 |
| 忙しい日はいくらでしょう? | 利用中の部屋の将来の割合 |
| 費用はどこにありましたか? | 費用の分割と単位による収益性 |
| どれ の 均衡 が まだ 重要 な もの です か | 領収及び支払額 |
| どの任務がまだ残っているか? | 欠陥とメンテナンス,清掃または任務の完了 |

## データソースを理解する

予約,滞在,および単位移動報告は,それらの申請記録を使用します. 投訴,維持,任務,シフト,ストック,契約,競合価格,証券預金などには,関連する取引記録が必要です. 競争相手の価格や評価は外部プラットフォームから自動的に取得されない. 報告には記録されたソースとともに手動で入力されたデータが表示されます.

見てください [取引記録](transactions.md) ソースデータを入力し, [報告書を使用する](reports.md) 計算と輸出規則について
