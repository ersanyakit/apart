# 客室会計と追加サービス

客室カードの会計、または予約詳細の客室会計／サービス追加を開きます。

客室会計には、その予約の宿泊料金、サービス料金、入出金履歴がまとめられます。合計は通貨ごとに確認してください。

## 追加サービスを登録する

1. 対象の予約の客室会計を開きます。
2. サービス名とカテゴリを入力または選択します。
3. 数量、単価、通貨を指定します。
4. 必要な説明を加え、合計金額を確認します。
5. 保存し、会計明細にサービスが追加されたことを確認します。

例：朝食を単価 150 TRY で 2 件登録すると、300 TRY のサービス請求が発生します。これはゲストから 300 TRY を受領したことを意味しません。入金は別途記録してください。

## 誤ったサービス料金を訂正する

サービスの取消操作を使い、理由を入力します。取消が会計に反映されたことを確認してください。説明を変更するだけ、またはマイナス金額のサービスを追加することで取消を代用しないでください。

フロントスタッフがサービスを追加できるのは、アクセス権のある施設の未終了の予約のみです。予約が終了済み、または権限の範囲外の場合は管理者に相談してください。

## チェックアウト前

最後のサービスを登録し、入金と返金を確認します。他のスタッフが変更した場合は会計を更新してください。チェックアウト時に未精算残高を確認しても、その残高は消えません。
