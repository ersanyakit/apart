# 財務・業務の記録

関連レポート画面でトランザクションを記録します. 利用可能なオプションは,レポートとアカウントの許可によって異なります.

## 正しいレコードタイプを選択する

| イベント | 使用する記録 |
| --- | --- |
| ゲストから金をもらった | 受け取った支払いは,日付,金額,通貨,支払い方法とともに. |
| ビジネスコストが発生した | 費用,カテゴリー,関係者/単位,説明. |
| 既存の負債が支払われた | 実際の出金であり、費用の計上とは別です。 |
| ゲストに返還された金 | 返金。処理待ちまたは完了の状態を記録します。 |
| 保証金を受け取った | 保証金の記録であり、宿泊収益として扱いません。 |
| 欠陥,任務,苦情,またはストック移動が発生した | 関連運用記録は,ソース,ステータス,要求されたフィールドを含む. |

## 記録を作成する

1. 正確なレポートとホテルの支店を開いて,レコーディングトランザクションを選択します.
2. 操作タイプと日付を選択します.
3. 記録型で要求される予約,ユニット,スタッフまたは他の当事者を選択します.
4. 通貨記録については,該当する金額,通貨,支払い方法を記入する.
5. 必要に応じて,アカウントまたはシフト参照,期限,状態およびメモを追加する.
6. 確認手順をチェックして保存します.
7. 同じ日付,ホテル支店,通貨を使って報告を確認してください.

## 給与,賃貸,公用事費

従業員の給料については,従業員を選択してください. 賃貸費用については,賃貸主を指定してください. 電力,水,インターネット,天然ガスなどの正しい種類を選択してください. 記録日期が報告期間を決定する.記号に記載されている月を記載することができます.

費用を登録しても支払いは実行されません。 給与画面で給与計算が自動実行されるわけではありません。 総額を見直すには,支出分割を使用します. 同じ支出を再び入力しないでください.

## アカウントとシフトの対応

オープン口座の決済には,ホテルの支店,通貨と参照が一致しなければならない. オープン・クローズおよび関連現金移動については同じシフト参照を使用する. ストック領収と消費については同じ製品コードを選択します.

新しい領収書として古い預金を再入力しないでください. 文書作成だけでは金融取引ではありません 維持費や損害費が事業費として表される場合,その費用を別々に記録し,重複しないことを確認してください.
