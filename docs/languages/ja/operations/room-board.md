# 客室状況ボードと清掃

ホテルの運営部門で部屋の状態を表示します

![部屋のステータスボード](../images/board.png)

## 部屋のカードを読む

ユニットコード,ゲストまたは予約情報,到着/出発日付を一緒に読む. 掃除と掃除は違います 清潔な部屋は占められても 空っぽな部屋はまだ掃除が必要かもしれません ステータスラベルを読む代わりに 色だけに頼る.

## ユニットを見つけ

1. 選択したホテルの支店を確認してください.
2. 必要に応じて検索,フロア,日付フィルターを調整する.
3. カードのユニットコードを確認する
4. カードのアクションメニューを開いてください. デスクトップでは,右クリックメニューは予約,ゲスト,ステータス,ドキュメントのアクションも提供します.

別の日付を閲覧する際,その日付の予約状態と現在の清掃状態を混同しないでください.

## 清掃状態を変更する

1. 準備室のコードを担当職員に確認してください.
2. カードの部屋の状態をチェックする
3. 実際の状態に応じてクリーンまたは汚いを選択します.
4. 確認を待って,更新されたラベルを確認してください.

承認された口座には 廃業・改装のオプションもあります メンテナンスや故障を記録する前に,既存の滞在と将来の予約を確認してください. 申請書で要求された理由または確認欄を記入する.

## チェックインがブロックされた場合

申請書では,実際の到着時間から計画された出発までの清掃,活動滞在および利用可能性をチェックします. 汚れた部屋の警告が表示された場合 部屋やベッドの正確なコードを確認し 更新し 現在の状態を確認してください

問題が続ければ, [トラブルシューティングのステップ](../reference/troubleshooting.md).
