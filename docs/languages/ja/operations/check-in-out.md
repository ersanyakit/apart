# チェックイン・早期チェックイン・チェックアウト

## 既存の予約でチェックインする

1. 予約一覧または客室カードで対象の記録を探します。
2. ゲスト名、客室などのユニット番号、予定日を確認します。
3. ゲストが到着し、客室の準備が整っていることを確認します。
4. 予約一覧で「チェックイン」または「早期チェックイン」を選びます。客室カードのメニューにも既存の予約に対する同じ操作があります。内容を確認して確定します。
5. 予約がチェックイン済みとなり、滞在中のゲスト一覧に表示されることを確認します。

予約の保存だけではチェックインされません。新しい宿泊を登録する前に、ゲストに既存の予約がないか確認してください。

## ゲストが予定より早く到着した場合

早期チェックインには既存の予約を使います。実際の到着時刻から予定の出発時刻まで、そのユニットが利用可能である必要があります。清掃状態や他の宿泊との重複も確認されます。

例：夕方に到着予定のゲストが正午に来た場合、客室が準備できており、他の宿泊と重複しなければ同じ予約でチェックインします。予定の到着日時は保持され、実際の到着日時は別に記録されます。チェックインを通すためだけに予定日を過去へ変更しないでください。

「未清掃」の警告が出たら、ユニット番号と最新の状態を確認します。準備済みの客室が正常に「清掃済み」として保存されてもチェックインできない場合は、[トラブルシューティング](../reference/troubleshooting.md)を参照してください。

## チェックアウトする

1. 滞在中のゲストの客室カードまたは予約からチェックアウト操作を開きます。
2. チェックアウト前の会計画面で、通貨ごとの集計を確認します。
3. 宿泊料金、追加サービス、入金、返金、保証金を確認します。
4. 未登録のサービスは出発前に追加します。他のスタッフが変更した場合は会計を更新します。
5. 未払い料金、返金または保証金の残高がある場合は内容を確認し、チェックアウト後も残高が保持されることに同意します。
6. 「チェックアウトを完了」を選びます。
7. 完了した宿泊記録、実際の出発日時、更新された客室状況を確認します。

チェックアウトしても未精算残高は消えません。文書を作成しても入金は自動登録されません。実際に代金を受け取り、正しく記録されていることを別途確認してください。
