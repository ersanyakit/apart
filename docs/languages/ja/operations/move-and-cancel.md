# 客室の移動・入れ替え・予約の取消

## ゲストを別のユニットに移す

1. 予約を開いて,交換室を選択してください.
2. 移動操作を選択してください.
3. 目的地の部屋,アパート,ベッドを選択してください.
4. ゲスト,日付,目的地を確認して確認してください
5. 新しいユニットのカードに ゲストが表示されているか確認する

チェックインされたお客様は 営業時間から動きます 過去のユニットに費やされた時間は 歴史に残っています ユニットコードを手動で変更することで歴史を再書き出すことを試みてはならない.

## 2つの予約単位交換

1. 交換室を開いて 1 件予約する
2. 交換操作を選択する.
3. 正しい2番目の予約を選択してください.
4. 2人のゲストと 2つのユニットと日付をチェック
5. 後で2つの予約を確認してください.

両方とも共同で検証されます 宿泊施設の利用可能性や宿泊施設の容量制限は交換を妨げる可能性があります. エラーを回避するために,2つの新しい予約を作成しないでください.

## チェックイン前に予約をキャンセル

1. 正しい予約を選択してください.
2. 予約をキャンセル
3. 確認書と必要な理由を記入してください.
4. 予約の最新状態を確認する
5. 返済を別々に処理する [金融取引記録](../finance/transactions.md).

すでにチェックインしたお客様には,予約キャンセルではなくチェックアウトを使用してください. キャンセルは銀行や決済端末で自動的にお金を返済しない.
