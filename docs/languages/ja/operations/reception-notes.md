# フロントメモとシフトの引き継ぎ

ホテルの運営欄に招待状を開くか,上にある通知ボタンを使用する.

![招待状](../images/notes.png)

## 課題を作成する

1. 選択したホテルの支店を確認してください.
2. ボードで新しいノートアクションを開く
3. 部屋203への到着準備をチェックするなど,短いアクション指向のタイトルを書いてください.
4. 必要な作業,部屋の情報,次のシフトの詳細を追加します.
5. 状態と優先順位を選択して保存します.
6. 注記が正しい列に表示されていることを確認します.

## 進展を更新する

作業は完了し,作業は完了する カードを引っ張ったり,その状態メニューを使って移動する. ステータスメニューはタッチとキーボードの使用にも適しています.

作業が実際に完了したときにのみカードを完成に移動します. 日常板に必要のないアーカイブメモは 必要に応じて復元します. アーカイブは永久に削除されません.

## 同じメモを編集する人が2人で

他の従業員がメモを変更したため,保存が拒否された場合,再び開いて,現在のバージョンを読み,変更を再び適用してください. 板は開いている時と 窓に戻るときに定期的に刷新されます カードが表示されない場合,検索して追加します.

ホテルの支部内でメモが共有されます. 記号を記入すると 部屋の清掃や予約や財務記録が自動的に更新されない. また,その対応画面で実際の操作を実行します.
