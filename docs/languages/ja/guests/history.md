# ゲスト情報・検索・宿泊履歴

## ゲストの詳細

1. 予約フォームでゲスト行を開くか,既存の予約でゲストを編集する.
2. 指定されたフィールドにそれぞれの人の正しい名前,連絡先,身分を入力します.
3. 国のリストから国籍を選択します. 国の名前やコードで検索できます
4. 滞在に参加する人全員にゲスト列を追加します.
5. 予約のゲストリストを保存して確認する.

同じ名前の2人が同じゲストだと考えないで下さい 同様の名前のみで 人を統合することはありません. 部屋/アパートの予約におけるゲストのカウントと個別賃貸ベッドの容量制限は別々に処理されます.

## 過去の滞在を 見つける

1. ゲスト検索と歴史を公開する
2. 日付と状態フィルタを設定する
3. 名前,身分情報,電話番号で検索する
4. 記録を開いて 滞在日期と単位配分を確認する
5. ゲストが引っ越した場合は 前のユニットや 滞在期間中の仲間をチェックしてください

## リストを輸出する

Excel または PDF エクスポートを使用する前にフィルターをチェックしてください. ゲスト輸出は フィルタリングされたクエリをカバーします 閲覧可能なページだけではありません 10,000 行までです より大きな結果のために日付範囲を絞る.

PDF生成が失敗した場合,同じ要求を繰り返し提出するのではなく,管理者にエラーを送信してください. サーバーのPDF生成コンポーネントには注意が必要かもしれません.
