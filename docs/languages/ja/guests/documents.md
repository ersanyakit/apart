# 契約書・領収書・文書テンプレート

## 予約文書を準備する

1. 適切な予約またはルームカードを開いてください.
2. 契約書,予約確認,支払い領収書,キャンセル書類を選択してください.
3. ドキュメント言語とテンプレートを確認する.
4. プレビューのゲスト,ホテルの支店,日付と金額のフィールドをレビューする.
5. 必要に応じて,このドキュメントのテキストを編集して作成するドキュメントのみを変更してください.
6. ドキュメントを発行し,利用可能なダウンロードまたは印刷操作を使用します.

支払領収書については,金額,通貨,方法,日付を確認する. 文書を発行する際には,銀行口座や決済端末が請求されず,金融決済が自動的に記録されず,KBSのゲスト通知も提出されず.

## ビジネステンプレートを編集する

1. 許可されたアカウントでドキュメントテンプレートを開く.
2. ドキュメントタイプと言語を選択します.
3. タイトルとボディを準備する
4. 各文書にゲストまたはホテルの支店の詳細を手動で入力するのではなく,カーソルの自動情報フィールドを挿入します.
5. タイトル,リスト,テーブル,並行ツールでコンテンツをフォーマットする.
6. 新しいドキュメントのプレビューで結果を保存して確認します.

各言語には独自のタイトルと身体があります. 他の言語が自動的に置き換えられると仮定するより,欠けている言語のコンテンツを準備する.

## 過去の文書は変わるのか?

発行された文書は,テキストと支払いフィールドが作成時にあったように保存します. テンプレートの更新は既存の文書を変更しない. プレビューで単一のドキュメントを編集することは,共有事業テンプレートを変更しません.

報告文書については, [報告書を使用する](../finance/reports.md).
