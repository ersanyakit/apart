# スタッフ・権限・操作履歴

スタッフの定義とシステムログを公開する

## スタッフの口座を設定する

1. 承認されたアカウントを使用してスタッフの定義を開く.
2. スタッフを作成するか,既存の人を編集する.
3. 完全な身分,ログイン,および表示されたスタッフ情報.
4. 職務に適した役割とホテルの支店アクセスを割り当てます
5. 従業員が自分のカードで正しいビジネスにサインインできるかどうか保存し確認します.

1つのアカウントを複数の従業員に共有しないでください. 個人のアカウントは,各操作を実行した者を特定し,優先順位を別々に保持します.

## メニューやアクションが欠けている

従業員の役割とホテルの支店へのアクセスを確認する 役割変更だけでは別のホテル支店へのアクセスが許されない可能性があります. 従業員のアカウントを更新または削除すると,開かれたセッションが終了し,再びサインインする必要があります.

## システムログに変更を表示する

1. システムログを開け
2. 当たり前の期間,操作または記録によってフィルタリング
3. 業務概要,客室/ホテルの支部及び職員をチェックする.
4. 取消または改装の理由を読み,前後の値と比較してください.

失敗した操作は成功変更記録を作成しない. 古い記録から欠落した詳細は再構築されていません. ログは取り消すツールではなく,関連する編集またはキャンセルワークフローで修正を行います.
