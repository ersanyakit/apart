# 言語・テーマ・表示設定

インターフェース内の開設設定と関連する優先順位制御.

![個人の好み](../images/settings.png)

## インターフェースを調整する

1. 設定を自分のアカウントで開く
2. テーマ,背景,フォントサイズを選択し,あなたの作品に適しています.
3. 言語と国/通貨格式の好みをチェックする.
4. 必要に応じてページヘッダー,サイドバー,カレンダー/現在のゲストビューを調整します.
5. 別のページに移動して,設定が保存されていることを確認します.

テーマ,言語,外観はサインインユーザーに属します. 保存エラーが表示された場合,設定から再試してください. 言語を変更すると,ゲストの登録された国籍も,選択した通貨も変わることはありません.

## 公共ウェブサイトの言語

最初の訪問で,ウェブサイトは自動的にブラウザの言語選択から最初のサポートされた言語を選択します. 前回の手動選択が優先されます. ブラウザの言語がサポートされていない場合,トルコ語を使用します.

家庭,価格,スクリーンショット,連絡先ページは60言語で提供されています. 言語メニューを開いて,名前やコードで検索して言語を選択します. 矢印の鍵と入力でオプションを選択します. エスケープはメニューを閉じる. 言語名は旗の隣に表示されています.

公開ページの翻訳カバーは,すべてのアプリケーションスクリーンが同じ程度に翻訳されていることを意味するものではありません. 失踪したカタログのラベルは英語で表示される可能性があります. 文書テンプレートは各言語に別々のコンテンツが必要です.

## 小型のスクリーン

同じページにアクセスするには,モバイルメニューを使用します. 必要に応じて,広いテーブルの中をスクロールする. すべてのフィールドと保存結果を確認するまでフォームを閉じるな.
