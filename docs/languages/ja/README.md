# INTERACTIVEOTEL ユーザーガイド

ホテル,アパルトホテル,ゲストハウス,短期賃貸アパートまたはホステルの日常業務を段階的に管理します. このガイドは受付スタッフ,ホテルの支店経営者,事業主向けです. 技術的な設定知識は必要ありません.

![INTERACTIVEOTEL](images/hero.png)

## このガイドを どう使うか

あなたの役割やアクセスできるホテルの支店によって,いくつかのオプションは利用できないかもしれません. 変更をする前に,選択されたホテルやホテルの支店を確認してください.

スクリーンショットは Mavi Avlu Otel の架空データと実際のアプリケーションインターフェースを表示しています 金額,日付,ゲスト名など 決定する際には,現時点の情報を自分のアプリケーションで利用してください.

スクリーンショットはオリジナルのトルコのインターフェースを維持しています. このガイドでは,選択したドキュメント言語でメニューの名前とアクションを説明します.アプリケーションは依然としてトルコ語のラベルを表示できます. 各テーマはステップ,期待される結果,関連ガイドについて説明します. ファイル名とリンクはすべての言語版において英語で残っています.
