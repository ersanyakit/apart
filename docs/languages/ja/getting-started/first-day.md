# 初日の準備：施設の設定

このページは,技術チームによってすでにアカウントと事業が作成された管理者向けです. ホテルの支店が既に利用されている場合,複製の部屋やベッドを作るのではなく,既存の記録をチェックしてください.

## 設定順番が推奨される

1. ホテル支部 プロフィールを開いて,事業とホテル支部情報を確認してください.
2. 床と部屋の定義では,床を作成し,部屋とアパートを割り当てます.
3. 各部屋で,部屋全体を借りるか,個々のベッドを借りるか選択してください.
4. 本物のベッドの家具を定義する ホステルの場合は,ベッドのレベルとベッドのスペースを別々にチェックしてください.
5. 部屋とホテルの支店の設備を完備し,関連する編集フォームで備蓄量を記入する.
6. スタッフの役割とホテルの支店へのアクセスをスタッフの定義で確認する.
7. ビジネス情報と必要な文書テンプレートの言語バージョンを準備する.
8. 部屋の状態をチェックする

![床と部屋の定義](../images/property.png)

## 最初の予約前に

| チェック | 期待された結果 |
| --- | --- |
| ホテルの支店とフロア | 部屋は正しいホテルの支店とフロアの下に表示されます. |
| レンタルモード | 部屋やベッドを選択できます. |
| 清掃 | ユニットは物理的に準備ができ 清潔と記されています |
| 日付 | 到着と出発は正し 矛盾する予約はありません |
| スタッフ | 各従業員は,自分のアカウントを使って必要なページにアクセスできます. |

訓練のために,管理者が指定したテスト環境を利用して,サンプル取引がライブビジネス記録と混同されないようにしてください.

継続する [ホテル支部構造](../property/structure.md) そして [予約作成](../operations/reservations.md).
