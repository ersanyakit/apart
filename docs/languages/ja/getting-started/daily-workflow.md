# フロント業務の一日の流れ

## シフト開始

1. 自分のアカウントでサインインして 選択したホテルの支店を確認してください.
2. 緊急で進行中の作業を受付メモの掲示板で読み取ってください.
3. 部屋の状況委員会で 汚れた 廃品・リフォームユニットをチェック
4. 滞在カレンダーと予約リストで 今日の到着と出発を確認してください.
5. 遅い出発と同じ日に別の到着を予定する部屋を考慮してください.

## 昼間

予約を記録する [予約ワークフロー](../operations/reservations.md). 2度目の予約をする代わりに,到着したゲストを既存の予約にチェックしてください. 宿泊客を移動する際に 予約の部屋交換操作を利用してください. 予約の正しいゲスト請求口座に追加のサービスを追加します.

清掃が完了したら,清掃状態を更新します. 確認メッセージを通過するために 準備されていない部屋を クリーンにマークしないでください.

## 出発時に

1. 開け [チェックアウト前のゲストの請求口座](../operations/check-in-out.md).
2. 宿泊料とサービス料,受け取った支払いは,返済と保証金を別々に検討する.
3. 許可の範囲内で必要な記録を記入してください.
4. チェックアウト確認後,宿泊と部屋の状態を確認してください.
5. 部屋に準備が必要なら,招待状を残す.

## 譲渡

完成していない作業,期待される到着,追跡を必要とするバランスを明確に記録する. シフト・キャッシュ・レポートにアクセスできれば,現金移動記録を実際に数えた現金と比較してください. 仕事が終わったらサインアウトする.

関連ガイド: [招待状](../operations/reception-notes.md).
