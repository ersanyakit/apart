# ログインと画面の基本

## 始める前に

申請のアドレス,アクセスすべき事業,個人アカウントの認証情報を管理者に尋ねてください. このガイドには共有されたデモパスワードはありません. 会社に割り当てられた口座を利用する

## サインインする

1. 申請のアドレスを開いてください. 公開サイトでは,サインインリンクをご利用ください.
2. あなたが一緒に働くホテルを選んでください.
3. スタッフカードを自分で選んでください.
4. パスワードを入力してサインインボタンを押してください.
5. 次の画面でホテルとホテルの支店の名前を確認してください. 記録を作成する前に正しいものを選択してください.

スタッフカードが欠けている場合は,まず選択した事業をチェックしてください. 口座とホテルの支店のアクセスを確認してください. パスワードエラーを回避するために,他人のカードを使用しないでください.

## インターフェースの部分

- 左のメニューでは,部屋のステータスボード,滞在カレンダー,予約その他の作業ページが開きます.
- ホテルおよびホテル支部選択機は,あなたの仕事のビジネスコンテキストを特定します.
- ページヘッダには検索,フィルター,アクションが含まれています. 隠されたコントロールを明らかにするために 崩壊したヘッダーを拡張します
- 右上の通知は成功した保存またはエラーを報告します. 欠落したフォームフィールドは,フォーム内に表示されます.
- 小型の画面では,同じ作業ページにアクセスするためにモバイルナビゲーションメニューを開きます.

保存後,成功通知と更新されたリストを確認してください. ネットワークエラーが発生した場合,同じ操作を再送信する前にレコードが作成されたかどうかを確認します.
