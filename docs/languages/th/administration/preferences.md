# ภาษา ธีม และการแสดงผลส่วนบุคคล

เปิดการตั้งค่าและการควบคุมความชอบที่เกี่ยวข้องในอินเตอร์เฟช

![ความชอบส่วนตัว](../images/settings.png)

## ปรับหน้าต่าง

1. เปิดการตั้งค่าด้วยบัญชีของคุณเอง
2. เลือกประเด็น หลังและขนาดตัวอักษรที่เหมาะกับงานของคุณ
3. ตรวจสอบความชอบภาษาและประเทศ/รูปแบบเงิน
4. ปรับหัวหน้าหน้าหน้า, ช่องข้างและการดูปฏิทิน/แขกปัจจุบันตามต้องการ
5. ย้ายไปหน้าอื่นและตรวจสอบว่าความชอบถูกเก็บไว้

ธีม ภาษา และรูปร่างเป็นของผู้ใช้งานที่ลงทะเบียน ถ้าเกิดความผิดพลาดในการบันทึก, ลองอีกครั้งจากการตั้งค่า การเปลี่ยนภาษาไม่เปลี่ยนชาติของแขกที่บันทึกไว้ หรือเปลี่ยนเงินที่ถูกเลือก

## ภาษาในเว็บไซต์สาธารณะ

เมื่อเข้าชมครั้งแรก เว็บไซต์นั้นจะเลือกภาษาแรกที่สนับสนุนโดยอัตโนมัติจากความชอบภาษาของเว็บไซต์ การเลือกมือก่อนหน้านี้เป็นหลัก ถ้าไม่มีภาษาบรอว์เซอร์ที่สนับสนุน การใช้ภาษาทุรกี

บ้าน ราคา ภาพจอ และหน้าติดต่อ มีให้บริการใน 60 ภาษา เปิดเมนูภาษา ค้นหาตามชื่อหรือรหัส แล้วเลือกภาษา คีย์ลูกศพ และเลือก Enter เป็นทางเลือก; Escape ปิดเมนู ชื่อภาษาถูกแสดงอยู่ข้างๆธง

การแปลหน้าสาธารณะไม่ได้หมายความว่าจอสมัครทุกครั้งถูกแปลในปริมาณเดียวกัน แท็กคาตาลที่หายไปอาจปรากฏในภาษาอังกฤษ แบล็อตเอกสารต้องมีเนื้อหาที่แยกแยกสําหรับแต่ละภาษา

## สกรีนเล็ก

ใช้เมนูมือถือ เพื่อเข้าถึงหน้าเดียวกัน เลื่อนในตารางกว้างเมื่อจําเป็น อย่าปิดแบบฟอร์ม จนกว่าคุณจะตรวจสอบสนามทั้งหมดและผลการบันทึก
