# พนักงาน สิทธิ์ และประวัติการดำเนินการ

เปิดความนิยามบุคลากรและบันทึกระบบ

## จัดบัญชีบุคลากร

1. เปิดนิยามบุคลากร โดยใช้บัญชีที่ได้รับอนุญาต
2. สร้างสมาชิกบุคลากร หรือแก้ไขบุคคลที่มีอยู่
3. ตัวอย่างเต็ม, ทางเข้าและข้อมูลพนักงานที่แสดง
4. มอบบทบาทและการเข้าถึงสาขาโรงแรมที่เหมาะสมกับงาน
5. เก็บและตรวจสอบว่าพนักงานสามารถเข้าสู่ธุรกิจที่ถูกต้องด้วยบัตรของตนเอง

อย่าแบ่งบัญชีเดียวกันให้กับหลายคน บัญชีส่วนตัวจะระบุผู้ดําเนินการแต่ละครั้ง และเก็บความชอบแยกแยก

## แเมนูหรือการกระทําหายไป

ตรวจสอบบทบาทของพนักงาน และการเข้าถึงสาขาโรงแรม การเปลี่ยนบทบาทเพียงอย่างเดียวอาจจะไม่ให้การเข้าถึงสาขาโรงแรมอื่น การปรับปรุงหรือลบบัญชีของบุคลากร อาจทําให้การเปิดการประชุมสิ้นสุด โดยต้องให้บุคคลลงทะเบียนอีกครั้ง

## ค้นหาการเปลี่ยนแปลงในบันทึกระบบ

1. เปิดบันทึกระบบ
2. การกรองตามระยะเวลา, การดําเนินงานหรือบันทึกที่เกี่ยวข้อง โดยใช้เครื่องควบคุมที่มีอยู่
3. ตรวจสอบ สรุปการดําเนินงาน ห้อง / สาขาโรงแรมและบุคลากร
4. เปรียบเทียบค่าก่อนและหลัง และอ่านเหตุผลการยกเลิกหรือการซ่อมแซม

การดําเนินงานที่ล้มเหลว ไม่ได้สร้างบันทึกการเปลี่ยนแปลงที่ประสบความสําเร็จ รายละเอียดที่หายไปจากบันทึกเก่าไม่ได้สร้างใหม่ ล็อคไม่ใช่เครื่องมือแก้ไข; ทําการแก้ไขผ่านกระบวนการแก้ไขหรือยกเลิกที่เกี่ยวข้อง
