# เช็กอิน เช็กอินก่อนเวลา และเช็กเอาต์

## เช็กอินจากการจองเดิม

1. ค้นหารายการที่ถูกต้องในรายการจองหรือการ์ดห้องพัก
2. ตรวจสอบชื่อผู้เข้าพัก รหัสหน่วยที่พัก และวันที่ตามแผน
3. ยืนยันว่าผู้เข้าพักมาถึงแล้วและห้องพร้อมใช้งาน
4. เลือกเช็กอินหรือเช็กอินก่อนเวลาในรายการจอง เมนูของการ์ดห้องมีการดำเนินการเดียวกันสำหรับการจองเดิม ตรวจสอบข้อมูลแล้วจึงยืนยัน
5. ตรวจสอบว่าการจองเปลี่ยนเป็นสถานะเช็กอินแล้วและปรากฏในรายการผู้เข้าพักปัจจุบัน

การบันทึกการจองยังไม่ใช่การเช็กอิน ก่อนสร้างการเข้าพักใหม่ ให้ตรวจสอบว่าผู้เข้าพักมีการจองอยู่แล้วหรือไม่

## ผู้เข้าพักมาถึงก่อนเวลา

ใช้การจองเดิมสำหรับการเช็กอินก่อนเวลา หน่วยที่พักต้องว่างตั้งแต่เวลามาถึงจริงจนถึงเวลาออกตามแผน ระบบจะตรวจสอบความสะอาดและการเข้าพักอื่นด้วย

ตัวอย่าง: ผู้เข้าพักที่คาดว่าจะมาถึงตอนเย็นมาถึงตอนเที่ยง หากห้องพร้อมและไม่มีการเข้าพักที่ทับซ้อน ให้เช็กอินด้วยการจองเดิม เวลามาถึงตามแผนจะยังคงอยู่ และระบบบันทึกเวลามาถึงจริงแยกต่างหาก อย่าเลื่อนวันที่ตามแผนย้อนหลังเพียงเพื่อให้เช็กอินได้

หากมีคำเตือนว่าห้องยังไม่สะอาด ให้ตรวจสอบรหัสหน่วยที่พักและสถานะล่าสุด หากห้องพร้อมจริงและบันทึกสถานะสะอาดสำเร็จแล้วแต่ยังเช็กอินไม่ได้ ให้ดู[การแก้ไขปัญหา](../reference/troubleshooting.md)

## เช็กเอาต์

1. เปิดการดำเนินการเช็กเอาต์จากการ์ดห้องหรือการจองของผู้ที่กำลังเข้าพัก
2. อ่านสรุปบัญชีแต่ละสกุลเงินในหน้าบัญชีก่อนเช็กเอาต์
3. ตรวจสอบค่าที่พัก บริการเสริม เงินที่รับแล้ว เงินคืน และเงินประกัน
4. เพิ่มบริการที่ยังไม่ได้บันทึกก่อนผู้เข้าพักออก หากพนักงานคนอื่นแก้ไขข้อมูล ให้รีเฟรชบัญชี
5. หากยังมีค่าบริการค้างชำระ เงินคืน หรือยอดเงินประกัน ให้ตรวจสอบก่อนยืนยันว่าจะคงยอดเหล่านี้ไว้หลังเช็กเอาต์
6. เลือกดำเนินการเช็กเอาต์ให้เสร็จสิ้น
7. ตรวจสอบรายการเข้าพักที่เสร็จสิ้น เวลาออกจริง และสถานะห้องล่าสุด

การเช็กเอาต์ไม่ลบยอดค้างชำระ การสร้างเอกสารก็ไม่บันทึกการรับเงินโดยอัตโนมัติ ให้ตรวจสอบแยกต่างหากว่าได้รับเงินจริงและบันทึกถูกต้องแล้ว
