# ย้ายห้อง สลับห้อง และยกเลิกการจอง

## ส่งแขกไปหน่วยอื่น

1. เปิดที่จองแล้วเลือกห้องเปลี่ยน
2. เลือกการเคลื่อนย้าย
3. เลือกห้องพักที่ว่าง คอนโดหรือเตียง
4. รีวิวแขก วันที่และจุดหมายแล้วยืนยัน
5. ตรวจสอบว่าแขกจะปรากฏบนบัตรของหน่วยใหม่

สําหรับแขกที่จดหมายแล้ว การเคลื่อนไหวนี้มีผลตั้งแต่เวลาปฏิบัติการ เวลาที่ใช้เวลาในหน่วยก่อนหน้านี้ ยังคงอยู่ในประวัติศาสตร์ อย่าพยายามเขียนประวัติใหม่ด้วยการเปลี่ยนรหัสหน่วยด้วยมือ

## แลกเปลี่ยนหน่วยจองสองหน่วย

1. เปิดห้องเปลี่ยนผ้าสําหรับจองครั้งเดียว
2. เลือกการแลกเปลี่ยน
3. เลือกจองที่สองที่เหมาะสม
4. รีวิวแขกทั้ง 2 หน่วย และวันที่ของพวกเขา
5. ยืนยันและตรวจสอบการจองทั้งสองหลังจากนั้น

ทั้งสองฝ่ายได้รับการยืนยันร่วมกัน ความมีของเตียงหรือขั้นต่ําของความสามารถของแขกอาจป้องกันการแลกเปลี่ยน อย่าสร้างการจองใหม่สองครั้ง เพื่อเลี่ยงความผิดพลาด

## ยกเลิกการจองก่อนการจดหมาย

1. เลือกที่จองที่ถูกต้อง
2. เปิดจองยกเลิก
3. เติมการยืนยันและเหตุผลที่ต้องการ
4. ตรวจสอบสถานะการจองที่ปรับปรุง
5. หากได้รับเงิน, จัดการคืนเงินโดยแยก [บันทึกการทําธุรกิจการเงิน](../finance/transactions.md).

สําหรับแขกที่ได้เช็คอินไปแล้ว ใช้เช็คเอาท์ แทนที่จะยกเลิกการจอง การยกเลิกไม่ได้คืนเงินโดยอัตโนมัติผ่านธนาคารหรือเครื่องชําระเงิน
