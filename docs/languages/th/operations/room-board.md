# กระดานสถานะห้องและการทำความสะอาด

เปิดคณะกรรมการสถานะห้อง ในส่วนการปฏิบัติงานโรงแรม

![โบอร์ดสถานะห้อง](../images/board.png)

## อ่านบัตรห้อง

อ่านรหัสหน่วย ข้อมูลของแขกหรือการจอง และวันเดินทาง/การเดินทางด้วยกัน การใช้งานและการทําความสะอาดต่างกัน: ห้องสะอาดอาจถูกใช้งาน และห้องว่างอาจยังต้องทําความสะสะอาด อ่านตราสถานะ แทนที่จะพึ่งแค่สี

## หาหน่วย

1. ยืนยันสาขาโรงแรมที่เลือก
2. ปรับกรองค้นหา, ชั้นและวันตามต้องการ
3. ตรวจสอบรหัสหน่วยบนบัตร
4. เปิดเมนูการกระทําของบัตร บนโต๊ะทํางาน เมนูด้วยการคลิกขวายังให้บริการการจอง, ผู้เข้าพัก, สถานการณ์และเอกสาร

เมื่อดูวันที่อื่นๆ อย่าผสมสถานะการจองวันนั้นกับสถานะการทําความสะอาดปัจจุบัน

## เปลี่ยนสถานะการทําความสะอาด

1. ยืนยันรหัสห้องเตรียมพร้อมกับสมาชิกที่รับผิดชอบ
2. เปิดการควบคุมสถานะห้องบนบัตร
3. เลือก Clean หรือ Dirty ตามสถานการณ์จริง
4. รอรับการยืนยัน และตรวจสอบตราที่ปรับปรุง

บัญชีที่ได้รับอนุญาตยังมีตัวเลือกว่าง หมดสภาพ และภายใต้การปรับปรุง ก่อนที่จะบันทึกการรักษาหรือความผิดพลาด ตรวจสอบการพักที่มีอยู่และการจองในอนาคต เติมเต็มเหตุผลหรือสนามการยืนยันที่ขอโดยการสมัคร

## ถ้าการเช็คอินถูกปิด

การสมัครงานตรวจสอบการทําความสะอาด, การพักอาศัยและการมีค่าใช้จ่าย ตั้งแต่เวลาที่มาจริงจนถึงเวลาออกที่วางแผน ถ้ามีสัญญาณเตือนห้องที่สกปรก ตรวจสอบรหัสห้องหรือเตียงที่แม่นยํา และตรวจสอบสถานการณ์ปัจจุบัน

ถ้าปัญหายังคงอยู่ ติดตาม [ขั้นตอนแก้ไขปัญหา](../reference/troubleshooting.md).
