# บันทึกแผนกต้อนรับและการส่งมอบกะ

เปิดบันทึกการต้อนรับในส่วนการปฏิบัติงานโรงแรม หรือใช้ปุ่มแจ้งความที่ด้านบน

![บันทึกการรับ](../images/notes.png)

## สร้างงาน

1. ยืนยันสาขาโรงแรมที่เลือก
2. เปิดบันทึกใหม่ในกระดาน
3. เขียนหัวข้อที่สั้น ๆ ที่มุ่งเน้นกับการกระทํา เช่น "ตรวจสอบการเตรียมการเดินทางมาห้อง 203"
4. เพิ่มงานที่ต้องการ ข้อมูลห้อง และรายละเอียดความต้องการของช่วงต่อไป
5. เลือกสถานะและความสําคัญ จากนั้นบันทึก
6. ยืนยันว่าหมายเลขจะปรากฏในคอลัมน์ที่ถูกต้อง

## ปรับปรุงความก้าวหน้า

บอร์ดต้องทํา หมวดที่กําลังดําเนินการ และเสร็จ ดึงบัตร หรือใช้เมนูสถานะของมันเพื่อย้ายมัน เมนูสถานการณ์ยังเหมาะสําหรับการใช้งานด้วยการสัมผัสและคีย์บอร์ด

ขยับบัตรไปยัง Completed เพียงเมื่อการทํางานได้สําเร็จ เอกสารบันทึกที่ไม่จําเป็นต้องใช้ในบอร์ดประจําวันและคืนมันเมื่อจําเป็น การบันทึกบันทึกไม่ได้หมายถึงการลบไปตลอดไป

## ถ้าคนสองคนแก้ไขหมายเลขเดียวกัน

ถ้าการเก็บเงินถูกปฏิเสธเพราะพนักงานคนอื่นเปลี่ยนใบหมาย, เปิดมันอีกครั้ง, อ่านฉบับปัจจุบันและใช้การเปลี่ยนแปลงของคุณอีกครั้ง. กระดานจะปรับปรุงประจําเวลาที่เปิด และเมื่อคุณกลับไปที่หน้าต่าง ใช้การค้นหาและโหลดเพิ่มเติมหากบัตรไม่เห็น

บันทึกถูกแบ่งออกภายในสาขาโรงแรม การเติมบันทึกไม่ได้ทําให้ห้องพักสะอาด, จองหรือบันทึกการเงินปรับปรุงโดยอัตโนมัติ ทําการทํางานจริงในหน้าจอที่ตรงกัน
