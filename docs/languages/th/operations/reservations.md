# สร้างและแก้ไขการจอง

เปิดรายการจอง หรือใช้จองที่หน่วยในห้อง

![จองใหม่](../images/new-booking.png)

## สร้างการจอง

1. เลือกสาขาโรงแรมที่เหมาะสม และเปิดฟอร์มจองใหม่
2. รีวิว การเดินทาง, คืนและการเดินทาง หลังจากเปลี่ยนสนามหนึ่ง ตรวจสอบค่าคํานวณของสนามอื่น ๆ
3. กรอกตัวผู้ถือจองและจํานวนแขก
4. เติมชื่อ, โทรศัพท์, บัตรประจําตัวตน/ جوازเดินทาง และท้องถิ่นของแขกแต่ละคน เพศเป็นทางเลือก
5. เลือกห้อง, คอนโดหรือเตียงที่เหมาะสมในกรอบที่ให้เช่า
6. ตรวจสอบราคาต่อคืนและค่าธรรมเนียมอื่น ๆ หรือค่าชําระก่อน ราคาต่อคืนไม่ใช่ราคาที่พักทั้งหมด
7. เพิ่มข้อมูลที่ต้องการสําหรับการทํางานต่อไปสู่ Notes
8. เก็บไว้และยืนยันว่าการจองจะปรากฏด้วยหน่วยและวันที่ถูกต้อง

ตัวอย่าง: การเดินทางถึงวันที่ 15 ตุลาคม และการเดินทางออกวันที่ 18 ตุลาลาคม หมายถึง 3 คืน การจองครั้งอื่นสามารถเริ่มต้นในเวลาออกเดินทางในวันที่ 18 ตุลาคม ผู้เข้าพักที่ยังไม่ได้เช็คออก ก็ยังสามารถปิดหน่วยได้ แม้กระทั่งหลังจากการออกที่วางแผน

## ทําไมหน่วยไม่ออก?

วันที่อาจขัดแย้งกับการจองอื่นๆ การจองของหน่วยพ่อแม่หรือเด็ก หรือสถานะหน่วยที่ไม่เหมาะสม การจองห้องพักทั้งห้อง จะปิดห้องพักให้เป็นเวลาเดียวกัน การจองห้อง ทําให้เตียงไม่หลับได้ เตียงเช่าอิสระในห้องเดียวกันสามารถมีการจองแยก

## แก้ไขวัน

1. เปิดรายละเอียดการจอง
2. เลือก Edit วันที่จอง
3. รีวิวและบันทึกวันใหม่และสนามราคา
4. ตรวจสอบการเปลี่ยนแปลงในปฏิทิน

คุณสามารถแก้ไขวันที่วางแผนหลังจากจดหมาย เวลาการเดินทางจริง และการเคลื่อนไหวของหน่วยก่อนหน้านี้ยังคงไม่เปลี่ยนแปลง การออกเดินทางใหม่ต้องเกิดขึ้นในอนาคต และไม่ควรขัดแย้งกับการจองครั้งอื่น ใช้ [การเปลี่ยนห้อง](move-and-cancel.md) เพื่อเปลี่ยนหน่วย
