# ปฏิทินการเข้าพักและผู้เข้าพักปัจจุบัน

## อยู่ตามปฏิทิน

![อยู่ตามปฏิทิน](../images/calendar.png)

1. เปิดปฏิทินการพักจากเมนู
2. ไปยังช่วงเวลาที่ต้องการ และเลือกรายวัน, รายสัปดาห์หรือรายเดือน
3. ลดผลการค้นหาด้วยกรองการค้นหาและสถานะ
4. เลือกที่พัก เพื่อตรวจสอบแขก วันที่ จดหมาย และราคาต่อคืน
5. หลังจากเปลี่ยนช่วงเวลาหรือกรอง ยืนยันว่าผลงานตรงกับการเลือกใหม่

การส่งออก CSV มีการจัดสรรหน่วยที่กรองไว้สําหรับช่วงที่เลือก พิมพ์ / PDF เปิดปฏิทินที่เห็นในกระจกการพิมพ์ของบrowser เลือกจุดหมาย PDF เพื่อบันทึกเป็นไฟล์

## ผู้เข้าพักปัจจุบัน

![ผู้เข้าพักปัจจุบัน](../images/stays.png)

ใช้ผู้เข้าพักปัจจุบัน เพื่อติดตามการพักที่เกิดขึ้นและการเดินทางที่วางแผน การค้นหา การเลือกพื้น และวันเริ่มต้นอยู่ในหัวหน้าหน้าหน้า ขยายหัวข้อ ถ้าการควบคุมนั้นซ่อนอยู่ ปรับการเดินเรือช่วงเวลา สถานการณ์ จํานวนวันและการควบคุมหน่วยว่างตามความต้องการ

แยกวันที่วางแผนจากเวลาที่ถึงและออกจริง การจดหมายในช่วงต้นและการย้ายห้องสามารถทําให้การย้ายจริงแตกต่างจากช่วงที่วางแผนไว้

ก่อนที่จะถือว่าบันทึกหายไป ล้างสาขาโรงแรม วันที่ ชั้น สถานการณ์และการค้นหากรองและตรวจสอบอีกครั้ง
