# บันทึกการเงินและการดำเนินงาน

ใช้การบันทึกธุรกิจในหน้าจอรายงานที่เกี่ยวข้อง ตัวเลือกที่มีขึ้นอยู่กับรายงานและอนุญาตบัญชีของคุณ

## เลือกประเภทบันทึกที่ถูกต้อง

| เหตุการณ์ | การบันทึกเพื่อใช้งาน |
| --- | --- |
| ได้เงินจากแขก | การชําระเงินที่ได้รับ พร้อมวัน, เงิน, เหรียญและวิธีชําระ |
| มีค่าใช้จ่ายทางธุรกิจ | ค่าใช้จ่าย พร้อมประเภท บุคคล/หน่วยที่เกี่ยวข้อง และคําอธิบาย |
| การจ่ายหนี้ที่มีอยู่ | การจ่ายเงินจริง แยกจากการบันทึกค่าใช้จ่าย |
| เงินจะถูกคืนให้กับแขก | เงินคืน โดยระบุว่ารอดำเนินการหรือเสร็จสิ้นแล้ว |
| ได้รับเงินประกัน | บันทึกเงินประกัน อย่านับเป็นรายได้ค่าที่พัก |
| เกิดความผิดพลาด การทํางาน การร้องเรียน หรือการเคลื่อนไหวของสินค้า | รายงานการดําเนินงานที่เกี่ยวข้อง พร้อมแหล่ง, สถานการณ์และสนามที่ต้องการ |

## สร้างบันทึก

1. เปิดรายงานที่ถูกต้อง และสาขาโรงแรม จากนั้นเลือกบันทึกธุรกิจ
2. เลือกประเภทการปฏิบัติงานและวันที่
3. เลือกการจองหน่วยงาน สมาชิกพนักงาน หรือพรรคอื่นที่ต้องการตามประเภทบันทึก
4. สําหรับบันทึกเงินเงิน, เงินเต็ม, เหรียญและวิธีการชําระเงินตามที่ต้องการ
5. เพิ่มเติมการอ้างอิงบัญชีหรือการเปลี่ยนแปลง, วันชําระ, สถานการณ์และบันทึกเมื่อจําเป็น
6. รีวิวขั้นตอนการยืนยันและบันทึก
7. ตรวจสอบรายงาน โดยใช้วันเดียวกัน สาขาโรงแรมและเงิน

## เงินเดือน ค่าเช่าและค่าบริการ

สําหรับเงินเดือนพนักงาน เลือกพนักงาน สําหรับค่าเช่า กําหนดเจ้าของบ้าน สําหรับค่าใช้จ่ายบริการเลือกประเภทที่เหมาะสม เช่นไฟฟ้า น้ํา อินเตอร์เน็ต หรือก๊าซธรรมชาติ วันบันทึกกําหนดช่วงรายงาน คุณสามารถระบุเดือนที่อยู่ในบันทึก

การบันทึกค่าใช้จ่ายไม่ได้ทำให้เกิดการจ่ายเงิน หน้าจอเงินเดือนไม่ได้คำนวณเงินเดือนโดยอัตโนมัติ ใช้การแบ่งค่าใช้จ่ายเพื่อตรวจสอบจํานวนรวม อย่าใส่ค่าใช้จ่ายเดียวกันอีกครั้งที่นั่น

## การตรงกับบัญชีและช่วงเวลา

สําหรับการชําระบัญชีเปิด โรงแรมสาขา, เงินและอ้างอิงต้องตรงกัน ใช้ระดับระยะเวลาเดียวกันสําหรับการเปิด,ปิด และการเคลื่อนไหวเงินสดที่เกี่ยวข้อง เลือกรหัสสินค้าเดียวกันสําหรับใบรับสินค้าและการบริโภค

อย่าใส่เงินล่วงหน้าเก่าใหม่เป็นใบรับรองใหม่ การสร้างเอกสารคนเดียวไม่ใช่ธุรกิจการเงิน ถ้าค่ารักษาหรือค่าเสียหายต้องปรากฏเป็นค่าใช้จ่ายของธุรกิจเช่นกัน, บันทึกค่าใช้จ่ายแยกกันและตรวจสอบว่ามันไม่ได้ซ้ํา
