# รายการรายงาน

การสมัครมี 57 รายงาน ก่อนหน้านี้ระบุคําถามที่คุณต้องการตอบ จากนั้นเลือกรายงานที่เกี่ยวข้อง และกําหนดวัน, สาขาโรงแรมและกรองเงิน

## ฉันควรเริ่มจากรายงานไหน?

| คําถาม | รายงาน |
| --- | --- |
| เกิดอะไรขึ้นในธุรกิจ? | วิวรวมการบริหาร |
| ทําไมรายได้และเงินที่ได้รับต่างกัน? | รายได้และการชําระเงินรายวัน |
| วิธีการชําระเงินที่ใช้ | วิธีการจ่ายเงิน |
| ห้องหรือเตียงใช้อย่างไร? | อาชีพประจําวัน อาชีพที่นอน หรืออาชีพที่พัก |
| วันหน้าจะมีงานเยอะแค่ไหน | ส่วนส่วนของห้องในอนาคตที่ใช้ |
| ค่าใช้จ่ายที่เกิดขึ้นอยู่ที่ไหน | การแยกค่าใช้จ่ายและรายได้ตามหน่วยงาน |
| ความสมดุล อะไร ที่ ยัง มี อยู่? | เงินที่ต้องรับ |
| มีหน้าที่อะไรที่ยังเปิดอยู่? | ความผิดพลาดและการรักษา การทําความสะอาด หรือการทําหน้าที่สําเร็จ |

## เข้าใจแหล่งข้อมูล

รายงานการจอง, การพักและการเคลื่อนไหวของหน่วยใช้บันทึกการสมัคร การร้องเรียน การรักษาความปลอดภัย การดําเนินงาน ช่วงงาน การจัดสรรสินค้า การสรรคสินค้า การประกอบสัญญา ราคาผู้แข่งขัน และฝากเงินประกันภัย จําเป็นต้องมีการบันทึกธุรกิจที่เกี่ยวข้อง ราคาและการรีวิวของผู้แข่งขันไม่ได้ถูกนํามาโดยอัตโนมัติจากโครงการภายนอก รายงานแสดงข้อมูลที่บันทึกมาด้วยมือกับแหล่งบันทึก

ดูสิ [รายงานการซื้อขาย](transactions.md) เพื่อใส่ข้อมูลแหล่ง และ [การใช้รายงาน](reports.md) สําหรับการคํานวณและกฎการส่งออก

| เงินประกัน | เงินประกันที่ได้รับและคืน |
| รายได้จากอพาร์ทเมนต์ | รายได้ที่พักตามอพาร์ทเมนต์ |
| ผู้เข้าพักพักยาว | การจองตั้งแต่ 28 คืนขึ้นไป |
| การดูแลห้องพัก | รายงานการดูแลตามอพาร์ทเมนต์ |
| ส่วนส่วนของห้องพักที่ใช้ | ความจุและสัดส่วนของห้องที่ใช้ในห้องพัก |
| ผลการดําเนินงานห้องพัก | ผลหลังจากจ่ายเงินโดยตรง |
| ค่าเช่าและค่าชําระที่ได้รับ | ราคาสัญญา วันชําระและบันทึกการจ่ายเงิน |

## การเงิน

| รายงาน | สิ่งที่มันแสดง |
| --- | --- |
| รายได้และการชําระเงินรายวัน | เติมเงินที่ผ่านมาของที่พัก, เติมรายได้, จ่ายเงินที่ได้รับและคืนเงินจะแสดงให้ละกัน |
| การแยกค่าใช้จ่าย | การแยกรายการเงินเดือน ค่าเช่า ค่าบริการและค่าใช้จ่ายการดําเนินงานอื่นๆ |
| รายได้และค่าใช้จ่าย | รายได้ระยะเวลา, รายจ่ายการดําเนินงานและผลการดําเน นงาน |
| วิธีการจ่ายเงิน | สถานที่รับและคืนเงิน |
| เงินเดือนพนักงาน | เงินเดือนที่บันทึกตามสมาชิกและระยะเวลา |
| ผลการดําเนินงานตามหน่วยงาน | เงินรายได้ต่อตัวการรายได้และค่าใช้จ่ายที่ได้รับการจัดสรรโดยตรง |
| เงินที่ต้องรับ | การวิเคราะห์ความแก่ของอัตราการเก็บเงินและบัญชีเปิดอื่นๆ |
| การยกเลิกและคืนเงิน | ยกเลิกการขาย เติมเต็ม และการคืนเงินที่รอ |
| ค่าเช่า | ค่าเช่าตามที่บริษัทจ่ายตามระยะเวลาและเจ้าของบ้าน |
| ค่าบริการ | ค่าใช้จ่ายไฟฟ้า น้ํา อินเตอร์เน็ต และก๊าซ ตามประเภท ระยะเวลา และผู้จําหน่าย |

## ผู้เข้าพัก

| รายงาน | สิ่งที่มันแสดง |
| --- | --- |
| การร้องเรียน | ประเภทการออก กรณีที่เปิด และเวลาในการแก้ไข |
| โปรไฟล์แขก | ผู้เข้าพักใหม่และที่กลับมา และการจําหน่ายประเทศ ที่สามารถปรับตัวตนได้ |
| เยือนที่กลับมา | การพักของแขก, รายได้ที่พักและช่วงระหว่างการเยี่ยม |
| ความพอใจของแขก | ได้คะแนนการวิจารณ์จาก 5 |

## โฮสเทล

| รายงาน | สิ่งที่มันแสดง |
| --- | --- |
| ความจุของเตียงสองชั้น | ความจุของเตียงชั้นบน ชั้นล่าง และกลุ่มเตียง |
| การใช้พื้นที่ร่วม | การใช้พื้นที่ร่วมกันที่บันทึกไว้ |
| รายได้บริการเพิ่มเติม | รถเก็บของ ผ้าซักรีด อาหารเช้า และรายได้เพิ่มเติมอื่นๆ |
| ผู้เข้าพักในกลุ่ม | การจองที่เชื่อมโยงด้วยรหัสกลุ่ม |
| เปลี่ยนห้องนอนและห้องพัก | ประวัติการจัดแลกระทบการจอง |
| ส่วนของเตียงที่ใช้ | ส่วนส่วนของห้องที่ใช้มาวัดในช่วงคืนนอน |
| เตรียมเตียง | สถานะการทําความสะอาดเตียงและงานการเตรียม |
| รายได้ต่อเตียง | คืนและรายได้ตามเตียง |
| พักแขกไม่นาน | การจองสำหรับ 1–7 คืน |
| การแสดงในห้องนอน | ขายและการใช้งานตามชนิดหน่วย |

## การบริหาร

| รายงาน | สิ่งที่มันแสดง |
| --- | --- |
| วิวรวมการบริหาร | รายได้ การชําระเงินที่ได้รับ ความสามารถ และตัวประชากรการดําเนินงาน |
| เปรียบเทียบของที่พัก | เปรียบเทียบที่ดินที่คุณได้รับอนุญาตให้บริหารในช่วงเดียวกัน |
| รายงานการซื้อขาย | การบันทึกการเงินและการดําเนินงานที่ใช้เป็นแหล่งรายงาน |

## อัตราการเข้าพัก

| รายงาน | สิ่งที่มันแสดง |
| --- | --- |
| การใช้พลังงาน | หน่วยงานทางกายภาพปัจจุบัน สามารถขายได้และปิดได้ |
| ส่วนส่วนของห้องที่ใช้ในวัน | ความสามารถทางกายภาพและการขายใช้ตัวแทนที่แยกแยก |
| ส่วนส่วนของห้องในอนาคตที่ใช้ | วิวความสามารถจากการจองปัจจุบัน |
| อัตราส่วนที่ผ่านมาของห้องที่ใช้ | การเปรียบเทียบรายวัน อาทิตย์และเดือน |
| ผลงานของหน่วย | คืน, รายได้และส่วนของห้องที่ใช้ต่อห้อง, เตียงหรืออพาร์ทเมนต์ |

## การดําเนินงาน

| รายงาน | สิ่งที่มันแสดง |
| --- | --- |
| การสูญเสียและความเสียหาย | แหล่งจ่ายค่าใช้จ่ายและค่าเสียหายที่บันทึก |
| การทําความสะอาดบ้าน | สถานการณ์การทําความสะอาดปัจจุบันและงานทําความสะดวกที่บันทึกไว้สําหรับแต่ละหน่วย |
| สถานที่และการบริโภค | ประเภทประเภทสินค้า การบริโภค เบลานซ์ และขั้นต่ําการจัดลําดับใหม่ ตามรหัสสินค้า |
| ความผิดพลาดและการรักษา | ปรับความผิดพลาด, ระยะเวลาในการแก้ไขและค่ารักษา |

## การจัดการรายได้

| รายงาน | สิ่งที่มันแสดง |
| --- | --- |
| ราคาแข่งขัน | จัดบันทึกการสังเกตเห็นราคากับแหล่ง |
| คาดการณ์รายได้ | ค่าที่พักในอนาคตของการจองที่ได้รับการยืนยัน |
| ADR และ RevPAR | รายได้ต่อคืนที่ขาย และต่อคืนที่ว่างสําหรับชนิดสินค้าเดียวกัน |
| ผลการผลิตราคา | ขายกลางคืนโดยประเภทสินค้าและวัน |

## การจอง

| รายงาน | สิ่งที่มันแสดง |
| --- | --- |
| แหล่งการจอง | รายได้ทางช่องทาง อัตราการยกเลิก และการขายหลังคอมมิชั่น |
| การแปลงขาย | การสอบถาม, คําอ้างอิง, การขายที่ชนะและแพ้ |

| ระยะเวลาการพักของแขก | จํานวนคืนและการจัดจําหน่ายการพักของแขกสั้นและยาว |
| สรุปการจอง | สถานการณ์การจองตามวันที่สร้าง |
