# บัญชีห้องพักและบริการเสริม

เปิดบัญชีจากการ์ดห้องพัก หรือเลือกบัญชีห้องพัก / เพิ่มบริการในรายละเอียดการจอง

บัญชีรวมค่าที่พัก ค่าบริการ และรายการรับจ่ายของการจองนั้น ให้ตรวจสอบยอดรวมแยกตามสกุลเงิน

## เพิ่มบริการเสริม

1. เปิดบัญชีของการจองที่ถูกต้อง
2. กรอกหรือเลือกชื่อบริการและหมวดหมู่
3. ระบุจำนวน ราคาต่อหน่วย และสกุลเงิน
4. เพิ่มคำอธิบายที่จำเป็นและตรวจสอบยอดรวม
5. บันทึกและตรวจสอบว่าบริการปรากฏในรายการบัญชีแล้ว

ตัวอย่าง: อาหารเช้า 2 ชุด ชุดละ 150 TRY ทำให้เกิดค่าบริการที่ต้องชำระ 300 TRY แต่ไม่ได้หมายความว่าได้รับเงินจากผู้เข้าพัก 300 TRY แล้ว ต้องบันทึกการรับเงินแยกต่างหาก

## แก้ไขค่าบริการที่ผิด

ใช้การยกเลิกบริการและระบุเหตุผล จากนั้นตรวจสอบรายการยกเลิกในบัญชี อย่าเพียงแก้คำอธิบายหรือเพิ่มบริการใหม่ที่มียอดติดลบเพื่อแทนการยกเลิก

พนักงานต้อนรับเพิ่มบริการได้เฉพาะการจองที่ยังไม่ปิดในสถานประกอบการที่ตนมีสิทธิ์เข้าถึง หากการจองปิดแล้วหรืออยู่นอกสิทธิ์ ให้ติดต่อผู้จัดการ

## ก่อนเช็กเอาต์

เพิ่มบริการสุดท้ายและตรวจสอบเงินที่รับแล้วกับเงินคืน หากพนักงานคนอื่นแก้ไขข้อมูล ให้รีเฟรชบัญชี การยืนยันยอดค้างชำระตอนเช็กเอาต์ไม่ได้ลบยอดนั้น
