# การใช้และอ่านรายงาน

เปิดรายงานในเมนูซ้าย รายงานมีให้บริการกับหน้าที่ผู้บริหารและบริหารธุรกิจ ภายในกรอบการเข้าถึงสาขาโรงแรมของพวกเขา

![วิวรวมการบริหาร](../images/report-dashboard.png)

## เตรียมรายงาน

1. เลือกรายงานที่คุณต้องการ เริ่มจากภาพรวมของบริหารงานเพื่อภาพรวม
2. กําหนดวันเริ่มต้นและวันจบ วันสิ้นสุดรวม
3. ตรวจสอบสาขาโรงแรมและการเลือกสกุลเงิน และขัดกรองอื่นๆ
4. อ่านบัตรสรุป แผน และตารางด้วยกัน
5. ถ้าไม่มีผล ตรวจสอบระยะเวลาและกรองก่อน

คําถามรองรับได้ถึง 366 วัน ถ้ามีขีดขั้นต่ําของจํานวนข้อมูลแล้ว กําหนดระยะเวลาและสร้างรายงานแยกแยก วันรายงานใช้เขตเวลาของสตานบูล

## รายได้และเงินที่ได้รับต่างกัน

รายได้ที่พักเกี่ยวข้องกับเวลากลางคืนที่บริการนี้ถูกให้บริการ การชําระเงินที่ได้รับเกี่ยวข้องกับเวลาที่เงินมาถึง เงินที่ได้รับในวันนี้สําหรับการพักในเดือนหน้า ไม่จําเป็นต้องปรากฏในวันเดียวกันในทั้งสองการ

![รายได้และการชําระเงินรายวัน](../images/report-revenue.png)

เหรียญไม่ได้แปลงโดยอัตโนมัติหรือรวมเป็นจํานวนรวม ผลการดําเนินงานไม่ได้เป็นกําไรสะอาดบัญชีหลังภาษีและการเงิน ผลในระดับหน่วยรวมเพียงค่าใช้จ่ายที่ได้รับมอบหมายให้หน่วย; ตรวจสอบค่าใช้จ่ายไม่ได้รับมอบแยก

## อ่านอัตราการใช้งาน

ความสามารถทางกายภาพและความสามารถที่สามารถขายได้ใช้ตัวแทนที่แตกต่างกัน ยูนิตที่ปิดขายสามารถส่งผลต่อผล การเปลี่ยนแปลงความสามารถในประวัติศาสตร์ไม่ได้ถูกเก็บไว้ ดังนั้นการคํานวณการใช้งานในประวัยจึงขึ้นอยู่กับนิยามทางกายภาพปัจจุบัน จํานวนห้องนอนและความสามารถของแขกต่างกัน

![ส่วนส่วนของห้องที่ใช้ในวัน](../images/report-occupancy.png)

## รีวิววิธีการชําระเงิน

เปรียบเทียบบัตรเครดิต โอนเงินทางธนาคาร เงินสด และช่องทางการชําระเงินอื่นๆ อ่านใบรับและเงินคืนแยกกัน ตรวจสอบวันและเงิน ก่อนตีความแผนที่

![วิธีการจ่ายเงิน](../images/report-payments.png)

## ส่งออกและเตรียมเอกสารรายงาน

CSV รวมทุกแถวในรายงานที่เลือก เตรียมเอกสารสร้างรายงานที่สามารถแก้ไขได้ โดยใช้กรองปัจจุบัน เพิ่มคําอธิบาย และดาวน์โหลด HTML หรือพิมพ์เป็น PDF ในบราwser เอกสารที่แก้ไขได้มีข้อมูลตารางสูงสุด 1,000 แถว ถ้าแถวถูกยกเว้น, ใช้ CSV สําหรับชุดข้อมูลทั้งหมด.

เลือกรายงานจาก [57-รายงานคาตาล](report-catalog.md). เติมข้อมูลแหล่งที่หายไปโดยใช้ [รายงานการซื้อขาย](transactions.md).
