# สัญญา ใบเสร็จ และแม่แบบเอกสาร

## เตรียมเอกสารจอง

1. เปิดการจองที่ถูกต้อง หรือบัตรห้องพัก
2. เลือกสัญญาที่ต้องการ, การยืนยันการจอง, จ่ายเงิน หรือเอกสารยกเลิก
3. ตรวจสอบภาษาเอกสารและแบบล่ม
4. รีวิวแขก สาขาโรงแรม ช่วงวันและจํานวนในภาพล่วงหน้า
5. หากจําเป็น, ใช้ Edit ข้อความของเอกสารนี้เพื่อเปลี่ยนเอกสารที่คุณกําลังจะสร้างเท่านั้น.
6. ออกเอกสารและใช้การดาวน์โหลดหรือพิมพ์ที่มีอยู่

สําหรับใบรับเงินชําระเงิน ยืนยันจํานวนเงิน หลักทรัพย์ วิธีและวันที่ การออกเอกสารไม่ได้คิดค่าบัญชีธนาคารหรือเครื่องชําระเงิน, จัดการชําระจ่ายเงินโดยอัตโนมัติ, หรือส่งแจ้งการแขก KBS

## ปรับเปลี่ยนรูปแบบธุรกิจ

1. เปิดเอกสาร Template กับบัญชีที่ได้รับอนุญาต
2. เลือกประเภทเอกสารและภาษา
3. เตรียมหัวข้อและร่างกาย
4. ใส่สนามข้อมูลอัตโนมัติในคาร์เซอร์ แทนที่จะใส่รายละเอียดของแขกหรือสาขาโรงแรมด้วยมือในเอกสารแต่ละครั้ง
5. โปรแกรมเนื้อหาด้วยหัวข้อ, รายการ, ตารางและเครื่องมือประสาน
6. เก็บและตรวจสอบผลในหน้าแรกเอกสารใหม่

แต่ละภาษามีชื่อและร่างกายของมันเอง เตรียมเนื้อหาภาษาที่หายไป แทนที่จะคาดว่าภาษาอื่นจะถูกเปลี่ยนโดยอัตโนมัติ

## เอกสารก่อนหน้านี้เปลี่ยนไหม

เอกสารที่ออกจะเก็บบทความและสนามการชําระเงินเหมือนตอนที่สร้าง การปรับปรุงแบบลักษณะไม่เปลี่ยนแปลงเอกสารที่มีอยู่ การปรับปรุงเอกสารเดียวในภาพล่วงหน้าไม่เปลี่ยนแปลงแบบลักษณะธุรกิจที่แบ่งปัน

สําหรับเอกสารรายงาน ติดเอกสารเตรียม [การใช้รายงาน](../finance/reports.md).
