# ข้อมูลผู้เข้าพัก การค้นหา และประวัติการเข้าพัก

## รายละเอียดผู้เข้าพักเต็ม

1. เปิดแถวแขกในฟอร์มจอง หรือใช้ Edit guests ในจองที่มีอยู่
2. กรอกชื่อที่ถูกต้องของแต่ละคน, ติดต่อและรายละเอียดตัวตนในสนามที่กําหนด
3. เลือกชาติจากรายการประเทศ คุณสามารถค้นหาตามชื่อประเทศหรือรหัส
4. เพิ่มแถวผู้เข้าพักให้กับใครก็ตามที่เข้ามาพักในภายหลัง
5. เก็บและตรวจสอบรายชื่อแขกที่จอง

อย่าคิดว่าคนสองคนที่มีชื่อเดียวกันคือแขกเดียวกัน แอพลิเคชันไม่รวมคนขึ้นอยู่กับชื่อที่เหมือนกันเท่านั้น จํานวนแขกในห้อง / คอนโดจองและขีดขั้นต่ําความสามารถสําหรับเตียงเช่าแต่ละคนถูกจัดการแยกแยก

## หาที่พักที่ผ่านมา

1. เปิดการค้นหาผู้เข้าพักและประวัติศาสตร์
2. กําหนดวันและกรองสถานะ
3. ค้นหาตามชื่อ ข้อมูลตัวตน หรือเบอร์โทรศัพท์
4. เปิดบันทึกและตรวจสอบวันที่พักและการจําหน่ายหน่วย
5. หากแขกย้ายไปตรวจสอบหน่วยก่อนหน้านี้ และคนที่พักด้วยกันในแต่ละช่วง

## ส่งรายการออก

ตรวจสอบกรองของคุณ ก่อนใช้ Excel หรือ PDF ออก การส่งออกของแขกครอบคลุม คําถามที่กรอง ไม่ใช่แค่หน้าที่เห็นได้สูงสุด 10,000 เส้น ลดระยะเวลาเพื่อผลที่ใหญ่กว่า

ถ้าการสร้าง PDF ล้มเหลว ส่งความผิดพลาดไปยังผู้บริหารของคุณ แทนที่จะส่งคําขอเดียวกันซ้ําซ้ํา ส่วนประกอบการสร้าง PDF ของเซอร์เวอร์อาจต้องการความสนใจ

คู่มือที่เกี่ยวข้อง: [เอกสารและแบบจําลอง](documents.md).
