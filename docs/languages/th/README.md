## วิธี ใช้ คู่มือ นี้

บางตัวเลือกอาจไม่มีขึ้นอยู่กับตําแหน่งของคุณ และสาขาโรงแรมที่คุณสามารถเข้าถึง ก่อนที่จะเปลี่ยนแปลงอะไรก็ได้ ตรวจสอบโรงแรมและสาขาโรงแรมที่เลือก

รูปภาพจอแสดงอินเตอร์เฟสแอพลิเคชั่นจริงกับข้อมูลปลอมสําหรับ Mavi Avlu Otel เงินเดือน วันที่และชื่อแขกเป็นตัวอย่าง ใช้ข้อมูลปัจจุบันในสมัครงานของคุณเอง เมื่อตัดสินใจ

การถ่ายจอยังคงมีอินเตอร์เฟสภาษาตุรกีเดิม คู่มือนี้อธิบายชื่อเมนูและการกระทําในภาษาเอกสารที่เลือก หัวข้อแต่ละรายละเอียดอธิบายขั้นตอน ผลการคาดหวัง และคู่มือที่เกี่ยวข้อง ชื่อไฟล์และลิงค์ยังคงอยู่ในภาษาอังกฤษในทุกฉบับภาษา
