# สิ่งอำนวยความสะดวกและสิ่งของในห้องพัก

เปิดหน้ากำหนดสิ่งอำนวยความสะดวก หรือส่วนคุณสมบัติในแบบฟอร์มแก้ไขห้องพักและสถานประกอบการ

![สิ่งอำนวยความสะดวกและสิ่งของ](../images/amenities.png)

## แยกประเภทข้อมูลให้ถูกต้อง

- สิ่งอำนวยความสะดวกระบุว่ามีคุณสมบัตินั้นหรือไม่ เช่น อุปกรณ์ห้องน้ำหรืออุปกรณ์ในห้องพัก
- รายการสิ่งของระบุวัตถุจริงและจำนวน
- เตียงจริงระบุรูปแบบที่พักและตำแหน่งที่นอน ต้องกำหนดแยกในส่วนจัดการเตียง

## เพิ่มคุณสมบัติให้ห้องพัก

1. ค้นหาหมวดหมู่และกลุ่มย่อยที่ถูกต้องในรายการสิ่งอำนวยความสะดวก
2. เปิดแก้ไขห้องที่ต้องการ
3. เลือกสิ่งอำนวยความสะดวกที่มีจริง และกรอกจำนวนสิ่งของตามจริง
4. บันทึกแบบฟอร์ม
5. เปิดห้องอีกครั้งเพื่อตรวจสอบว่าตัวเลือกและจำนวนยังคงอยู่

กำหนดสิ่งอำนวยความสะดวกส่วนกลางในระดับสถานประกอบการ ไม่ใช่ทำให้ดูเหมือนว่ามีในทุกห้อง อ่างน้ำร้อนส่วนกลางกับอ่างน้ำร้อนส่วนตัวภายในห้องเป็นคนละคุณสมบัติ

## รายการมาตรฐาน การกำหนดให้ห้อง และสต๊อก

รายการมาตรฐานมีคำนิยามที่ใช้ร่วมกัน ผู้ใช้ที่มีสิทธิ์สามารถใช้คำนิยามเฉพาะของธุรกิจได้ด้วย การมีสินค้าในรายการไม่ได้หมายความว่าสินค้านั้นถูกกำหนดให้ห้องแล้ว

การเปลี่ยนจำนวนสิ่งของในห้องไม่ใช่การรับสินค้าเข้าคลัง ให้ใช้[บันทึกธุรกรรม](../finance/transactions.md)และรายงานสต๊อกที่เกี่ยวข้องเพื่อติดตามการรับเข้าและการใช้สินค้า ใช้รหัสสินค้าเดิมแทนการสร้างสินค้าซ้ำด้วยชื่อสะกดต่างกัน
