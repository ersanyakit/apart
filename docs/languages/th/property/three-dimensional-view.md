# มุมมอง 3 มิติ

เปิด 3D View ในโรงแรมปฏิบัติการ

![มุมมอง 3 มิติ](../images/property-3d.png)

## ค้นหาสาขาโรงแรม

1. เลือกสาขาโรงแรมที่เหมาะสม และเปิด 3D View
2. ใช้ปุ่มพื้นในสถานการณ์ เพื่อเลือกพื้น
3. ใช้พื้นแยกและกําแพงควบคุมเพื่อเปิดให้เห็นภายใน
4. เลือกห้องหรือเตียง เพื่อตรวจสอบข้อมูลและสถานะการพัก
5. ติดตามการดําเนินการที่สามารถใช้ได้ที่หน้าจอการจองที่เกี่ยวข้อง
6. ใช้ Refresh เพื่อหาสถานะล่าสุด

## รับแปลสถานการณ์

ชั้น ห้องและเตียงมาจากนิยามสาขาโรงแรม โครงการที่หายไปหรือซับซ้อนกัน สามารถจัดตั้งตามแผนการ และเตียงในห้องนั้นถูกจัดตั้งโดยอัตโนมัติ นี่ไม่ใช่เครื่องวัดสถาปัตยกรรม หรือเครื่องแก้ไขแผนที่พื้น การสํารวจสถานการณ์ไม่ได้เปลี่ยนสมาธิที่บันทึกไว้

การแบ่งปันภาพของแขกของห้องจองข้ามเตียงไม่ได้สร้างการมอบเตียงจริง ผู้เข้าพักที่ไม่มีเพศที่กําหนดใช้ตัวละครที่ไม่เป็นตัวละคร เพศไม่ได้ถูกสรุปจากชื่อ

## หน่วยหายไปหรือดูผิด

ตรวจสอบสาขาโรงแรม ชั้น ความสัมพันธ์ห้อง ความหมายของเฟอร์นิเจอร์เตียงจริง และโหมดเช่า เตียงตามแผนที่ที่เลือกเป็นเฟอร์นิเจอร์ห้องจัดสรรไม่สร้างหน่วยจองแยก

ถ้าบราwser ไม่สามารถเปิดฉาก 3D ได้ ใช้การทดลองใหม่ หรือการเลือกหน่วยตามข้อความ คุณสามารถดําเนินการประจําวันได้จาก [โบอร์ดสถานะห้อง](../operations/room-board.md).
