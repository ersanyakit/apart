# สถานประกอบการ ชั้น ห้องพัก และอพาร์ตเมนต์

โรงแรมเปิดสาขา โปรไฟล์และพื้นและห้องนิยาม

![ความหมายของสาขาและหน่วยโรงแรม](../images/property.png)

## วางแผนโครงสร้าง

ระดับชั้นสูงคือโรงแรม → สาขาโรงแรม / สาขาสาขา → ชั้นและหน่วยงาน หน่วยหนึ่งอาจเป็นอพาร์ทเมนต์ ห้องนอน หรือเตียง ห้องพักอาจอยู่ในอพาร์ทเมนต์ และเตียงก็อาจอยู่ในห้องพัก ชั้นฟิสิกและหน่วยแม่เป็นความสัมพันธ์ที่แยกกัน ห้องในอพาร์ทเมนต์หลายชั้นอาจอยู่บนชั้นที่แตกต่างกัน

## สร้างชั้นและหน่วย

1. เลือกสาขาโรงแรม และเปิดนิยามชั้นและห้อง
2. กําหนดรหัสพื้น แสดงชื่อและลําดับ อย่าใช้รหัสชั้นอีกครั้งในสาขาโรงแรมเดียวกัน
3. ในฟอร์มหน่วย เลือกประเภทอพาร์ทเมนต์ ห้องหรือห้องพัก และใส่รหัสของมัน
4. มอบพื้นที่ที่เหมาะสม และถ้าจําเป็น หน่วยแม่
5. เติมแบบเลือกแบบเช่าในรูปห้อง
6. เพิ่มเฟอร์นิเจอร์เตียงจริง สิ่งอํานวยความสะดวกและข้อมูลประกอบสินค้า
7. เก็บและตรวจสอบหน่วยในรายการนิยามและภาพการทํางานที่เกี่ยวข้อง

## ให้เช่าห้องหรือเตียงส่วนตัว?

| การเลือก | ผล |
| --- | --- |
| ห้องทั้งห้อง | ห้องคือหน่วยจอง; เฟอร์นิเจอร์เตียงจริงของมันอธิบายการวางแผนห้อง |
| เตียงส่วนตัว | ช่องเตียงที่เชื่อมโยงจะนําเสนอแยกกัน |

รูปแบบเช่าห้องพักยังใช้กับเตียงที่เพิ่มขึ้นในภายหลัง การเปลี่ยนแปลงที่ส่งผลต่อการจองที่ดําเนินอยู่ อาจถูกปิด

## ปรับเปลี่ยนหรือลบความนิยาม

ปรับบันทึกเพื่อตรวจสอบพื้นและหน่วยผู้ปกครอง ถ้าการเปลี่ยนแปลงทางโครงสร้างจะส่งผลกระทบต่อการจองที่ได้รับการยืนยันหรือมีสิทธิภาพ, ก่อนอื่นก็ย้ายมันไปตามที่เหมาะสม หรือพิจารณายกเลิกสําหรับจองที่ไม่ได้จอง ติดตามการยืนยันของสมัคร แทนที่จะเลี่ยงมัน

สําหรับการดําเนินการเป็นจํานวนมาก ตรวจสอบรหัสหน่วยทั้งหมดที่เลือก ตรวจสอบกรองและแถวที่เลือกก่อนการใช้การเปลี่ยนแปลงต่อหลายหน่วย
