# เตียงจริงและเตียงสองชั้น

เฟอร์นิเจอร์เตียงจริงอธิบายเฟอร์นิเจลและความสามารถของมัน พื้นที่นอนที่สามารถจองได้แยกกันคือหน่วยเช่า การเลือกเตียงในสถานที่อํานวยความสะดวกหรือประวัติสินค้าไม่ได้สร้างพื้นที่เฟอร์นิเจอร์เตียงจริงที่สามารถจองได้

## กําหนดเตียง

1. เปิด เฟอร์นิเจอร์เตียงจริง ความหมายจากการจัดการเตียงภายในความหมายของพื้นและห้อง
2. เลือกเตียงเดี่ยว, เตียงคู่ หรือเตียงที่มีระดับ 2, 3 หรือ 4 เป็นการตั้งค่าก่อน
3. ตรวจสอบรหัสเตียง ห้องและพื้น
4. ปรับรูปแบบเตียง โครงสร้างทางกายภาพ จํานวนระดับและขนาด
5. ตรวจสอบรหัสสถานที่ ทุกที่ ตําแหน่งและความสามารถของแขก
6. รีวิว Active และ reservable โดยแยกพร้อมกับโหมดเช่าห้องพัก
7. เลือก Save Bed

การเลือกค่าตั้งต้นเป็นเพียงการกรอกข้อมูลในช่องต่าง ๆ ต้องบันทึกจึงจะสร้างรายการได้

## ตัวอย่างของเตียงเบค

เตียงสองชั้นมีที่นอนจริงสองตำแหน่ง คือชั้นบนและชั้นล่าง ใช้รหัสแยกสำหรับชั้นล่างและชั้นบน เตียงคู่หนึ่งเตียงอาจเป็นที่นอนหนึ่งตำแหน่งที่รองรับสองคน จำนวนตำแหน่งที่นอนกับจำนวนคนที่รองรับได้เป็นคนละค่า

## เพิ่มเตียงจากฟอร์มห้อง

โปรแกรมสร้าง / แก้ไขห้องให้คุณเลือกประเภทและจํานวนเตียง เหล่านี้จะเพิ่มขึ้นกับเฟอร์นิเจอร์เตียงจริงที่มีอยู่ เพื่อเปลี่ยนเตียงที่มีอยู่ ปรับบันทึกของมัน แทนที่จะเพิ่มอีกเตียง

หลังจากบันทึก, ตรวจสอบรหัสเตียงในรายการนิยามและการวางแผนใน [มุมมอง 3 มิติ](three-dimensional-view.md). หากเตียงว่างจากบอร์ดการขาย ตรวจสอบสถานที่เช่าห้องพัก และสามารถจองเตียงได้แยกกันได้หรือไม่
