# ขั้นตอนการทำงานของกะต้อนรับ

## เริ่ม shift

1. ลงทะเบียนด้วยบัญชีของคุณเอง และยืนยันสาขาโรงแรมที่เลือก
2. อ่านงานด่วนและกําลังดําเนินอยู่บนแผ่นบันทึกการรับ
3. ตรวจสอบหน่วยงานที่สกปรก ไม่เรียบร้อย และซ่อมแซมที่ห้อง
4. ดูการเดินทางและการเดินทางของวันนี้ในปฏิทินการพักและรายการจอง
5. คิดถึงการออกเดินทางในช่วงสาย พร้อมกับห้องพักที่กําหนดไว้สําหรับการเดินทางกลับในวันเดียวกัน

## กลางวัน

จัดการจองใหม่ [กระบวนการทํางานในการจอง](../operations/reservations.md). ตรวจสอบแขกที่มาในจองที่มีอยู่แทนที่จะจองครั้งที่สอง ใช้บริการเปลี่ยนห้องของห้องพักในการย้ายแขก เพิ่มบริการเพิ่มเติมไปยังบัญชีชําระค่าเช่าที่ถูกต้องในการจอง

ปรับปรุงสถานะการทําความสะอาดเมื่อการทําความบริสุทธิ์เสร็จ ไม่เคยระบุห้องที่ไม่ได้เตรียมไว้ว่า สะอาด เพียงเพื่อผ่านข้อความยืนยัน

## ตอนออกเดินทาง

1. เปิด [บัญชีชําระเงินของแขกก่อนเช็คเอาท์](../operations/check-in-out.md).
2. ตรวจสอบค่าใช้จ่ายที่พักและบริการ, การชําระเงินที่ได้รับ, การคืนเงินและการฝากเงินกัน
3. เติมบันทึกที่ต้องการภายในอนุญาตของคุณ
4. หลังจากยืนยันการเช็คออก ตรวจสอบสถานการณ์การพักและห้องพัก
5. ถ้าห้องต้องการการเตรียมตัว

## การส่ง

จัดบันทึกงานที่ยังไม่เสร็จ การคาดว่าจะมาถึง และสมดุลเงินที่ต้องการการติดตาม หากคุณมีการเข้าถึงรายงานการทํางานและรายงานเงินสด เทียบการเคลื่อนไหวเงินสดที่บันทึกไว้กับเงินสดที่นับจริง สมัครออกเมื่องานเสร็จ

คู่มือที่เกี่ยวข้อง: [บันทึกการรับ](../operations/reception-notes.md).
