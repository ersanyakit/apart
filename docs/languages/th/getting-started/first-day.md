# วันแรก: เตรียมสถานประกอบการของคุณ

หน้านี้เป็นสําหรับผู้บริหารที่บัญชีและธุรกิจของพวกเขาถูกสร้างขึ้นโดยทีมงานเทคนิค หากสาขาโรงแรมใช้งานแล้ว ตรวจสอบบันทึกที่มีอยู่ แทนที่จะสร้างห้องหรือเตียงสองตัว

## แนะนําการตั้ง

1. เปิดโปรไฟล์สาขาโรงแรม และตรวจสอบข้อมูลทางธุรกิจและสาขาของโรงแรม
2. ในความหมายของพื้นและห้อง, สร้างพื้นและมอบห้องและอพาร์ทเมนต์ให้กับพวกเขา.
3. สําหรับแต่ละห้อง เลือกให้เช่าห้องทั้งห้อง หรือเตียงส่วนตัว
4. กําหนดเฟอร์นิเจอร์เตียงจริง สําหรับโรงแรมพักเช็คระดับชั้นเตียง และพื้นที่เตียงที่นําเสนอให้แยกกัน
5. อุปกรณ์อํานวยความสะดวกของห้องพักและโรงแรมและจํานวนประกอบสินค้าในฟอร์มการแก้ไขที่เกี่ยวข้อง
6. ตรวจสอบบทบาทบุคลากรและการเข้าถึงสาขาโรงแรมในนิยามบุคลากรี
7. เตรียมข้อมูลธุรกิจและเวิชั่นภาษาที่ต้องการของเวิชาการเอกสาร
8. ตรวจสอบสถานการณ์การทําความสะอาดและการดูแลของห้อง

![ความหมายของพื้นและห้อง](../images/property.png)

## ก่อนการจองครั้งแรก

| เช็ค | ผลที่คาดหวัง |
| --- | --- |
| สาขาและชั้นโรงแรม | ห้องนี้ปรากฏอยู่ใต้สาขาโรงแรมและชั้นที่เหมาะสม |
| รูปแบบเช่า | ห้องหรือเตียงที่คุณตั้งใจเช่าสามารถเลือกได้ |
| การทําความสะอาด | ยูนิตพร้อมแล้ว และมีเครื่องหมาย "สะอาด" |
| วันที่ | การเดินทางและการเดินทางถูกต้อง โดยไม่มีการจองที่ขัดแย้ง |
| พนักงาน | ลูกจ้างแต่ละคนสามารถเข้าถึงหน้าที่ต้องการได้โดยใช้บัญชีของตนเอง |

สําหรับการฝึกอบรม ใช้สภาพทดสอบที่กําหนดโดยผู้จัดการของคุณ เพื่อให้การทําธุรกิจแบบตัวอย่างไม่ผสมกับบันทึกธุรกิจสด
