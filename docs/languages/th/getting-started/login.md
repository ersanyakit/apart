# เข้าสู่ระบบและทำความรู้จักหน้าจอ

## ก่อนที่คุณจะเริ่ม

สอบถามผู้บริหารของคุณเกี่ยวกับที่อยู่ของสมัครงาน ธุรกิจที่คุณควรเข้าถึง และข้อมูลบัญชีส่วนตัวของคุณ ไม่มีรหัสผ่านการแสดงตัวอย่างที่แบ่งปันในคู่มือนี้ ใช้บัญชีที่ได้รับจากธุรกิจของคุณ

## สมัครเข้า

1. เปิดที่อยู่การสมัคร หากคุณอยู่ในเว็บไซต์สาธารณะ ใช้ลิ้งการลงทะเบียน
2. เลือกโรงแรมที่คุณจะทํางานกับ
3. เลือกบัตรบุคลากรของคุณเอง
4. กรอกรหัสผ่านและกดปุ่มการลงทะเบียน
5. ตรวจสอบชื่อโรงแรมและสาขาโรงแรมบนหน้าจอต่อไป หากคุณทํางานที่หลายสาขาโรงแรม เลือกที่ถูกต้อง ก่อนที่จะสร้างบันทึก

หากบัตรบุคลากรคุณหายไป ก่อนอื่น ตรวจสอบธุรกิจที่เลือก หากยังหายไป ขอผู้บริหารของคุณตรวจสอบบัญชีและการเข้าถึงสาขาโรงแรมของคุณ อย่าใช้บัตรของพนักงานอื่น เพื่อเลี่ยงความผิดพลาดคําว่าผ่านผ่าน

## ส่วนส่วนของอินเตอร์เฟส

- เมนูทางซ้ายจะเปิดแผ่นสถานการณ์ห้องพัก, ตารางการพัก, การจองและหน้าทํางานอื่นๆ
- ตัวเลือกโรงแรมและสาขาโรงแรมจะระบุสถานการณ์ธุรกิจสําหรับงานของคุณ
- หัวหน้าหน้าหน้ามีการค้นหา, การกรองและการกระทํา ขยายหัวข้อที่ล้มเหลว เพื่อเปิดเผยการควบคุมที่ซ่อนอยู่
- ข่าวสารด้านบนขวารายงานการบันทึกหรือความผิดพลาดสําเร็จ สาขาที่หายไปในฟอร์มแสดงอยู่ในฟอร์ม
- บนหน้าจอเล็ก เปิดเมนูทางเดินมือถือ เพื่อเข้าถึงหน้าทํางานเดียวกัน

หลังจากบันทึก, ตรวจสอบแจ้งความสําเร็จและรายการที่ปรับปรุง หากเกิดความผิดพลาดในเครือข่าย ตรวจสอบว่าบันทึกถูกสร้างหรือไม่ ก่อนส่งการปฏิบัติงานเดียวกันอีกครั้ง
