# คำศัพท์

| ระยะเวลา | ความหมาย |
| --- | --- |
| โรงแรม /ธุรกิจ | ธุรกิจหลักที่สาขาและอนุญาตโรงแรมเป็นส่วนหนึ่ง |
| สถานประกอบการ / สาขา | สถานที่ที่การดําเนินการ; บันทึกถูกกําหนดให้กับสาขาโรงแรมที่คัดเลือก |
| หน่วย | คอนโด ห้องนอน หรือเตียงในโครงสร้างเช่า |
| เตียงจริง | เฟอร์นิเจอร์เตียงหรือเตียง; ไม่จําเป็นต้องเป็นหน่วยที่สามารถเช่าได้แยก |
| ที่นอนแต่ละตำแหน่ง | สถานที่หรือระดับในโครงสร้างทางกายภาพ ความสามารถของแขกถูกกําหนดแยก |
| จองที่ยืนยัน | การจองที่บันทึกแล้วแต่ยังไม่ได้เช็กอิน |
| การเดินทาง/การเดินทางที่วางแผน | วันที่คาดหมายสําหรับการจอง |
| การเดินทาง/การเดินทางจริง | เวลาที่การเช็คอินและการเช็คเอาท์เกิดขึ้นจริง |
| การจัดสรร | ยูนิตที่จองไว้ในช่วงเวลาที่ระบุ |
| บัญชีห้องพัก | สรุปบัญชีค่าบริการและรายการรับจ่ายของการจอง |
| รายได้ค้างรับตามบริการ | ค่าบริการที่ให้บริการในระยะเวลาหนึ่ง การจ่ายเงินอาจมาถึงในวันอื่น |
| เงินที่รับแล้ว | เงินที่ได้รับจากธุรกิจ |
| ค่าใช้จ่าย / การจ่ายเงิน | ค่าใช้จ่ายคือต้นทุนที่เกิดขึ้น ส่วนการจ่ายเงินคือเงินที่ออกจากธุรกิจ |
| เงินประกัน | เงินประกันที่คืนตามเงื่อนไข ไม่ใช่รายได้ค่าที่พัก |
| หน่วยที่พัก-คืน | ใช้งานหรือขายของหน่วยเดียวในคืนเดียว |
| อัตราเข้าพักตามความจุจริง | ใช้หน่วยคืนเมื่อเทียบกับความสามารถทางกายภาพ |
| อัตราเข้าพักตามความจุที่ขายได้ | การใช้งานที่เกี่ยวข้องกับความสามารถที่สามารถขายได้ |
| ADR | รายได้หารด้วยจำนวนคืนที่ขายได้ของประเภทเดียวกัน |
| RevPAR | รายได้หารด้วยจำนวนคืนที่มีไว้ขายของประเภทเดียวกัน |
| ผลการดำเนินงาน | รายได้หักค่าใช้จ่ายดำเนินงานในรายงาน ไม่ใช่กำไรสุทธิทางบัญชี |
| หนังสือบันทึก | นำออกจากมุมมองประจำวัน ไม่ใช่การลบถาวร |

รับแปลตัวกระบุสถานะแต่ละครั้ง พร้อมกับวันและประเภทของบันทึก ดูสิ [การใช้รายงาน](../finance/reports.md) สําหรับรายละเอียดการคิดเลข
