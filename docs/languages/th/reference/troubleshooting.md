# การแก้ไขปัญหา

## ห้องพักสะอาด แต่ที่เช็คอินบอกว่ามันสกปรก

1. เปรียบเทียบรหัสหน่วยในความผิดพลาดกับบัตร มันอาจหมายถึงสาขาโรงแรมอื่น หรือเตียงที่เชื่อมต่อกัน
2. ยืนยันสาขาโรงแรมและจอง
3. อัพเดทและตรวจสอบตราการทําความสะอาดปัจจุบัน
4. ถ้าห้องถูกเตรียมแล้ว ยืนยันว่าการช่วย Clean ได้สําเร็จ
5. สําหรับการจดหมายก่อนหน้านี้ ตรวจสอบการพักอีกครั้งระหว่างการเดินทางมาถึงและการเดินทางตามแผน
6. ถ้าความผิดพลาดยังคงอยู่ ให้ผู้จัดการของคุณรหัสหน่วย วันที่วางแผน เวลาการทํางาน และข้อความผิดพลาดแม่นยํา

อย่าซ้ําการจอง หรือปิดการพักอีกครั้งโดยบังเอิญ เพื่อเลี่ยงความผิดพลาด

## ห้องว่างไม่สามารถเลือกได้

ตรวจสอบระยะเวลาเต็ม, รูปแบบเช่า, ความสามารถในการขายและการจองของหน่วยผู้ปกครอง / เด็ก ตรวจสอบผู้เข้าพักที่ทํางาน ที่ไปช้า ห้องว่างในวันนี้ ไม่ได้หมายความว่ามันว่างตลอดช่วงเวลาที่เลือก

## มีการจองหรือหมายเลขหายไป

ก่อนอื่น ตรวจสอบสาขาโรงแรม วันที่ สถานการณ์ ชั้นและกรองการค้นหา สําหรับข้อความ, ตรวจสอบยังเก็บของและโหลดเพิ่มเติม. หากบันทึกยังหายไป ดูการแจ้งและถ้าได้รับอนุญาต ดูบันทึกระบบ

## รายงานทั้งหมดแตกต่างจากสิ่งที่ฉันคาดหวัง

ตรวจสอบระยะเวลา การเงิน สาขาโรงแรม และประเภทรายงาน การแยกรายได้จากการจ่ายที่ได้รับและค่าใช้จ่ายจากการจ่ายออก ยืนยันว่าการชําระเงินล่วงหน้าที่เก่าไม่ได้ถูกบันทึกสองครั้ง ค่าใช้จ่ายที่ไม่ได้จําหน่ายส่งผลต่อการเปรียบเทียบระดับหน่วย การนิยามฟิสิกส์ปัจจุบันส่งผลต่อคํานวณการใช้งาน

## ปุ่มการเช็คเอาท์ปิด

รอจนกว่าบัญชีชําระค่าแขกจะโหลด และการประหยัดบริการจะจบ ยืนยันว่าการจองยังจองอยู่ หากต้องการการรับรองอัตราสมดุลที่ยังคงอยู่ ต้องตรวจสอบอัตราต่อรองก่อนที่จะยอมรับ

## 3D View ไม่เปิด

ใช้ทางเลือกทดลองใหม่ ถ้าบราwser ไม่สามารถแสดงฉากได้ ใช้การเลือกหน่วยที่ใช้เนื้อหา หรือกระดานสถานะห้อง ถ้าเพียงสาขาโรงแรมเดียวเท่านั้นได้รับผลกระทบ ตรวจสอบห้องและความหมายของเฟอร์นิเจอร์เตียงจริง

## ภาษาเอกสารว่างเปล่า หรือรุ่น PDFล้มเหลว

ตรวจสอบว่าภาษาที่เลือกมีหัวข้อและร่างแบบอย่าง สําหรับความผิดพลาดของ PDF ผู้บริหารอาจต้องตรวจสอบส่วนประกอบ PDF ด้านเซอร์เวอร์ การพิมพ์โปรแกรมปฏิทิน / รายงานในบrowser ต่างจากเอกสาร PDF ของแขก / เอกสารที่สร้างขึ้นในเซอร์เวอร์

## ฉันควรใส่อะไรในคําขอสนับสนุน?

เผยชื่อหน้า, สาขาโรงแรมและรหัสหน่วยงาน, เวลาปฏิบัติงาน, ผลที่คาดหวัง, ผลจริงและข้อความผิดพลาด. ซ่อนตัวตนผู้เข้าพัก ไม่จําเป็น ข้อมูลการติดต่อและการชําระเงินในภาพจอ อย่าใส่ปัสริดของคุณ
