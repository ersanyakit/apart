# การเชื่อมต่อ GitBook สำหรับผู้ดูแลเอกสาร

หน้านี้สําหรับคนที่ตีพิมพ์หนังสือแนะนํา พนักงานต้อนรับไม่จําเป็นต้องทําขั้นตอนเหล่านี้

## โครงสร้างสํานักเก็บของ

- รากเก็บของ `gitbook-docs.yaml` บันทึกข้อมูล และ แผนที่ภาษาแต่ละภาษา ชื่อไฟล์ของมันไม่ได้เริ่มด้วยจุด
- เนื้อหาตุรกียังคงอยู่ใน `docs/`. ฉบับแปลได้ใน `docs/languages/` ตามรหัสภาษาของพวกเขา
- หนังสือภาษาแต่ละภาษา มีภาษาของมันเอง `.gitbook.yaml`, `README.md`, `SUMMARY.md` และ `images/` แผ่น
- ชื่อไฟล์หัวข้ออยู่ในภาษาอังกฤษในทุกฉบับ รูปจันทร์ยังคงมีอินเตอร์เฟสภาษาตุรกี

การจัดตั้งตาม [เอกสาร Git Sync อย่างเป็นทางการ](https://gitbook.com/docs/docs-as-code/git-sync/content-configuration). การเตรียมไฟล์เองไม่ได้เชื่อมต่อหรือตีพิมพ์เว็บ GitBook

## เชื่อมสมุด

1. ยืนยันว่าไฟล์คู่มือทั้งหมดถูกประกอบและถูกผลักไปยังสาขา GitHub ที่คุณตั้งใจจะใช้
2. เปิดการเชื่อมต่อ Git Sync สําหรับเว็บเอกสารใน GitBook
3. เลือกสํานักเก็บสินค้าและสาขา ปล่อยบันทึกโครงการว่าง หรือใช้งาน `./`. การตั้งค่าเว็บไซต์อยู่ที่รากของสํานักเก็บข้อมูล และนําแผนที่ภาษาแต่ละภาษาไปยังโฟลเดอร์ของตัวเอง
4. สําหรับการสอดคล้องครั้งแรก นําเนื้อหา GitHub ที่มีอยู่เข้า GitBook หากคุณมีเนื้อหาใน GitBook แล้วดูทิศการสอดคล้องที่เลือก
5. ดูหน้าแรกการตีพิมพ์ภาษา การเรียงลําดับหน้า รูปภาพ และลิงค์ภายใน
6. กําหนดที่อยู่โฆษณาและการตั้งค่าเข้าใช้งานในบัญชีของคุณ แล้วโฆษณามาพร้อมแล้ว

## ความผิดพลาดการตั้งค่า

ถ้า GitBook รายงานว่า `gitbook-docs.yaml` ไม่อยู่บนสาขา ตรวจสอบว่าไฟล์ที่มีชื่อถูกต้องอยู่ที่รากของสาขาระยะไกลที่เลือก รายงานในพื้นที่เองก็ไม่เพียงพอ ไม่เหมือนกัน `.gitbook-docs.yaml` หรือ `.gitbook.yaml` แทนการตั้งค่าสถานที่ หลังจากดันไฟล์แล้ว ลองอีกครั้งด้วยสาขาเดียวกัน

ไม่ตั้งบันทึกโปรแกรมเป็น `docs` สําหรับการตั้งค่านี้ ค่าใช้งานของไดเรอคเตอร์ภาษาแต่ละแบบที่ถูกแผนที่ `root: ./` ในส่วนของ `.gitbook.yaml` รายงาน รักษากุญแจพื้นที่ที่มีอยู่คงหลังการสอดคล้อง; ใช้สนามชื่อในการเปลี่ยนชื่อ

## รักษาการแปล

เมื่อการกระทําหรือหน้าจอเปลี่ยนแปลง ปรับปรุงหน้าที่ตรงกันในทุกภาษา รายชื่อหน้าใหม่แต่ละครั้งในฉบับนั้น `SUMMARY.md`. รักษาลิงค์ภาพเป็นส่วนของ และภายในโฟลเดอร์ภาษาที่ถูกแผนที่ เพื่อให้ GitHub และ GitBook สามารถแก้ไขมันได้

ปรับปรุงภาพจอพร้อมกับคําแนะนํา รักษาการปรับแต่ง README ในสมุดเก็บข้อมูลเมื่อ Git Sync ได้เปิดให้ใช้ ไม่ต้องเอกสารคุณสมบัติที่ไม่มีหรือที่อยู่ประจําสดที่ไม่ทํางาน
