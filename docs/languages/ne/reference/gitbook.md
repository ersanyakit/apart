# कागजात प्रशासकका लागि GitBook जडान निर्देशिका

यो पृष्ठ पुस्तिका प्रकाशित गर्ने व्यक्तिको लागि हो। रिसेप्शन स्टाफले यी चरणहरू गर्न आवश्यक छैन।

## भण्डार संरचना

- भण्डार-मूल `gitbook-docs.yaml` साइटको वर्णन गर्दछ र प्रत्येक भाषालाई यसको कागजात निर्देशिकामा नक्सा गर्दछ। यसको फाईल नाम एउटा बिन्दुबाट सुरु हुँदैन।
- टर्कीको सामग्री अझै पनि `docs/`. अनुवादित संस्करणहरू `docs/languages/` तिनीहरूको भाषा कोडहरू।
- प्रत्येक भाषा निर्देशिकाको आफ्नै छ `.gitbook.yaml`, `README.md`, `SUMMARY.md` र `images/` फोल्डर।
- विषय फाइल नामहरू सबै संस्करणहरूमा अंग्रेजीमा छन्। स्क्रिनशटमा टर्कीको इन्टरफेस राखिएको छ।

कन्फिगरेसन निम्नानुसार छ: [आधिकारिक Git Sync कागजात](https://gitbook.com/docs/docs-as-code/git-sync/content-configuration). फाइलहरू तयार पार्दा GitBook साइटहरू जडान वा प्रकाशित हुँदैनन्।

## भण्डारलाई जडान गर्नुहोस्

1. जाँच गर्नुहोस् कि सबै गाइड फाइलहरू प्रतिबद्ध छन् र तपाईंले प्रयोग गर्ने GitHub शाखामा धकेल्नुहोस्।
2. GitBook मा कागजात साइटको लागि Git Sync जडान खोल्नुहोस्।
3. भण्डार र शाखा छनौट गर्नुहोस्। प्रोजेक्ट डाइरेक्टरी खाली छोड्नुहोस् वा प्रयोग गर्नुहोस् `./`. साइट कन्फिगरेसन रिपोजिटरी रूटमा छ र प्रत्येक भाषालाई यसको आफ्नै फोल्डरमा नक्सा गर्दछ।
4. प्रारम्भिक समक्रमणका लागि, GitHub मा अवस्थित सामग्री आयात गर्नुहोस्। यदि तपाईंसँग GitBook मा पहिले नै सामग्री छ भने, छनौट गरिएको सिंक्रोनाइजेशन दिशा समीक्षा गर्नुहोस्।
5. भाषा संस्करणहरू, पृष्ठ क्रम, छविहरू र आन्तरिक लिंकहरू पूर्वावलोकन गर्नुहोस्।
6. तपाईंको खातामा प्रकाशन ठेगाना र पहुँच सेटिंग्स सेट गर्नुहोस्, त्यसपछि तयार हुँदा प्रकाशित गर्नुहोस्।

## कन्फिगरेसन त्रुटि

यदि GitBook ले रिपोर्ट गरेको छ कि `gitbook-docs.yaml` शाखामा अवस्थित छैन, जाँच गर्नुहोस् कि सही नाम राखिएको फाइल चयन गरिएको रिमोट शाखाको जरामा अवस्थित छ। स्थानीय फाइल मात्र पर्याप्त छैन। न त `.gitbook-docs.yaml` न त `.gitbook.yaml` साइट कन्फिगरेसनको सट्टा। फाइल थिचेपछि, फेरि त्यही शाखा प्रयोग गर्नुहोस्।

प्रोजेक्ट डाइरेक्टरीमा सेट नगर्नुहोस् `docs` यो कन्फिगरेसनको लागि। प्रत्येक नक्सा गरिएको भाषा निर्देशिकाले प्रयोग गर्दछ `root: ./` आफ्नो `.gitbook.yaml` फाइल। समक्रमण पछि अवस्थित स्पेस कुञ्जीहरू स्थिर राख्नुहोस्; नाम परिवर्तनको लागि शीर्षक फिल्डहरू प्रयोग गर्नुहोस्।

## अनुवाद कायम राख्नुहोस्

जब कुनै कार्य वा स्क्रिन परिवर्तन हुन्छ, प्रत्येक भाषा संस्करणमा मिल्दो पृष्ठ अपडेट गर्नुहोस्। प्रत्येक नयाँ पृष्ठलाई त्यस संस्करणमा एक पटक सूचीबद्ध गर्नुहोस् `SUMMARY.md`. छवि लिङ्कहरू सापेक्ष र नक्सा गरिएको भाषा फोल्डर भित्र राख्नुहोस् ताकि GitHub र GitBook तिनीहरूलाई समाधान गर्न सक्दछ।

निर्देशनहरूसँगै स्क्रिनशटहरू अपडेट गर्नुहोस्। Git Sync सक्षम हुँदा README सम्पादनहरू भण्डारमा राख्नुहोस्। अनुपलब्ध सुविधाहरू वा गैर-कार्यात्मक प्रत्यक्ष डेमो ठेगानाहरू कागजात नगर्नुहोस्।
