# शब्दावली

| अवधि | अर्थ |
| --- | --- |
| होटल / व्यवसाय | मुख्य व्यवसाय जुन होटल शाखाहरू र अनुमतिहरू सामेल छन्। |
| आवास स्थल / शाखा | स्थान जहाँ सञ्चालनहरू गरिन्छ; रेकर्डहरू चयनित होटल शाखाको दायरामा छन्। |
| इकाई | भाडा संरचनामा एक अपार्टमेन्ट, कोठा, निदालय वा ओछ्यान। |
| भौतिक ओछ्यान | बेड वा बेक फर्नीचर; अनिवार्य रूपमा छुट्टै भाडामा लिने इकाई होइन। |
| ओछ्यानको स्थान | भौतिक संरचनामा स्थान वा स्तर; अतिथि क्षमता छुट्टै परिभाषित गरिएको छ। |
| पुष्टि भएको आरक्षण | सुरक्षित गरिएको तर चेक-इन नभएको बुकिङ। |
| नियोजित आगमन/प्रस्थान | आरक्षणको लागि अपेक्षित मितिहरू। |
| वास्तविक आगमन/प्रस्थान | चेक-इन र चेक-आउटको समय वास्तवमा हुन्छ। |
| विनियोजन | एक निश्चित समय अन्तरालमा आरक्षण द्वारा कब्जा गरिएको इकाई। |
| कोठाको खाता | बुकिङका शुल्क, सेवा र भुक्तानी गतिविधिको खाता सारांश। |
| अर्जित आम्दानी | एक अवधिमा प्रदान गरिएको सेवाको मूल्य; भुक्तानी अर्को मितिमा आउन सक्छ। |
| प्राप्त भुक्तानी | व्यवसायले प्राप्त गरेको पैसा। |
| खर्च / बाहिरिने भुक्तानी | खर्च भनेको लागेको लागत हो; भुक्तानी भनेको व्यवसायबाट बाहिरिएको रकम हो। |
| धरौटी | फिर्ताका सर्तसहित लिइएको धरौटी; आवास आम्दानी होइन। |
| एकाइ-रात | एक युनिटको प्रयोग वा बिक्री एक रातको लागि। |
| भौतिक क्षमताको उपयोग दर | भौतिक क्षमताको तुलनामा प्रयोग गरिएको एकाई-रातहरू। |
| बिक्रीयोग्य क्षमताको उपयोग दर | बिक्रीको लागि उपलब्ध क्षमताको तुलनामा प्रयोग। |
| एडीआर | एउटै उत्पादन प्रकारको आम्दानीलाई बिक्री भएका रातले भाग गरेको मान। |
| रेभपार् | एउटै उत्पादन प्रकारको आम्दानीलाई बिक्रीका लागि उपलब्ध रातले भाग गरेको मान। |
| सञ्चालन नतिजा | प्रतिवेदनमा आम्दानीबाट सञ्चालन खर्च घटाएको नतिजा; लेखाको खुद नाफा होइन। |
| अभिलेख | दैनिक दृश्यबाट हटाउने कार्य, स्थायी मेटाइ होइन। |

प्रत्येक स्थिति लेबलको साथ रेकर्डको मिति र प्रकारको व्याख्या गर्नुहोस्। हेर्नुहोस् [प्रतिवेदन प्रयोग गर्दै](../finance/reports.md) गणना विवरणहरूको लागि।
