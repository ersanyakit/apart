# शब्दावली

| अवधि | अर्थ |
| --- | --- |
| होटल / व्यवसाय | मुख्य व्यवसाय जिसमें होटल शाखाएं और अनुमतिएं शामिल हैं। |
| आवास स्थल / शाखा | ऑपरेशन किए जाने का स्थान; रिकॉर्ड का दायरा चयनित होटल शाखा तक पहुंचता है। |
| इकाई | किराए की संरचना में एक अपार्टमेंट, कमरा, छात्रावास या बिस्तर। |
| भौतिक बिस्तर | बिस्तर या सोफे का फर्नीचर; जरूरी नहीं कि अलग से किराए पर लेने योग्य इकाई हो। |
| बिस्तर का स्थान | भौतिक संरचना में एक स्थान या स्तर; अतिथि क्षमता अलग से परिभाषित की जाती है। |
| आरक्षण की पुष्टि | सहेजी गई बुकिंग जिसका अभी चेक-इन नहीं हुआ है। |
| नियोजित आगमन/प्रस्थान | आरक्षण के लिए अपेक्षित तिथियां। |
| वास्तविक आगमन/प्रस्थान | वे समय जब चेक-इन और चेक-आउट वास्तव में होता है। |
| आवंटन | एक विशेष समय अंतराल के दौरान एक आरक्षण द्वारा कब्जा की गई इकाई। |
| कमरे का खाता | बुकिंग के शुल्क, सेवाओं और भुगतान गतिविधियों का खाता सारांश। |
| अर्जित राजस्व | एक अवधि में प्रदान की गई सेवा का मूल्य; भुगतान किसी अन्य तिथि पर आ सकता है। |
| प्राप्त भुगतान | व्यवसाय द्वारा प्राप्त धन। |
| व्यय / किया गया भुगतान | व्यय वह लागत है जो बन चुकी है; भुगतान व्यवसाय से बाहर जाने वाली रकम है। |
| सुरक्षा जमा | शर्तों के अनुसार लौटाई जाने वाली जमा राशि; यह आवास का राजस्व नहीं है। |
| इकाई-रात | एक इकाई का उपयोग या बिक्री एक रात के लिए। |
| भौतिक क्षमता की अधिभोग दर | भौतिक क्षमता की तुलना में उपयोग की गई इकाई-रातें। |
| बिक्री योग्य क्षमता की अधिभोग दर | बिक्री के लिए उपलब्ध क्षमता के सापेक्ष उपयोग। |
| एडीआर | एक ही उत्पाद प्रकार के राजस्व को बिकी हुई रातों से भाग देना। |
| रेवपीएआर | एक ही उत्पाद प्रकार के राजस्व को बिक्री के लिए उपलब्ध रातों से भाग देना। |
| संचालन परिणाम | रिपोर्ट में राजस्व से संचालन व्यय घटाने का परिणाम; यह लेखांकन का शुद्ध लाभ नहीं है। |
| अभिलेख | दैनिक दृश्य से हटाना, स्थायी रूप से मिटाना नहीं। |

प्रत्येक स्थिति लेबल को रिकॉर्ड की तारीख और प्रकार के साथ व्याख्या करें। देखिये [रिपोर्ट का उपयोग करना](../finance/reports.md) गणना विवरण के लिए।
