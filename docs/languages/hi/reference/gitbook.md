# दस्तावेज़ प्रशासकों के लिए GitBook कनेक्शन मार्गदर्शिका

यह पृष्ठ मार्गदर्शिका प्रकाशित करने वाले व्यक्ति के लिए है। रिसेप्शन स्टाफ को इन चरणों को करने की आवश्यकता नहीं है।

## भंडारण संरचना

- रिपॉजिटरी रूट `gitbook-docs.yaml` साइट का वर्णन करता है और प्रत्येक भाषा को अपनी प्रलेखन निर्देशिका में मानचित्रित करता है। इसकी फ़ाइल का नाम एक बिंदु से शुरू नहीं होता है।
- तुर्की सामग्री में बनी हुई है `docs/`. अनुवादित संस्करण `docs/languages/` अपनी भाषा कोड के तहत।
- प्रत्येक भाषा निर्देशिका की अपनी है `.gitbook.yaml`, `README.md`, `SUMMARY.md` और `images/` फ़ोल्डर।
- सभी संस्करणों में विषय फ़ाइल नाम अंग्रेजी में हैं। स्क्रीनशॉट तुर्की इंटरफ़ेस को बनाए रखते हैं।

कॉन्फ़िगरेशन निम्नानुसार है [आधिकारिक Git Sync प्रलेखन](https://gitbook.com/docs/docs-as-code/git-sync/content-configuration). फ़ाइलों को तैयार करने से स्वयं GitBook साइट को कनेक्ट या प्रकाशित नहीं होता है।

## भंडारण को कनेक्ट करें

1. सत्यापित करें कि सभी गाइड फ़ाइलें प्रतिबद्ध हैं और आप उपयोग करने का इरादा GitHub शाखा में धक्का दिया.
2. GitBook में प्रलेखन साइट के लिए Git Sync कनेक्शन खोलें।
3. भंडार और शाखा चुनें। परियोजना निर्देशिका खाली या उपयोग छोड़ें `./`. साइट कॉन्फ़िगरेशन रिपॉजिटरी रूट पर है और प्रत्येक भाषा को अपने स्वयं के फ़ोल्डर में मैप करता है।
4. प्रारंभिक सिंक्रनाइज़ेशन के लिए, मौजूदा GitHub सामग्री को GitBook में आयात करें। यदि आपके पास पहले से ही GitBook में सामग्री है, तो चयनित सिंक्रनाइज़ेशन दिशा की समीक्षा करें।
5. भाषा संस्करणों, पृष्ठ क्रम, छवियों और आंतरिक लिंक का पूर्वावलोकन करें।
6. अपने खाते में प्रकाशन पते और पहुँच सेटिंग्स सेट करें, फिर तैयार होने पर प्रकाशित करें।

## कॉन्फ़िगरेशन त्रुटि गायब

यदि GitBook रिपोर्ट करता है कि `gitbook-docs.yaml` शाखा पर मौजूद नहीं है, जांचें कि सही ढंग से नामित फ़ाइल चयनित रिमोट शाखा की जड़ पर मौजूद है। स्थानीय फ़ाइल ही पर्याप्त नहीं है। न ही `.gitbook-docs.yaml` और न ही `.gitbook.yaml` साइट कॉन्फ़िगरेशन की जगह लेता है। फ़ाइल को दबाने के बाद, उसी शाखा के साथ पुनः प्रयास करें।

परियोजना निर्देशिका को सेट न करें `docs` इस कॉन्फ़िगरेशन के लिए। प्रत्येक मानचित्रित भाषा निर्देशिका उपयोग करता है `root: ./` अपने `.gitbook.yaml` फ़ाइल। सिंक्रनाइज़ेशन के बाद मौजूदा स्पेस कुंजी को स्थिर रखें; नाम बदलने के लिए शीर्षक फ़ील्ड का उपयोग करें।

## अनुवादों का रखरखाव

किसी क्रिया या स्क्रीन में परिवर्तन होने पर, प्रत्येक भाषा संस्करण में मिलान पृष्ठ को अद्यतन करें। उस संस्करण में एक बार प्रत्येक नए पृष्ठ को सूचीबद्ध करें `SUMMARY.md`. छवि लिंक को सापेक्ष और मानचित्रित भाषा फ़ोल्डर के अंदर रखें ताकि GitHub और GitBook उन्हें हल कर सकें।

निर्देशों के साथ स्क्रीनशॉट अपडेट करें। Git Sync सक्षम होने पर README संपादन को रिपॉजिटरी में रखें। अनुपलब्ध सुविधाओं या गैर कार्यात्मक लाइव डेमो पते का दस्तावेजीकरण न करें।
