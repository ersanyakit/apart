# रिपोर्ट सूची

आवेदन में 57 रिपोर्टें दी गई हैं। पहले उस प्रश्न की पहचान करें जिसका आप उत्तर देना चाहते हैं, फिर संबंधित रिपोर्ट और निर्धारित तिथि, होटल शाखा और मुद्रा फ़िल्टर चुनें।

## मुझे किस रिपोर्ट से शुरू करना चाहिए?

| प्रश्न | रिपोर्ट |
| --- | --- |
| व्यापार में क्या हो रहा है? | प्रबंधन का अवलोकन |
| राजस्व और प्राप्त धन का अंतर क्यों है? | दैनिक राजस्व और भुगतान |
| भुगतान के कौन से तरीके उपयोग किए जाते हैं? | भुगतान की विधि |
| कमरे या बिस्तरों का उपयोग कैसे किया जा रहा है? | दैनिक निवास, बिस्तर या अपार्टमेंट |
| आने वाले दिन कितने व्यस्त होंगे? | उपयोग में आने वाले कमरों का भविष्य का अनुपात |
| लागतें कहां हुईं? | खर्चों का विभाजन और इकाई के अनुसार लाभप्रदता |
| कौन-कौन से संतुलन अभी भी उल्लेखनीय हैं? | प्राप्तियां और देयियां |
| कौन-कौन से कार्य खुले हैं? | दोष और रखरखाव, सफाई या कार्य पूरा करना |

## डेटा स्रोत को समझें

आरक्षण, ठहरने और इकाई आंदोलन की रिपोर्ट में उन आवेदन रिकॉर्ड का उपयोग किया जाता है। शिकायतों, रखरखाव, कार्यों, शिफ्टों, स्टॉक, अनुबंधों, प्रतिस्पर्धी कीमतों और प्रतिभूतियों के लिए संबंधित लेनदेन रिकॉर्ड की आवश्यकता होती है। प्रतिस्पर्धी कीमतों और समीक्षाओं को बाहरी प्लेटफार्मों से स्वचालित रूप से नहीं लिया जाता है। रिपोर्टों में अपने दर्ज स्रोत के साथ मैन्युअल रूप से दर्ज किए गए डेटा दिखाई देते हैं।

देखिये [लेनदेन रिकॉर्ड](transactions.md) स्रोत डेटा दर्ज करने के लिए और [रिपोर्ट का उपयोग करना](reports.md) गणना और निर्यात नियमों के लिए।

| उपयोग किए जाने वाले कमरे के अपार्टमेंट अनुपात | अपार्टमेंट-रात में उपयोग में आने वाले कमरों की क्षमता और अनुपात। |
| अपार्टमेंट परिचालन परिणाम | प्रत्यक्ष आवंटित व्यय के बाद परिणाम। |
| प्राप्त किराया और भुगतान | अनुबंध मूल्य, परिपक्वता तिथि और भुगतान रिकॉर्ड। |

## वित्त

| रिपोर्ट | यह क्या दिखाता है |
| --- | --- |
| प्राप्त दैनिक राजस्व और भुगतान | आवास की जमा राशि, अतिरिक्त राजस्व, प्राप्त भुगतान और धनवापसी अलग से दिखाई देती हैं। |
| व्यय विखंडन | वेतन, किराया, उपयोगिता और अन्य परिचालन व्यय का विखंडन। |
| आय और व्यय | अवधि के राजस्व, परिचालन व्यय और परिचालन परिणाम। |
| भुगतान की विधि | रसीद और धनवापसी के चैनल। |
| कर्मचारियों के वेतन | कर्मचारी और अवधि के अनुसार दर्ज वेतन व्यय। |
| इकाई के अनुसार परिचालन परिणाम | यूनिट राजस्व और प्रत्यक्ष आवंटित व्यय; आवंटित नहीं किए गए व्यय अलग से दिखाए जाते हैं। |
| प्राप्तियां और देयियां | आरक्षण शेष और अन्य खुले खातों का वृद्धावस्था विश्लेषण। |
| रद्द और धनवापसी | रद्द बिक्री, पूर्ण और लंबित वापसी। |
| किराये के व्यय | व्यवसाय द्वारा अवधि और किरायेदार द्वारा भुगतान किया गया किराया ट्रैक करें। |
| उपयोगिता व्यय | प्रकार, अवधि और आपूर्तिकर्ता के अनुसार बिजली, जल, इंटरनेट और गैस के खर्च। |
