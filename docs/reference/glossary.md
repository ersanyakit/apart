# Terimler sözlüğü

| Terim | Anlamı |
| --- | --- |
| Otel / işletme | Tesislerin ve yetkilerin bağlı olduğu ana işletme. |
| Tesis / şube | Günlük işlemleri yürüttüğünüz yer; kayıtlar seçili tesis kapsamında değerlendirilir. |
| Birim | Kiralama yapısındaki daire, oda, yatakhane veya yatak. |
| Fiziksel yatak | Odadaki yatak/ranza düzeni; her zaman ayrı satış birimi değildir. |
| Yatak yeri | Fiziksel düzenin bir yeri/seviyesi; kişi kapasitesi ayrıca tanımlanır. |
| Onaylı rezervasyon | Kaydı oluşturulmuş, henüz giriş yapılmamış rezervasyon. |
| Planlanan giriş/çıkış | Rezervasyon için öngörülen tarihler. |
| Gerçek giriş/çıkış | Fiilen yapılan konaklama işleminin zamanı. |
| Tahsis | Rezervasyonun belirli bir zaman aralığında hangi birimde bulunduğu. |
| Folyo | Rezervasyonun borç, hizmet ve ödeme hareketlerinin hesap özeti. |
| Tahakkuk / gelir | Hizmetin ilgili dönemde oluşan bedeli; tahsilat tarihi farklı olabilir. |
| Tahsilat | İşletmenin aldığı para hareketi. |
| Gider / ödeme | Gider oluşan maliyet; ödeme ise para çıkışıdır. |
| Güvence | İade koşullarıyla alınan depozito; konaklama geliri değildir. |
| Birim-gece | Bir birimin bir gecelik kullanım/satış ölçüsü. |
| Fiziksel doluluk | Kullanılan birim-gecenin fiziksel kapasiteyle ilişkisi. |
| Satılabilir doluluk | Kullanımın satışa açık kapasiteye göre oranı. |
| ADR | Aynı ürün türünde gelir / satılan gece. |
| RevPAR | Aynı ürün türünde gelir / satılabilir gece. |
| Faaliyet sonucu | Rapordaki gelir ve faaliyet giderleri farkı; muhasebe net kârı değildir. |
| Arşiv | Kaydın günlük görünümden ayrılması; fiziksel silme anlamına gelmez. |

Uygulamada gördüğünüz durum etiketini kaydın tarihi ve türüyle birlikte yorumlayın. Ayrıntılı hesap davranışları için [raporlar rehberine](../finance/reports.md) bakın.
